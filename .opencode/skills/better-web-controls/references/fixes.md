# 细节修复对照表（fixes）

> 用户抱怨"页面不对劲"时用。每个 Bug 都是三段式：**症状 → 病因 → 一句 AI 能懂的指令**。直接抄指令，别自己发挥措辞——这些句子是视频里验证过的、AI 一次能做对的表述。

## 7句细节修复（×之前 / ✓之后 对照）

| # | 症状（用户会说） | 病因 | 直接给 AI 的指令 |
|---|---|---|---|
| 1 | 大字和小字没对齐 | 两行字号不同，按外框（bounding box）对齐就会错位 | 「按文字基线对齐，不是按外框。」 |
| 2 | 图片看着偏了 | `object-fit: contain` 会居中留白，看着像歪的 | 「改成填满容器 cover，别居中。」 |
| 3 | 图标和文字错位 | 没说清对齐方式，图标就飘 | 「图标和文字**垂直居中 / 左对齐 / 右对齐**（说清是哪种）。」 |
| 4 | 间距怎么都去不掉 | 多半是残留的 margin 没归零 | 「查残留的 margin，彻底去掉。」 |
| 5 | 内容被导航栏挡住 | 透明浮动导航叠在内容上 | 「给内容留出导航栏的高度（padding-top）。」 |
| 6 | 想要整体居中，但文字也跟着居中了 | 全部居中会把内部文字一起居中 | 「容器整体居中、内部左对齐。」 |
| 7 | 背景框和里面的内容对不齐 | 胶囊和内容四周间距不一致 | 「四周间距保持一致，比如都留 10px。」 |

## Vibe Coding 翻车急救包 — 6句可直接抄的 Prompt

遇到对应问题直接复制那句：

1. 【统一图标】删除装饰 Emoji，统一 SVG 尺寸、线宽和颜色。
2. 【语义裁切】先识别关键主体，再计算 1:1 的裁切位置。
3. 【等高卡片】每一行按最高卡片，统一整行卡片高度。
4. 【响应式布局】桌面多列、手机单列，检查 375、768、1440px。
5. 【横向滚动】定位真正溢出的元素，不要只隐藏滚动条。
6. 【弹窗滚动】请限制弹窗的最大高度，让弹窗始终完整留在浏览视口内；标题和底部按钮固定可见，只允许中间内容区域独立滚动。

## 其他常见翻车对照

| 症状 | 指令 |
|---|---|
| Emoji 满天飞、图标风格乱 | 用第1句【统一图标】 |
| 头像/封面裁不到重点 | 用第2句【语义裁切】 |
| 内容不同卡片长短不齐 | 用第3句【等高卡片】 |
| 页面莫名能左右晃、多出滚动条 | 用第5句【横向滚动】 |
| 弹窗太长、底部按钮怎么滑都看不见 | 用第6句【弹窗滚动】 |
| 链接导入失败没提示 | 「获取失败或没有权限时，明确说明原因」 |
| 表格往下滚找不到列 | 「表格内部往下滚时，表头留在顶部，只滚动下方数据内容」 |
| 危险操作误触 | 「输入 DELETE 后按钮才启用」（见 rules.md 确认篇） |

## 使用建议

- 用户说不清哪里不对时，先按症状表匹配；匹配不上就问"是位置不对、间距不对，还是被什么挡住了"——这三类各对应表格里的一列病因。
- 修完后建议用户自查三处：对齐、间距、遮挡——翻车重灾区。
