# Better Web Controls · IP 标识（logo）

> 角色名：**拓比 / Toby**（"拓"= 拓印、转写；一个把模糊说法转写成准确控件的转接头小孩）

## 0. 本次制作方式（先说明一个环境替换）

ip-as-logo 技能默认流程是「三个方向 → 六个候选位图 → 选一个」。本环境**没有任何图像生成模型**，
因此按约定改为：**继续沿用该技能的造型语言（4–7 个大形状、圆润厚重、两角色色 + 一背景色、从角落生长、32px 可辨），
用 SVG 手绘矢量**落地。位图一律由 SVG 经 Chrome headless 精确尺寸栅格化，不使用截图或放大缩小。

## 1. 三个方向

| 方向 | 主体 — 与产品的关系 — 决定性轮廓 |
| --- | --- |
| A 译钮 | 一颗横置的开关/胶囊滑块活了 — 产品就是把「要做个下拉」这种开关级的请求说清楚；开关拨到 ON 的那一下 = 说法被翻译准确的瞬间 — **一圆 + 一横胶囊**的「头 / 身」两段式轮廓 |
| B 落榫 | 一把圆头木槌 — 手艺人性格的直接化身：把模糊说法敲定成一个能落地的规格 — **横厚锤头 + 粗短柄插进画面角落**的 L 形轮廓 |
| C 词条块 + 插脚 | 一张词典词条卡（方形厚卡）头顶两根钝圆插脚 — 卡片 = 词条，插脚 = 转接头，把一句话转成控件名 — **方块 + 两个凸台**的「凸」字轮廓 |

## 2. 六个候选（同批设想，均已实际画过并做 32px/16px 目测）

| 编号 | 设想 | 结论 |
| --- | --- | --- |
| A1 | 方块板 + 右上角一颗紫色圆旋钮，五官在板面 | 圆旋钮像"贴着的气球"，两色没有形成前后关系；弃 |
| A2 | 大圆脑袋压在紫色胶囊轨道上（旋钮 = 头） | 小尺寸最讨喜，但只是一团"雪人"，认不出是控件；弃 |
| B1 | 横锤头 + 斜柄入左下角，紫柄黄头 | 斜柄在 32px 会糊成一条杂边，且"锤子"读起来偏硬；弃 |
| B2 | 横锤头 + 垂直粗柄，L 形直角 | 轮廓干净但性格太工具化，不够"可爱"；弃 |
| C1 | 圆角厚卡 + 右上角钝圆索引标签（台阶轮廓） | 台阶在 32px 只剩 1px 白边，标签像"耳朵"；改成双凸台 |
| C2 | 卡身黄 + 左中侧伸出紫色标签 | 侧标签在大尺寸像"挂在卡上的零件"，重心散；弃 |
| **C3（最终）** | **黄色厚卡 + 两根紫色钝圆插脚**，卡片下沿被画布裁切 | **入选**：轮廓最稳、两色面积最均衡、32px 后仍是「两个凸台 + 一张脸」 |

> 说明：ip-as-logo 默认把候选分到左下 / 右下两个角落各测一遍；本次需求硬性要求**自左下角生长**，
> 因此六个候选全部按左下 / 下沿方向构图测试，未做右下分配。

## 3. 最终方案：为什么是 C3

1. **32px 最先被认出**：轮廓只有"一张宽卡 + 两个凸台"。凸台间距 76/512 ≈ 4.75px、卡宽 446/512 ≈ 28px，
   缩到 32px 后仍是两个分开的紫色凸台 + 两个深色眼睛，不会糊成一团（见 32px 自查）。
2. **两色有分工**：紫色只负责"插脚"，黄色只负责"卡身"，两块都是大面积连续色块；五官复用背景墨色，不引入第四色。
3. **和产品对得上**：词条卡 = 这本"控件翻译词典"的物件；两根钝插脚 = 转接头，正是"把模糊说法插进精确规格"的动作。
   卡身下沿被裁切、重心压在左下 → 从画面下沿偏左"长出来"。
4. **性格对得上**：没有表情包式的笑，只有两点眼 + 一条极小的嘴，克制；所有形体都是钝圆、无尖角、无描边，
   像一块被反复磨圆的木头/塑料件，手艺人式的可爱。
5. **可复用**：图形只有 6 个基础形体，SVG 1KB 级，可内联、可换底、可单色化（见"用法"）。

**造型说明（给后续改动的人）**
- 卡身：`rect x=24 y=176 w=446 h=400 rx=118`（下沿超出画布 → 被裁切，形成"从下长出"）
- 插脚：`rect 116×156 rx=58` ×2，横向间距 76，中心与卡身中心（x=247）对齐
- 五官：眼 `r=40`，中心间距 132；嘴 `50×20 rx=10`
- 外轮廓连续：两根插脚被卡身覆盖下段，合成一个连通轮廓；眼睛与嘴是内部墨色，不参与外轮廓
- **总形状数 6**（卡身 1 + 插脚 2 + 眼 2 + 嘴 1），外轮廓由其中 3 个大形状合并而成

## 4. 色值

| 用途 | 色值 | 面积占比（约） | 理由 |
| --- | --- | --- | --- |
| 背景 | `#141414` | 深色底，占画面约 22% | 取展示页底色：标识嵌进深色页面时无缝；深底给亮色块最高对比，32px 轮廓最硬 |
| 角色色 1 · 卡身 | `#FFEF93` | 约 62% | 明度最高（≈ L*94），深底上最先被看到，让"那块被说清楚的东西"成为视觉主体 |
| 角色色 2 · 插脚 | `#C2A8FF` | 约 16% | 展示页的强调紫，用作"转接"的副形体；与黄同属高明度家族，所以只做副面积，不抢主体 |
| 五官（墨） | `#141414` | < 1% | 直接复用背景色，**整图仍只有三色**；深墨在黄底上约 16:1 对比，比用紫色画眼睛在小尺寸可靠得多 |

**为什么背景用深色、不用黄或紫**：深底是展示页的既有语境（`#141414`），标识放上去几乎无边界感；
同时只有深底能同时让黄和紫都"亮起来"。若用黄做底，紫色角色 + 深色五官会变成"负形"，32px 下轮廓会与底糊在一起。

## 5. 产出文件

| 文件 | 说明 |
| --- | --- |
| `docs/logo.svg` | 主标识，`viewBox="0 0 512 512"`，正方形，无外部字体/无外链，1KB |
| `docs/logo-512.png` | 512×512，Chrome headless 由 SVG 精确栅格化 |
| `docs/logo-128.png` | 128×128 |
| `docs/logo-32.png` | 32×32（导航尺寸验收样张） |
| `source/html/better-web-controls/logo.svg` | 博客站内副本 |
| `source/html/better-web-controls/logo.png` | 512 PNG 副本 |

三张 PNG 全部为**不透明深色底**（`#141414`），与 SVG 内部底色完全一致；不提供透明版，
因为五官墨色与背景同值，透明后放在浅色底上会失去对比。

## 6. 用法

- **导航 / 页脚**：内联下面这段透明背景的片段，不带宽高，尺寸交给 CSS
  （`.bwc-mark{width:32px;height:32px}`，最小 24px）。眼睛与嘴是 `#141414`，
  在深色页面里读作镂空，所以这段只用于深色底。

  ```html
  <svg class="bwc-mark" viewBox="0 0 512 512" xmlns="http://www.w3.org/2000/svg" role="img" aria-label="Better Web Controls" focusable="false">
    <g fill="#C2A8FF">
      <rect x="93" y="60" width="116" height="156" rx="58"/>
      <rect x="285" y="60" width="116" height="156" rx="58"/>
    </g>
    <rect x="24" y="176" width="446" height="400" rx="118" fill="#FFEF93"/>
    <g fill="#141414">
      <circle cx="181" cy="296" r="40"/>
      <circle cx="313" cy="296" r="40"/>
      <rect x="222" y="368" width="50" height="20" rx="10"/>
    </g>
  </svg>
  ```
- **浅色页面 / 独立使用**：在外层套一个 `#141414` 的圆角容器，或直接用 PNG。
- **favicon / 应用图标**：直接 `logo-32.png`、`logo-128.png`。
- **社交分享 / 大图**：`logo-512.png`，或直接在页面里内联 `logo.svg` 并给容器 `width`。
- **深色页面**：原样使用，`#141414` 底会自然融进页面。
- **浅色页面**：不要抠掉底色。把标识放进一个 `border-radius: 22%` 的 `#141414` 小块里再用，或直接用 PNG。
  抠掉底板后，眼睛和嘴（`#141414`）仍可读，但黄卡在白色上对比不足（约 1.4:1），不推荐。

**不要做**：旋转 / 倾斜、改色或加第四色、加描边或投影、加圆角外框或文字、把插脚改细或改成尖头、
拉伸变形（保持 1:1）、在 24px 以下使用。

## 7. 自查记录

- **32×32**：`logo-32.png` 实拍目测 → 两个紫色插脚、黄色卡身、两个深色眼点均可分辨，没有糊成一团；
  嘴在 32px 退化为 2px 短线，属"极小、从属"的预期，不承担识别。
- **16×16**：仍可读出"凸字形 + 两个眼点"，作为极限尺寸记录（不在正式使用范围内）。
- **黑剪影测试**：把整图压成单色，外轮廓 = 一张宽下摆的圆角卡 + 两个凸台，与同尺寸任何方形控件图标不混淆。
- **三色复核**：`#141414` / `#FFEF93` / `#C2A8FF`，SVG 源文件内无其他颜色字面量；无渐变、无 `stroke`、无 `filter`、无 `<text>`。
