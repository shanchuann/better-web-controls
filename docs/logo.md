# Better Web Controls 标识

## 来源

定稿图为上游提供的 app-icon.png，尺寸 1024 x 1024。仓库内同时保留源图与矢量化版本：矢量由该图轮廓重建，经高斯预平滑、轮廓提取、抽稀与二次贝塞尔拟合，与源图逐像素比对差异约 0.1%，造型未改动。

## 造型

白色厚块角色，头部自画面右侧与下沿探入，边缘被画布裁切。面上有两个斜向眼点与一个横向鼻点，均为负形，露出黑色场。整图仅黑白两色，无描边、无渐变、无文字、无投影。

顶部留有 V 形缺口，是下拉箭头的负形，也是索引卡上的缺口。这本词典最先要翻译的一句话正是做个下拉。

## 色值

| 用途 | 色值 |
|---|---|
| 场 | #000000 |
| 形体 | #FFFFFF |
| 眼与鼻 | #000000，负形 |

## 文件

| 文件 | 用途 |
|---|---|
| docs/logo.svg | 主标识，1024 单位，自包含，可直接内联 |
| docs/logo-512.png | 512 x 512，由 SVG 精确栅格化 |
| docs/logo-128.png | 128 x 128 |
| docs/logo-32.png | 32 x 32，导航尺寸验收样张 |
| docs/app-icon.png | 上游源图，1024 x 1024 |
| source/html/better-web-controls/logo.svg | 展示页 favicon 与导航内联用 |
| source/html/better-web-controls/logo.png | 展示页 512 位图 |

三档 PNG 均为不透明黑场，与 SVG 内部底色一致，不做抠底。

## 用法

深色页面直接使用 SVG 或 PNG，黑场与深底贴合。导航与页脚可内联透明片段，只保留白色路径与黑色五官路径，尺寸交给 CSS，常用 26 至 32px。favicon 使用 logo-32.png 或 logo.svg。浅色页面保留黑场，不要抠掉底色。最小尺寸 24px，32px 时两个眼点与顶部缺口仍可辨认。

## 不要做

旋转或倾斜，加描边、投影与外框，拉伸比例，抠掉黑场，改变眼鼻颜色，在 24px 以下使用。
