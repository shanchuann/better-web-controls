# Better Web Controls 更新记录

## v1.1.0（2026-10-28）

内容扩充，新增 6 个专题。新增条目依据公开可用性研究（Nielsen Norman Group、WCAG 等）与主流设计系统的通行实践整理。

- `controls.md`：长列表加载（分页 / 加载更多 / 无限滚动）、步骤条与分步向导、Tooltip、命令面板；特殊控件新增滑块与评分（8 种增至 10 种）
- `rules.md`：暗色模式适配规则（非反色的 6 条规则）、移动端降级检查清单（7 项）
- `SKILL.md`：路由表与触发描述补充新专题入口词

## v1.0.1（2026-10-28）

全量语言审校：按正式书面语体统一措辞，去除口语化表达与 AI 写作痕迹。表格与 Prompt 模板内容未改动，功能无变化。

## v1.0（2026-10-28）

首个发布版本。

- 收录内容：控件图鉴（按钮、下拉、轮播、Tab、侧边栏、弹窗、进度、上传、表格）、布局（网站、AI产品、登录页、导航、首页、大屏、工作台）、交互规则（提示分级、二次确认、等待、校验、空状态、对齐、长页面定位、分组）、细节修复、图表选型
- 全部条目经逐帧核对原始素材，无推断性内容
- 方法论文档并入 references 目录，无外部文件依赖
