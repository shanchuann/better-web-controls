# 控件图鉴（controls）

> 每个控件：中文名 + 英文名 + 形式/作用 + 适用场景 + 「跟AI说」模板。

## 按钮 — 三步公式：① 形态 → ② 样式 → ③ 文字

别只说"加个按钮"——不说形态、样式、文字，AI 每次生成的都一样。

**6种形态**：

| 形态 | 英文名 | 用途 | 跟AI说 |
|---|---|---|---|
| 面状按钮 | SOLID BUTTON | 主操作最醒目；实心填充一整块颜色。注册、保存、提交 | 「创建一个面状、圆角的"立即注册"按钮，橙色实心填充。」 |
| 线状按钮 | OUTLINE BUTTON | 次操作不抢主按钮的戏；只有一圈描边、没有底色。取消、更多、查看详情 | 「创建一个线状、圆角的"了解更多"按钮，只有一圈描边。」 |
| 文字按钮 | TEXT BUTTON | 最轻量的操作；没边框没底色，就一行字。忘记密码、查看全部 | 「创建一个无底框的"忘记密码"文字按钮。」 |
| 带图标按钮 | ICON BUTTON | 图标+文字，操作含义一眼懂。下载、添加、搜索 | 图标加文字，如「+下载」 |
| 胶囊按钮 | PILL BUTTON | 活泼亲和；圆角拉到最大像颗胶囊。年轻化产品 | 「胶囊按钮，圆角拉到最大。」 |
| 全宽按钮 | FULL-WIDTH BUTTON | 宽度撑满容器。移动端表单、注册页必备 | 「全宽按钮，宽度自适应。」 |

- 样式要点：颜色（**主色只给最重要的一个按钮**）、圆角、尺寸、hover 反馈
- 文字要点：动词开头、简短、说结果不说过程（"立即下载"而不是"点击这里"）
- 页面层级：主按钮实心只有一个，旁边按钮全部线状或文字

**决策**：用户说"加个按钮"，先问主操作还是次操作 → 面状 vs 线状/文字；再看场景（移动端表单→全宽；年轻品牌→胶囊）。

## 下拉组件 — 7种：看起来都往下展开，用途完全不同

说"做个下拉选择"，AI 默认给你最普通的那种。**三要素：组件名称 · 使用场景 · 操作规则**。

1. **Select（单选下拉）**：固定选项选一个。适合=订单状态、用户角色、内容分类
   「做一个订单状态 Select，提供"待处理、进行中、已完成"三个固定选项，只能选择一个。」
2. **Multi-select（多选下拉）**：多选、展示成标签、可单删。适合=数据过滤、权限、标签
   「做一个技能 Multi-select，支持多选，选中后显示成标签并可单独移除。」
3. **Grouped Select（分组下拉）**：选项很多、按类别分组展示；**分组只在有逻辑归属、没有上下级关系时用**
   「做一个 Grouped Select，将品牌按"产品、视觉、研发"分成三组展示。」
4. **Cascader（级联选择）**：选项有上下级，逐级选择。**Grouped 是分组，Cascader 才是上下级**
   「做一个三级 Cascader，按"省—市—区"逐级展示，选择后显示完整路径。」
5. **Split Button（拆分按钮）**：主体执行最常用默认操作，小箭头展开低频操作
   「做一个 Split Button，点击"发布"直接发布，点右侧箭头展开"定时发布 / 保存草稿"。」
6. **Mega Menu（巨型菜单）**：导航内容多、分类复杂；顶级导航下挂多列分类
   「为产品官网制作 Mega Menu，分三列，每列包含分类、产品名称、简图和简介。」
7. **Date Picker（日期选择）**：选日期、时间或范围
   「做一个日期范围 Date Picker，选择入住和退房日期，过去日期不可选，并显示住宿天数。」

决策链：日期/时间？→ Date Picker。有没有上下级？→ 有→Cascader，无但有类别→Grouped，无类别少量→Select，多选→Multi-select。是导航多列面板？→ Mega Menu。主/低频操作并存？→ Split Button。

## 表单输入控件 — 先判断：输入 还是 选择

先分输入再分选择，再报名字。
- 输入类：**Text Field**（短内容）/ **Textarea**（长内容）
- 选择类：**Select**（固定选项）/ **Combobox 可搜索选择框**（选项太多，边搜边选）/ **Radio Group**（少量单选）/ **Checkbox**（同时多选）

| 需求 | 控件 | placeholder 示例 |
|---|---|---|
| 短内容 | Text Field | 请输入姓名 |
| 长内容 | Textarea | 请输入自我描述 |
| 固定选项 | Select | 请选择城市 |
| 边搜边选 | Combobox | 搜索站点 |
| 少量单选 | Radio Group | 猫 / 狗 |
| 同时多选 | Checkbox | 设计 / 运营 |

表单整体体验 7 检查点（Label / Required / Helper Text / Inline Validation / Default Value / Logical Grouping / Success Feedback）见 `rules.md`。

## 轮播 — 7种玩法（AI 默认只会"左右滑+三个圆点"）

说"做个轮播"，先从这几种里挑形式，再说细节。
1. **淡入式 Fade**：图与图交叉淡化，柔和；品牌官网、大图 Banner
2. **3D旋转木马 3D Carousel**：中间大、两侧小、带透视；作品集橱窗感
3. **卡片堆叠 Card Stack**：最上面一张滑走露出下一张；商品推荐、内容卡片流
4. **翻页式 Page Flip**：像翻画册 3D 翻面带卷边，杂志感；作品、品牌展示
5. **手风琴画廊 Accordion**：一排图只露一条边，扫到哪张展开哪张；摄影集、作品集
6. **360°旋转展示 360° View**：按住拖一圈看全角度，松手自动回正；电商产品图、硬件展示
7. **视差轮播 Parallax**：两层错速滚动，图快背景慢；品牌首页、活动主视觉

**细节三步**：说形式 → 说指示器（圆点/箭头）→ 说自动播放。
「做一个手风琴画廊：一排图片只露出一条边，鼠标移到哪张哪张展开；用小圆点指示器；自动播放，悬停暂停。」

## Tab 标签页 — 6种

四要素：使用场景 → 标签外形 → 选中状态 → 切换反馈。
1. **图片预览标签 IMAGE PREVIEW TABS**（缩略图切换主图；作品集、空间案例、商品展示）
   「做一个图片预览标签。每个标签用缩略图+文字标题；点击标签时，上方大图与文案随选中项一起切换；缩略图沿底部排成一行。」
2. **线性滑块标签 LINEAR SLIDER TABS**（细线跟随滑动；后台看板、详情页双栏）
   「做一个线性滑块标签。文字居左排布，滑块为细线且与文字对齐；点击时平滑滑动，内容切换。」
3. **卡片式标签页 CARD TABS**（标签与面板相连；层级明显的内容展示）
   「做一个卡片式标签页。选中项为高亮卡片，未选中为浅灰，悬停时卡片浮起；下方内容面板跟随切换。」
4. **鱼骨式步骤标签 CHEVRON STEPPER TABS**（步骤首尾相接；结账、开户等有先后顺序的流程）
   「做一个鱼骨式步骤标签。每个标签像连续箭头，当前步骤用高亮色填充；点击时切换对应内容面板。」
5. **分段控件标签 SEGMENTED CONTROL TABS**（同一轨道内切换；视图/时间范围切换）
   「做一个分段控件标签。放在同一轨道容器内，选中分段高亮浮起，切换时圆形滑块平滑移动。」
6. **文件夹标签 FOLDER TABS**（页签连接内容面板、选中上抬微倾角；文档库、档案分类）
   「做一个文件夹标签。选中的标签向上抬起 8°，非选中的保持原位；下方面板跟随切换。」

## 侧边栏 — 5种 + 4件套

开场判断：要悬浮感还是贴边？信息层级深不深？收起方式？
1. **悬浮岛式 Floating Island**（不贴边、四周留白、圆角卡+柔和阴影）
   「左右侧栏悬浮式设计：圆角卡片、背景留白，并用柔和阴影营造悬浮感。」
2. **弧形滚轮式侧边导航**（选项沿弧排布，到达基准线才高亮；氛围感展示型页面）
3. **多级侧边栏**（父级下继续展开子菜单；信息层级多的系统）
4. **可折叠侧边栏 Collapsible Sidebar**（展开显示图标与文字，收起只留图标）
   「做一个可折叠侧边栏：展开宽 240px，收起为图标栏，内容区域随比例伸缩。」
5. **隐藏式侧边栏**（平时不见，点击展开，再点一次关闭）

**说清4件事**：01 类型 · 02 位置 · 03 宽度 · 04 收起方式
「在页面左侧做一个宽 248px 的可折叠侧边栏：展开时显示文字，收起后留图标，当前页面高亮。」

## 弹窗 — Modal vs Popover + 四要素

两类弹窗，别把小弹窗做成大卡片：
- **Modal 居中弹窗**：打断当前任务，处理完才能继续；删除确认、支付确认等高风险
- **Popover 气泡弹层**：少量内容紧贴触发点出现，轻、不打断；行尾"…"菜单、轻量操作

**四要素**：① 类型 → ② 触发（位置） → ③ 关闭方式 → ④ 内容
「居中的 Modal，点击删除后触发；点击取消、确认按钮或按 Esc 后关闭；包含风险说明和两个操作按钮。」
弹窗太长的滚动修复句见 `fixes.md`。

## 进度 — 先分大类，再选动画

**第一步判断：能算出比例吗？**
- 能算（上传多少、处理几条）→ **确定进度 Determinate**
- 算不出（AI思考、未知时长接口）→ **不确定进度 Indeterminate**，别硬编"83%"

确定进度 4 种动画：**平滑填充 Bar**（文件上传下载，配百分比）/ **阶段步骤 Steps**（注册、多步任务）/ **环形百分比 Ring**（按钮内、卡片角落等小空间）/ **整体填充仪表**（完成度、占比展示）。
不确定进度 4 种动画：**循环同步 spinner**（按钮内、行内等待，最通用）/ **雷达扫描 radial sweep**（分析类场景）/ **三点跳动 dots**（AI 生成文字的气泡内）/ **音频波动 waveform**（语音处理中）。

口播模板：「上传文件用条形进度 Bar，填充从 0 到 100%，旁边显示百分比」「AI 生成文案的地方用三点跳动 dots」。
等待体验整体策略（短/中/长）见 `rules.md`。

## 上传 — 5种方式按场景选（已视频逐帧验证）

| 方式 | 英文名 | 怎么用 | 适合 | 跟AI说 |
|---|---|---|---|---|
| 本地文件上传 | Local file upload | 点一下按钮，从设备中选择文件 | 表单附件、简历、证件材料 | 「打开文件选择器，限制格式与大小；选择后显示文件名，支持删除重选」 |
| 拖拽上传 | Drag & drop | 把文件拖进接收区，松手即可添加 | 电脑端素材、批量文档 | 「拖入时高亮，松手后显示文件列表；同时保留点击选择的入口」 |
| 粘贴上传 | Paste from clipboard | 把参考图粘贴进 AI 对话，再输入需求 | AI 对话、风格参考、设计创作 | 「图片直接粘贴在输入框上方显示为参考图，再输入"请参考这张图片的风格"」 |
| 拍照上传 | Capture & upload | 手机直接拍照，预览后再提交 | 单据、现场记录、资料采集 | 「提供拍照入口，支持重拍和确认；保留相册或文件选择入口」 |
| 链接导入 | Import from URL | 粘贴可访问的链接，获取远程资源 | 在线图片、远程资料 | 「粘贴链接后校验是否允许访问；失败或无权限时说明原因」 |

粘贴上传的关键价值：「直接读取剪贴板里的图片，不必先保存到本地，再找文件上传」。
通用规则（第1集总结）：说明支持的**格式和大小**（拖拽区标注"单文件不超过 20 MB"），允许用户**移除后重新选择**。

## 表格 — 5种：怎么找 · 怎么看 · 怎么操作（已视频逐帧验证）

跟AI做表格，别只说"放哪些字段"。先想清楚：用户怎么**找**到要的行、怎么**看**懂每一列、怎么**操作**。

- **01 表头筛选 Column Filter**：只看符合条件的内容；适合=标签、状态、负责人过滤（标签种类太多，只看重点客户）
  「加一个表头筛选，可以按标签、状态和负责人过滤」
- **02 列排序 Column Sort**：把最关心的数据排在前面；适合=金额、日期、数量
  「想先看金额最高的，不用自己找，这叫列排序：金额列可升降序点击排序」
- **03 固定表头 Sticky Header**：往下翻也知道每列是什么；适合=长列表、记录明细
  「表格内部往下滚时，表头留在顶部，只滚动下方数据内容」
- **04 行操作收纳 Row Actions**：常用操作直接点，其他按需展开（"…"菜单）；适合=每条记录有多个操作
  「每一行都放查看、编辑、复制、删除会挤成一团——常用操作直接显示，其余收进行尾"…"菜单」
- **05 自定义列 Column Settings**：按自己的任务选择显示字段；适合=字段多、使用角色不同
  「加一个列设置，勾选要显示的字段，并记住我的选择」
