# 控件图鉴（controls）

每个控件按固定结构描述：中文名、英文名、形式与作用、适用场景、"跟AI说"模板。

## 按钮 — 三步公式：形态、样式、文字

仅要求"加一个按钮"时，AI 每次生成的结果基本相同。按钮需要按三步描述：形态、样式、文字。

**6种形态**：

| 形态 | 英文名 | 用途 | 跟AI说 |
|---|---|---|---|
| 面状按钮 | SOLID BUTTON | 主操作，视觉权重最高；实心填充。注册、保存、提交 | "创建一个面状、圆角的"立即注册"按钮，橙色实心填充。" |
| 线状按钮 | OUTLINE BUTTON | 次操作，不与主按钮争夺注意力；仅一圈描边，无底色。取消、更多、查看详情 | "创建一个线状、圆角的"了解更多"按钮，只有一圈描边。" |
| 文字按钮 | TEXT BUTTON | 轻量操作；无边框无底色，仅一行文字。忘记密码、查看全部 | "创建一个无底框的"忘记密码"文字按钮。" |
| 带图标按钮 | ICON BUTTON | 图标加文字，操作含义直观。下载、添加、搜索 | 图标加文字，如"+下载" |
| 胶囊按钮 | PILL BUTTON | 活泼亲和；圆角取最大值。年轻化产品 | "胶囊按钮，圆角拉到最大。" |
| 全宽按钮 | FULL-WIDTH BUTTON | 宽度撑满容器。移动端表单、注册页 | "全宽按钮，宽度自适应。" |

- 样式要点：颜色（主色仅用于最重要的一个按钮）、圆角、尺寸、hover 反馈。
- 文字要点：动词开头，表述简短，说明结果而非过程。例如使用"立即下载"，而非"点击这里"。
- 页面层级：主按钮使用实心样式且全页仅一个，其余按钮使用线状或文字样式。

**选型判断**：用户要求添加按钮时，先判断主操作还是次操作，分别对应面状按钮与线状、文字按钮；再结合场景确定形式：移动端表单使用全宽按钮，年轻化品牌使用胶囊按钮。

## 下拉组件 — 7种：外观相似，用途不同

仅说"做个下拉选择"时，AI 默认提供最普通的形式。各下拉组件的展开方向相似，用途不同。描述时需包含三要素：组件名称、使用场景、操作规则。

1. **Select（单选下拉）**：固定选项中选择一个。适用于订单状态、用户角色、内容分类。
   "做一个订单状态 Select，提供"待处理、进行中、已完成"三个固定选项，只能选择一个。"
2. **Multi-select（多选下拉）**：支持多选，选中项以标签展示，可单独移除。适用于数据过滤、权限设置、标签标记。
   "做一个技能 Multi-select，支持多选，选中后显示成标签并可单独移除。"
3. **Grouped Select（分组下拉）**：选项较多时按类别分组展示。分组仅用于存在逻辑归属、不存在上下级关系的选项。
   "做一个 Grouped Select，将品牌按"产品、视觉、研发"分成三组展示。"
4. **Cascader（级联选择）**：选项存在上下级关系，逐级选择。注意：Grouped 是分组，Cascader 才是上下级。
   "做一个三级 Cascader，按"省—市—区"逐级展示，选择后显示完整路径。"
5. **Split Button（拆分按钮）**：主体执行最常用的默认操作，箭头展开低频操作。
   "做一个 Split Button，点击"发布"直接发布，点右侧箭头展开"定时发布 / 保存草稿"。"
6. **Mega Menu（巨型菜单）**：导航内容多、分类复杂；顶级导航下挂多列分类。
   "为产品官网制作 Mega Menu，分三列，每列包含分类、产品名称、简图和简介。"
7. **Date Picker（日期选择）**：选择日期、时间或日期范围。
   "做一个日期范围 Date Picker，选择入住和退房日期，过去日期不可选，并显示住宿天数。"

**选型判断**：日期或时间需求用 Date Picker；选项有上下级用 Cascader，无层级但有类别用 Grouped，无层级且少量用 Select，多选用 Multi-select；多列导航面板用 Mega Menu；默认操作与低频操作并存用 Split Button。

## 表单输入控件 — 先判断输入还是选择

先区分用户是自己填写内容，还是从已有选项中选择，再确定控件名称。

- 输入类：**Text Field**（短内容）/ **Textarea**（长内容）
- 选择类：**Select**（固定选项）/ **Combobox** 可搜索选择框（选项多，边搜边选）/ **Radio Group**（少量单选）/ **Checkbox**（同时多选）

| 需求 | 控件 | placeholder 示例 |
|---|---|---|
| 短内容 | Text Field | 请输入姓名 |
| 长内容 | Textarea | 请输入自我描述 |
| 固定选项 | Select | 请选择城市 |
| 边搜边选 | Combobox | 搜索站点 |
| 少量单选 | Radio Group | 猫 / 狗 |
| 同时多选 | Checkbox | 设计 / 运营 |

表单整体体验的 7 个检查点（Label / Required / Helper Text / Inline Validation / Default Value / Logical Grouping / Success Feedback）见 `rules.md`。

## 轮播 — 7种玩法（AI 默认只会"左右滑加三个圆点"）

用户要求做轮播时，先从以下形式中选择，再补充细节。

1. **淡入式 Fade**：图与图交叉淡化，切换柔和。品牌官网、大图 Banner
2. **3D旋转木马 3D Carousel**：中间大、两侧小、带透视。作品集橱窗效果
3. **卡片堆叠 Card Stack**：最上面一张滑走露出下一张。商品推荐、内容卡片流
4. **翻页式 Page Flip**：3D 翻面带卷边，类似画册。作品、品牌展示
5. **手风琴画廊 Accordion**：一排图只露出一条边，指向哪张展开哪张。摄影集、作品集
6. **360°旋转展示 360° View**：按住拖动查看全角度，松手自动回正。电商产品图、硬件展示
7. **视差轮播 Parallax**：两层错速滚动，前景快背景慢。品牌首页、活动主视觉

**细节三步**：说形式，说指示器（圆点或箭头），说自动播放。
"做一个手风琴画廊：一排图片只露出一条边，鼠标移到哪张哪张展开；用小圆点指示器；自动播放，悬停暂停。"

## Tab 标签页 — 6种

描述包含四要素：使用场景、标签外形、选中状态、切换反馈。

1. **图片预览标签 IMAGE PREVIEW TABS**（缩略图切换主图；作品集、空间案例、商品展示）
   "做一个图片预览标签。每个标签用缩略图+文字标题；点击标签时，上方大图与文案随选中项一起切换；缩略图沿底部排成一行。"
2. **线性滑块标签 LINEAR SLIDER TABS**（细线跟随滑动；后台看板、详情页双栏）
   "做一个线性滑块标签。文字居左排布，滑块为细线且与文字对齐；点击时平滑滑动，内容切换。"
3. **卡片式标签页 CARD TABS**（标签与面板相连；层级明显的内容展示）
   "做一个卡片式标签页。选中项为高亮卡片，未选中为浅灰，悬停时卡片浮起；下方内容面板跟随切换。"
4. **鱼骨式步骤标签 CHEVRON STEPPER TABS**（步骤首尾相接；结账、开户等有先后顺序的流程）
   "做一个鱼骨式步骤标签。每个标签形如连续箭头，当前步骤用高亮色填充；点击时切换对应内容面板。"
5. **分段控件标签 SEGMENTED CONTROL TABS**（同一轨道内切换；视图或时间范围切换）
   "做一个分段控件标签。放在同一轨道容器内，选中分段高亮浮起，切换时圆形滑块平滑移动。"
6. **文件夹标签 FOLDER TABS**（页签连接内容面板，选中上抬微倾角；文档库、档案分类）
   "做一个文件夹标签。选中的标签向上抬起 8°，非选中的保持原位；下方面板跟随切换。"

## 侧边栏 — 5种，描述包含4项要素

先判断：需要悬浮感还是贴边、信息层级深浅、收起方式。

1. **悬浮岛式 Floating Island**（不贴边、四周留白、圆角卡加柔和阴影）
   "左右侧栏悬浮式设计：圆角卡片、背景留白，并用柔和阴影营造悬浮感。"
2. **弧形滚轮式侧边导航**（选项沿弧排布，到达基准线才高亮；氛围感展示型页面）
3. **多级侧边栏**（父级下展开子菜单；信息层级多的系统）
4. **可折叠侧边栏 Collapsible Sidebar**（展开显示图标与文字，收起仅留图标）
   "做一个可折叠侧边栏：展开宽 240px，收起为图标栏，内容区域随比例伸缩。"
5. **隐藏式侧边栏**（平时不显示，点击展开，再点击关闭）

**描述包含4项要素**：类型、位置、宽度、收起方式。
"在页面左侧做一个宽 248px 的可折叠侧边栏：展开时显示文字，收起后留图标，当前页面高亮。"

## 弹窗 — Modal 与 Popover，描述包含4项要素

两类弹窗，避免将小型弹窗做成占满全屏的大卡片：

- **Modal 居中弹窗**：打断当前任务，处理完才能继续。删除确认、支付确认等高风险操作
- **Popover 气泡弹层**：少量内容紧贴触发点出现，操作轻，不打断页面。行尾"…"菜单、轻量操作

**四要素**：类型、触发（位置）、关闭方式、内容。
"居中的 Modal，点击删除后触发；点击取消、确认按钮或按 Esc 后关闭；包含风险说明和两个操作按钮。"
弹窗过长的滚动修复句见 `fixes.md`。

## 进度 — 先分大类，再选动画

第一步判断能否算出比例。

- 能算（已上传多少、已处理几条）→ **确定进度 Determinate**
- 算不出（AI 思考中、时长未知的接口等待）→ **不确定进度 Indeterminate**，不要编造"83%"这类虚假百分比

确定进度 4 种动画：**平滑填充 Bar**（文件上传下载，配百分比数字）/ **阶段步骤 Steps**（注册、多步任务）/ **环形百分比 Ring**（按钮内、卡片角落等小空间）/ **整体填充仪表**（完成度、占比展示）。
不确定进度 4 种动画：**循环同步 spinner**（按钮内、行内等待，最通用）/ **雷达扫描 radial sweep**（分析类场景）/ **三点跳动 dots**（AI 生成文字的气泡内）/ **音频波动 waveform**（语音处理中）。

表述模板："上传文件用条形进度 Bar，填充从 0 到 100%，旁边显示百分比""AI 生成文案的位置用三点跳动 dots"。
等待体验的整体策略（按短、中、长等待分类）见 `rules.md`。

## 上传 — 5种方式按场景选择

| 方式 | 英文名 | 怎么用 | 适合 | 跟AI说 |
|---|---|---|---|---|
| 本地文件上传 | Local file upload | 点按钮，从设备中选择文件 | 表单附件、简历、证件材料 | "打开文件选择器，限制格式与大小；选择后显示文件名，支持删除重选" |
| 拖拽上传 | Drag & drop | 文件拖入接收区，松手即添加 | 电脑端素材、批量文档 | "拖入时高亮，松手后显示文件列表；同时保留点击选择的入口" |
| 粘贴上传 | Paste from clipboard | 把参考图粘贴进 AI 对话，再输入需求 | AI 对话、风格参考、设计创作 | "图片直接粘贴在输入框上方显示为参考图，再输入"请参考这张图片的风格"" |
| 拍照上传 | Capture & upload | 手机直接拍照，预览后提交 | 单据、现场记录、资料采集 | "提供拍照入口，支持重拍和确认；保留相册或文件选择入口" |
| 链接导入 | Import from URL | 粘贴可访问的链接获取远程资源 | 在线图片、远程资料 | "粘贴链接后校验是否允许访问；失败或无权限时说明原因" |

粘贴上传的价值：直接读取剪贴板中的图片，省去先保存到本地再上传的步骤。
通用规则：说明支持的格式与大小（拖拽区可标注单文件上限，例如 20 MB），允许用户移除后重新选择。

## 表格 — 5种：怎么找、怎么看、怎么操作

描述表格时不要只说明包含哪些字段。先明确三点：用户如何找到目标行、如何理解每一列、如何执行操作。

- **01 表头筛选 Column Filter**：仅显示符合条件的内容。适用于标签、状态、负责人过滤（标签种类多时只看重点客户）
  "加一个表头筛选，可以按标签、状态和负责人过滤"
- **02 列排序 Column Sort**：将最重要的数据排在前面。适用于金额、日期、数量
  "金额列支持点击表头升降序排序，默认按金额从高到低"
- **03 固定表头 Sticky Header**：向下滚动时仍能对应每列的含义。适用于长列表、记录明细
  "表格内部往下滚时，表头留在顶部，只滚动下方数据内容"
- **04 行操作收纳 Row Actions**：常用操作直接显示，其余收进行尾"…"菜单。适用于每条记录有多个操作的情况
  "每一行的查看、编辑、复制、删除会挤在一起。常用操作直接显示，其余收进行尾"…"菜单"
- **05 自定义列 Column Settings**：按任务需要选择显示的字段。适用于字段多、使用角色不同的情况
  "加一个列设置，勾选要显示的字段，并记住我的选择"
