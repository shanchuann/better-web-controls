# 细节修复对照表（fixes）

用户表示"页面不对劲"时使用本表。每个问题按三段描述：症状、病因、修复指令。指令句式经原视频验证，可直接复制使用，不建议改写措辞。

## 7句细节修复

| # | 症状（用户可能说） | 病因 | 修复指令 |
|---|---|---|---|
| 1 | 大字和小字没对齐 | 两行字号不同，按外框（bounding box）对齐会错位 | "按文字基线对齐，不是按外框。" |
| 2 | 图片看着偏了 | `object-fit: contain` 居中留白，看起来像歪的 | "改成填满容器 cover，别居中。" |
| 3 | 图标和文字错位 | 未说明对齐方式 | "图标和文字垂直居中 / 左对齐 / 右对齐（指明是哪种）。" |
| 4 | 间距去不掉 | 多半是残留的 margin 未归零 | "查残留的 margin，彻底去掉。" |
| 5 | 内容被导航栏挡住 | 透明浮动导航叠加在内容上 | "给内容留出导航栏的高度（padding-top）。" |
| 6 | 容器居中，内部文字也跟着居中 | 全部居中会影响内部文字 | "容器整体居中、内部左对齐。" |
| 7 | 背景框与内容对不齐 | 胶囊与内容四周间距不一致 | "四周间距保持一致，比如都留 10px。" |

## Vibe Coding 常见问题 — 6句可直接使用的 Prompt

遇到对应问题时复制对应句子：

1. 【统一图标】删除装饰 Emoji，统一 SVG 尺寸、线宽和颜色。
2. 【语义裁切】先识别关键主体，再计算 1:1 的裁切位置。
3. 【等高卡片】每一行按最高卡片，统一整行卡片高度。
4. 【响应式布局】桌面多列、手机单列，检查 375、768、1440px。
5. 【横向滚动】定位真正溢出的元素，不要只隐藏滚动条。
6. 【弹窗滚动】请限制弹窗的最大高度，让弹窗完整保留在浏览视口内；标题和底部按钮固定可见，仅中间内容区域独立滚动。

## 其他常见问题对照

| 症状 | 处理 |
|---|---|
| Emoji 装饰过多、图标风格不统一 | 使用第1句【统一图标】 |
| 头像或封面裁切位置不对 | 使用第2句【语义裁切】 |
| 内容不同导致卡片高度不齐 | 使用第3句【等高卡片】 |
| 页面出现横向滚动条 | 使用第5句【横向滚动】 |
| 弹窗过长，底部按钮不可见 | 使用第6句【弹窗滚动】 |
| 链接导入失败无提示 | "获取失败或没有权限时，明确说明原因" |
| 表格滚动后看不到列名 | "表格内部往下滚时，表头留在顶部，只滚动下方数据内容" |
| 危险操作被误触 | "输入 DELETE 后按钮才启用"（见 rules.md 二次确认） |

## 使用建议

- 用户说不清问题时，先按症状表匹配；无法匹配时询问属于哪一类：位置不对、间距不对，还是被其他元素遮挡。
- 修复完成后建议检查三处：对齐、间距、遮挡。这三处是常见问题集中区域。
