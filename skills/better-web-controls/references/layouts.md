# 布局与结构（layouts）

## 网站布局 — 7种

**做网站之前，先选对布局，再说参数。**
1. **单栏布局 Single Column**：内容一列通到底，阅读节奏最舒服；博客、长文、极简介绍页
2. **落地页布局 Landing Page**：大图开场、功能介绍跟上、按钮收尾；SaaS 官网、App 下载页、活动推广
3. **瀑布流 Masonry**：不等高卡片无限下拉，图片多也不乱；灵感站、图片社区、作品集
4. **全屏沉浸式 Full-screen**：首屏一整屏大图只留一句主标题；品牌官网、游戏站、发布会
5. **分隔面板 Splitter**：中间分隔线可拖、两边宽度自调；代码编辑器、文件管理器、BI 看板
6. **仪表盘布局 Dashboard**：数据看板、监控台，图表卡片一眼扫完
7. **自定义模块**（自由拼装）：页面像积木，模块拖到哪算哪

## AI 产品布局 — 6种

做 AI 产品别只画聊天窗口。**先选形态，再说任务。**
1. **对话式 Chat**：问题开放、想法还在发散
2. **面板分割 Side Panel**：左边干活右边 AI 盯着；写代码、改文档，选中哪段改哪段
3. **插件式隐藏 Plugin**：平时藏起来需要时出现；老产品加 AI 不改用户习惯
4. **悬浮球 Floating Ball**：常驻屏幕随时唤起；跨软件求助不切窗口（文档页角标"帮我总结这份文件"）
5. **无限画布 Infinite Canvas**：卡片摊开自由摆放，AI 陪你在画布上发散；头脑风暴、梳理方案
6. **隐藏UI Invisible**：完全没有界面，AI 后台默默干活；相册分类、邮件归档等自动化

## 登录页 — 5种 + 公式（布局、背景、卡片）（已视频逐帧验证）

"帮我做个高级的登录页" = 让 AI 瞎猜。直接报样式名：
1. **居中卡片式 Centered Card**（稳妥通用，大多数工具和 SaaS 产品的默认答案）
   「做居中卡片式登录页，卡片悬浮，页面留白充足。」
2. **Split Screen 左右分屏式**（品牌表达+登录并存；想兼顾品牌展示）
   「做 6:4 左右分屏，左边讲品牌，右边放无卡片表单；移动端折叠单栏布局。」
3. **Immersive Background 沉浸背景式**（表单融入有色背景，用排版和底线建立层级，不再套一张卡片）
   「使用陶橙到金色的沉浸渐变背景，登录表单无边框叠放其上，并加深色遮罩保证可读性。」
4. **Role-based Tabs 多角色Tab登录**（同一表单切换身份；个人+企业双端产品）
   「用 Tab 切换个人用户与企业管理员，展示两种身份不同的登录字段。」
5. **Step-by-step 分步登录式**（验证步骤较多时，一屏只做一件事，降低理解和操作负担）
   「把登录拆成分步流程，一屏只完成一个任务，并展示进度与返回入口。」

## 导航 — 9种 · 该叫什么 · 怎么说

"帮我做个好看的导航栏"十次八九次不对——不是 AI 笨，是不会描述。每个导航 = **名字 + 触发方式 + 收起方式 + 位置**。

**一、位置/布局类**
1. **悬浮吸顶 Floating · Sticky**：浮起的圆角卡，离顶留白带阴影，下滚钉在顶部 → 「floating 悬浮导航 + sticky 吸顶固定」
2. **侧边栏 Sidebar**：竖排左侧，可折叠成图标；后台、工具站标配 → 「sidebar 侧边栏 + 可折叠 collapsible 成图标」
3. **面包屑 Breadcrumb**：不是主菜单，是主导航下面一层路径 → 「主导航下加一行 breadcrumb 面包屑」

**二、结构类**
4. **二级下拉 Dropdown**：鼠标一放子菜单往下弹 → 「hover 展开的二级 dropdown 下拉菜单」
5. **巨型菜单 Mega Menu**：一悬停铺开多列面板，电商大站标配 → 「mega menu 巨型菜单 + 多列分类面板」
6. **汉堡抽屉 Hamburger · Drawer**：点三条杠，菜单侧滑出；手机端最常见 → 「hamburger 汉堡菜单 + drawer 抽屉侧滑」
7. **全屏遮罩 Full-screen Overlay**：点开盖住整屏、菜单居中放大，有仪式感；作品集常用 → 「full-screen overlay 全屏遮罩菜单」

**三、动效/行为类**
8. **锚点导航 Scrollspy**：滚到哪个区块对应项自动高亮；长文档、落地页 → 「scrollspy 锚点导航，滚到哪高亮哪」
9. **滚动收缩 Shrink on Scroll**：顶部透明贴大图，下滚变矮变实色 → 「导航顶部透明，下滚变矮变实色 shrink」

## 首页 — 10大模块解剖

搞不清模块叫什么名字？10个一次认全：

| 模块 | 英文名 | 职责 |
|---|---|---|
| 导航栏 | Navbar | 顶部导航 |
| 首屏 | Hero | 第一眼大区域 |
| 价值主张 | Value Prop | 首屏最大那句，讲"能做到什么"，不是产品名 |
| 信任系 | Social Proof | 数据、背书、合作证据 |
| 功能区 | Features | 逐个讲能力 |
| 用户评价 | Testimonials | 真实用户口碑，打消顾虑 |
| 价格表 | Pricing | 套餐与价格 |
| 常见问题 | FAQ | 答疑 |
| 行动按钮 | CTA | 转化动作 |
| 页脚 | Footer | 链接、联系方式、版权，收尾兜底 |

## 首屏设计 — 先判网站类型，再决定突出什么

首屏不是塞满内容，而是**回答用户最关心的问题**：

| 类型 | 用户想确认 | 首屏该给的答案 |
|---|---|---|
| 产品介绍类 | 能解决什么？ | 产品价值 |
| 个人品牌形象类 | 你是谁、擅长什么？ | 定位、代表作品和风格 |
| 活动行动召唤类 | 为什么要现在参加？ | 行动理由 |

个人品牌示例：「为个人设计师作品集页面设计首屏：加入圆形头像、放大代表作品 Banner。」

## 大屏看板 — 3层结构 + 5种布局

**看板不是图越多越专业**，而是结果、趋势、原因层层递进——别让 AI 做"一整页的图表拼盘"。
- 顶部：**KPI卡**（每张卡只亮一个指标，标同比/环比，如 DAU 28,460 +4.7%）
- 中部：趋势图（看变化）
- 底部：明细表（找原因）

**5种大屏布局（已视频逐帧验证）**：
- **01 中心聚焦 Center Focus**：让观众第一眼看见核心业务（核心地图/态势居中大幅，指标环绕四周）；地图、园区态势、核心设备状态
- **02 上总下分 Summary First**：先给结论再向下拆解原因；经营复盘、汇报大屏、管理看板
- **03 左右分栏 Overview & Detail**：一边看整体结果，一边看原因和明细；区域分析、业务对比、异常诊断
- **04 网格模块 Modular Grid**：同时监控多种状态，但保留主次（重点卡片突出）；设备监控、运维中心、综合态势
- **05 流程链路 Process Flow**：沿业务链路横向串联各环节指标，哪个环节异常一眼定位；供应链、工业生产、应急指挥

**跟AI说的顺序**：业务关系 → 布局 → 视觉风格。**别只说"科技感"**——要说产品气质、信息密度、明确模式、图形语言四个维度。
Prompt 顺序示例：「先说清业务关系（这是给管理层看的复盘）→ 选布局（上总下分）→ 再定视觉风格（深色底、高对比、克制配色）」。

## 工作流实战 — 目标先行

搭工作台/工具类页面时，"做个网页"很难做对；按下面顺序写：
1. 核心目标：用户打开后马上要能干什么（"今天学什么、还要多久、哪些要复习"）
2. 功能清单：逐条列出模块与可交互操作（可编辑/新增/勾选/删除）
3. 交互细节：状态、反馈，参考 `rules.md`

**可抄的完整 Prompt 范例**（个人学习工作台）：
「请为我制作一个中文版『个人学习工作台』网页，面向正在备考、学英语、考证或学习新技能的普通用户。
核心目标：用户打开网页后，马上知道今天学什么、还要多久、哪些内容需要复习。
请包含以下功能：
1. 学习日历：可编辑目标名称、考试日期、目标分数和每日学习时长。
2. 今日学习：展示今天的学习任务、预计用时、优先级和完成状态，支持新增、编辑、删除、勾选完成。」

同思路可替换核心目标与功能清单，迁移到备考之外的工作台（如内容排期、销售跟进、项目管理）。

## 风格参考图 — 连控件一起画/说

只有色彩和字体的参考图，按钮、输入框、卡片每个都要 AI 猜，做出来当然乱。风格参考要**把控件长什么样一起写进 Prompt**。

**范例结构**（"苹果液态玻璃风"完整风格 Prompt 的要素拆解，可直接仿写）：
- 主色/底色：主色 #DCD5CC 暖米白 + 具体色值
- 大字排版：Hero 大标题的字号层级与字重
- 控件规格：按钮色值（如 #F01701）、圆角大小（如 4px）
- 图标语言：线性/面性、粗细、统一颜色
- 质感关键词：液态玻璃 Liquid Glass——半透明磨砂+背景折射

生成风格参考图后，再让 AI 按参考图 + 控件名 + 交互规则做页面（工作流：风格 Prompt → 生成参考图 → 作为附件交给 AI 搭页面）。
