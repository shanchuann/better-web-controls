# 布局与结构（layouts）

## 网站布局 — 7种

制作网站前，先确定布局类型，再补充参数。

1. **单栏布局 Single Column**：内容单列贯通，阅读节奏平稳。博客、长文、极简介绍页
2. **落地页布局 Landing Page**：大图开场、功能介绍、按钮收尾。SaaS 官网、App 下载页、活动推广
3. **瀑布流 Masonry**：不等高卡片纵向排列，图片数量多时仍保持秩序。灵感站、图片社区、作品集
4. **全屏沉浸式 Full-screen**：首屏整屏大图，仅保留一句主标题。品牌官网、游戏站、发布会
5. **分隔面板 Splitter**：中间分隔线可拖动，两侧宽度自调。代码编辑器、文件管理器、BI 看板
6. **仪表盘布局 Dashboard**：数据看板、监控台，图表卡片一览
7. **自定义模块**（自由拼装）：页面由模块组合，位置可拖动调整

## AI 产品布局 — 6种

制作 AI 产品时不要只画聊天窗口。先确定形态，再描述任务。

1. **对话式 Chat**：问题开放、想法仍在发散阶段
2. **面板分割 Side Panel**：左侧工作区，右侧 AI 面板。写代码、改文档，选中哪段处理哪段
3. **插件式隐藏 Plugin**：平时隐藏，需要时出现。老产品接入 AI，不改变用户习惯
4. **悬浮球 Floating Ball**：常驻屏幕随时唤起。跨软件求助，不切换窗口（文档页角标"帮我总结这份文件"）
5. **无限画布 Infinite Canvas**：卡片自由摆放，AI 在画布上配合发散。头脑风暴、方案梳理
6. **隐藏UI Invisible**：无界面，AI 在后台处理。相册分类、邮件归档等自动化任务

## 登录页 — 5种，描述包含布局、背景、卡片三项

"帮我做个高级的登录页"这类表述会让 AI 自行猜测。应直接指明样式名称：

1. **居中卡片式 Centered Card**（稳妥通用，多数工具与 SaaS 产品的常规选择）
   「做居中卡片式登录页，卡片悬浮，页面留白充足。」
2. **Split Screen 左右分屏式**（品牌展示与登录并存）
   「做 6:4 左右分屏，左边讲品牌，右边放无卡片表单；移动端折叠单栏布局。」
3. **Immersive Background 沉浸背景式**（表单融入有色背景，用排版与分隔线建立层级，不使用卡片）
   「使用陶橙到金色的沉浸渐变背景，登录表单无边框叠放其上，并加深色遮罩保证可读性。」
4. **Role-based Tabs 多角色Tab登录**（同一表单切换身份；个人与企业双端产品）
   「用 Tab 切换个人用户与企业管理员，展示两种身份不同的登录字段。」
5. **Step-by-step 分步登录式**（验证步骤较多时，每屏只完成一个任务，降低理解与操作负担）
   「把登录拆成分步流程，一屏只完成一个任务，并展示进度与返回入口。」

## 导航 — 9种：名称、说法

"帮我做个好看的导航栏"这类表述大概率得不到预期结果，原因在于描述不具体。每种导航按名称、触发方式、收起方式、位置四项描述。

**一、位置与布局类**
1. **悬浮吸顶 Floating · Sticky**：浮起的圆角卡，离顶留白带阴影，滚动时固定在顶部 → 「floating 悬浮导航 + sticky 吸顶固定」
2. **侧边栏 Sidebar**：竖排左侧，可折叠为图标。后台、工具站常用 → 「sidebar 侧边栏 + 可折叠 collapsible 成图标」
3. **面包屑 Breadcrumb**：非主菜单，是主导航下一层的路径提示 → 「主导航下加一行 breadcrumb 面包屑」

**二、结构类**
4. **二级下拉 Dropdown**：悬停时子菜单向下展开 → 「hover 展开的二级 dropdown 下拉菜单」
5. **巨型菜单 Mega Menu**：悬停后展开多列面板。电商类网站常用 → 「mega menu 巨型菜单 + 多列分类面板」
6. **汉堡抽屉 Hamburger · Drawer**：点击三条杠图标，菜单从侧边滑出。移动端常见 → 「hamburger 汉堡菜单 + drawer 抽屉侧滑」
7. **全屏遮罩 Full-screen Overlay**：点击后覆盖整屏，菜单居中放大。作品集常用 → 「full-screen overlay 全屏遮罩菜单」

**三、动效与行为类**
8. **锚点导航 Scrollspy**：滚动到某区块时，对应导航项自动高亮。长文档、落地页 → 「scrollspy 锚点导航，滚到哪高亮哪」
9. **滚动收缩 Shrink on Scroll**：顶部透明覆盖大图，下滚后变矮并转为实色 → 「导航顶部透明，下滚变矮变实色 shrink」

## 首屏设计 — 先判断网站类型，再确定重点

首屏的任务是回答用户最关心的问题，不是塞满内容。

| 类型 | 用户想确认的问题 | 首屏应给出的答案 |
|---|---|---|
| 产品介绍类 | 能解决什么问题 | 产品价值 |
| 个人品牌形象类 | 你是谁、擅长什么 | 定位、代表作品和风格 |
| 活动行动召唤类 | 为什么现在参加 | 行动理由 |

个人品牌示例：「为个人设计师作品集页面设计首屏：加入圆形头像、放大代表作品 Banner。」

## 大屏看板 — 3层结构，5种布局

看板的专业程度不取决于图表数量，而取决于信息层级：结果、趋势、原因逐层递进。避免让 AI 生成堆积图表的页面。

- 顶部：**KPI卡**（每张卡只呈现一个指标，标注同比或环比，例如 DAU 28,460 +4.7%）
- 中部：趋势图（反映变化）
- 底部：明细表（定位原因）

**5种大屏布局**：
- **01 中心聚焦 Center Focus**：让观众第一眼看到核心业务（核心地图或态势居中，指标环绕四周）。地图、园区态势、核心设备状态
- **02 上总下分 Summary First**：先给结论，再向下拆解原因。经营复盘、汇报大屏、管理看板
- **03 左右分栏 Overview & Detail**：一侧看整体结果，一侧看原因与明细。区域分析、业务对比、异常诊断
- **04 网格模块 Modular Grid**：同时监控多种状态，保留主次（重点卡片突出）。设备监控、运维中心、综合态势
- **05 流程链路 Process Flow**：沿业务链路横向串联各环节指标，异常环节一眼定位。供应链、工业生产、应急指挥

**Prompt 顺序**：业务关系、布局、视觉风格。仅说"科技感"不够，需说明产品气质、信息密度、明确模式、图形语言四个维度。
顺序示例：「先说清业务关系（这是给管理层看的复盘），再选布局（上总下分），最后定视觉风格（深色底、高对比、克制配色）。」

## 工作流实战 — 先定目标

搭建工作台或工具类页面时，仅说"做个网页"难以得到正确结果。按以下顺序描述：

1. 核心目标：用户打开页面后应能立即完成什么（例如"今天学什么、还要多久、哪些要复习"）
2. 功能清单：逐条列出模块与可交互操作（可编辑、新增、勾选、删除）
3. 交互细节：状态与反馈，参考 `rules.md`

**可直接使用的完整 Prompt 范例**（个人学习工作台）：
「请为我制作一个中文版『个人学习工作台』网页，面向正在备考、学英语、考证或学习新技能的普通用户。
核心目标：用户打开网页后，马上知道今天学什么、还要多久、哪些内容需要复习。
请包含以下功能：
1. 学习日历：可编辑目标名称、考试日期、目标分数和每日学习时长。
2. 今日学习：展示今天的学习任务、预计用时、优先级和完成状态，支持新增、编辑、删除、勾选完成。」

同一思路可替换核心目标与功能清单，用于其他工作台，例如内容排期、销售跟进、项目管理。

## 风格参考图 — 控件样式需一并说明

仅包含色彩与字体的参考图，无法让 AI 确定按钮、输入框、卡片的形式。风格参考需要把控件样式写入 Prompt。

**范例结构**（"苹果液态玻璃风"风格 Prompt 的要素，可直接套用）：
- 主色与底色：主色 #DCD5CC 暖米白，标注具体色值
- 大字排版：Hero 标题的字号层级与字重
- 控件规格：按钮色值（如 #F01701）、圆角大小（如 4px）
- 图标语言：线性或面性、粗细、统一颜色
- 质感关键词：液态玻璃 Liquid Glass，即半透明磨砂加背景折射

生成风格参考图后，再让 AI 按参考图加控件名加交互规则制作页面。工作流为：风格 Prompt、生成参考图、作为附件交给 AI 搭建页面。
