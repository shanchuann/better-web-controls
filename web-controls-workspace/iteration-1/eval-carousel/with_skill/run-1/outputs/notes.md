# 商品图展示区选型笔记 · 陶瓷蓝牙音箱

按 `skills/web-controls/SKILL.md` 工作流：需求类型 = 新增控件 → 路由到 `references/controls.md` → 「轮播 — 7 种玩法 / Tab——图片预览标签」章节。用户原话是"不要左右滑动加三个圆点，要好看的高级浏览方式"——命中 skill 里的典型大坑："做个轮播只会得到左右滑+三个圆点"，必须先报对名字再说细节，不能直接写代码。

|---|---|---|---|---|
| A | **360°旋转展示 360° View** | 按住拖一圈看全角度，松手自动回正；指示器可选 | **电商产品图、硬件展示** | ✅ 完美命中：陶瓷音箱是"造型+釉面"的手作器物，买家最想看的就是各个角度的釉色、形体 |

## 二、最终选择

**主形式：360°旋转展示 360° View（自绘 CSS 3D 圆筒 + 交互加成）**
**辅助形式：图片预览标签 IMAGE PREVIEW TABS（底部缩略图导轨，负责非 360 的场景图/细节图）**

即：360° 旋转做主舞台，其余 4 张（釉面细节 / Hi-Fi 孔阵 / 客厅实景 / 尺寸比例）走缩略图标签导轨——正好是 Apple / B&O 详情页的结构，但形式换了心。

## 三、为什么

1. **内容关系判断**（skill："判断先于选择"）：商品图不是"几张并列的图"，而是"同一器物的多视角 + 多场景"。用户任务有两种：① 验货（看釉面、形体、孔阵）→ 360° 最能胜任；② 看场景（放客厅什么感觉、多大）→ 缩略图标签。轮播的"左右滑"恰恰是两种任务的最低效形态。
2. **skill 原文点实证**：controls.md 里 360° View 的适用场景写的就是"电商产品图、硬件展示"——陶瓷音箱完全命中；而 Accordion 写的是"摄影集、作品集"，气质对但任务错。
3. **商品属性加成**：手作陶瓷 = 卖点全在表面釉色与形体。360° 让"釉里红一圈"在旋转中自己被发现，比贴五张静态图更有"器物感"。
4. **为什么不纯用 E**：纯缩略图标签 = 各大电商默认做法，用户明确说"不要普通的"。所以把它降级为导轨，把交互惊喜留给 360°。

## 四、细节三步落实（skill：形式 → 指示器 → 自动播放）

- **形式**：360° 旋转展示。按住左右拖动看全角度；松手带惯性滑行并自动吸附到最近的 24 个刻面；4 秒无操作进入**缓慢自动旋转**，任何交互立即停止。
- **指示器**：不用圆点。① 底部 5 格缩略图导轨（当前项描边高亮）；② 右下角实时角度读数 "217°"；③ 首次进入时的"↔ 按住拖动"提示胶囊，开始拖拽后淡出。
- **自动播放**：360° 模式闲置 4s 后缓慢自转（约 8°/s），拖动/键盘/切换缩略图即停。这与"品牌官网 Banner 的无条件 autoplay"不同——详情页自动播放必须为验货让路，只作吸引注意的引导。
- **交互加成**：键盘 ←→ 每按一次转 15°；两套釉色（缎白 / 红釉）实时换釉面环带色。

## 五、可直接抄的 Prompt（按 skill 公式组装）

> 做一个电商详情页的 360°旋转展示 360° View + 图片预览标签 IMAGE PREVIEW TABS 组合。**形式**：主舞台为可 360° 拖动旋转的陶瓷圆筒音箱（24 个刻面圓筒 + 前后釉面盖 + 顶盖），按住左右拖动旋转，松手带惯性惯性滑行、自动吸附到最近刻面；**指示器**：不用圆点，底部一行 5 格缩略图标签导轨（360° / 釉面细节 / Hi-Fi 孔阵 / 客厅实景 / 尺寸比例），点击切换，当前项描边高亮；360° 模式右下角显示实时角度读数，首次进入显示"按住拖动"提示胶囊，开始拖后淡出；**自动播放**：360° 闲置 4 秒后缓慢自转，任何交互立即停止。**边界情况**：键盘 ←→ 每按一次转 15°；提供缎白/红釉两种釉色实时切换；移动端硬件不支持拖动时，退化为点击缩略图看静图 + 左右箭头按 15° 步进旋转。

## 六、落地说明

- 单文件 HTML，零外部依赖，音箱本体用 CSS 3D 圆筒自绘（24 刻面 + 前后釉面盖 + 顶盖），细节/场景图用 CSS/SVG 手绘占位——保证任何环境打开都是"成品感"。
- 文件：`carousel.html`，可直接双击打开。
