# notes.md — 陶瓷蓝牙音箱“商品图片展示区”方案记录

任务：为电商详情页做一个**非传统轮播**（不要左右滑动 + 三个圆点）的商品图片浏览区，输出单文件 HTML。

---

## 一、考虑过的候选方案

### 方案 A：3D 环绕拖拽（仿 360° 展示 / drag-to-rotate）
- 思路：连续帧序列，横向拖动模拟把音箱转起来。
- 优点：最有"把玩感"，科技产品常见。
- 缺点：对**陶瓷手作**这个品类气质不符（它更像卖 3C 参数）；且没有真实 360° 素材时，只有 6 个"场景位图"会明显跳帧、穿帮，效果反而廉价。实施风险最高。

### 方案 B：卡片牌堆（拖走顶牌、洗牌到队尾 / fanned deck）
- 思路：图片像一摞拍立得卡片，拖拽顶部的牌飞走，下层自动补位。
- 优点：交互本身很"可晒"，动效有戏剧性。
- 缺点：**信息效率差**——用户看到的是"抽卡游戏"，不是"检查商品"。想回看第 2 张细节必须反复洗；对购物转化帮助小。且拖拽冲突多（旋转飞出 vs 页面滚动）。

### 方案 C：编辑式纵向长卷（scroll-jack 纵向逐屏展示，大字标题 + 全屏图）
- 思路：整页像品牌 lookbook，滚轮逐屏推进图片与故事文案。
- 优点：质感天花板级别，适合品牌向。
- 缺点：在商品详情页里劫持整个滚动是**反购物习惯**的（右侧还有规格/加购要滚动）；实现成"局部 scroll-jack"又容易和页面滚动打架。

### 方案 D：左右布告栏双联动（主图 + 横向 filmstrip 缩略条 + 数字角标）
- 思路：经典 luxury 电商（Aesop / SSENSE 一系）的带状结构。
- 优点：熟悉、稳妥。
- 缺点：太常见，与"普通轮播"的差异不够大，容易做回老路。

### 方案 E（落选但被吸收）：放大镜 hover lens
- 单独作为主交互不够，但"**看细节**"是陶瓷品类刚需，被吸收进最终方案。

---

## 二、最终选择：拱形舞台画廊（Arch Niche Stage）

结构 = **拱形主图舞台 + 竖排拱形缩略图列 + 数字计数器 + 细线进度**，交互 = **拖拽 / 滚轮 / 键盘 / 双击放大**。

选它的理由：

1. **拱形（niche / 壁龛）语言与品类强绑定**：陶瓷 = 窑、龛、器物陈列架。主图做成上圆下方的拱门，缩略图列做成一竖排小龛，页面本身就解释了"这是件器物"——这是轮播和圆点无论如何给不了的表达。
2. **浏览效率不打折**：缩略图列随时可跳任意一张（保留"非线跳转"能力，这点比牌堆 B 强）；拖拽、滚轮 scrub、←→ 键、点缩略图四条路径都能换图。
3. **手势做了"阻尼 + 回弹 + 速度判定"**：拖动时整层带 0.5 倍阻尼位移，松手若超过阈值或甩动速度够快就切换，否则用 `cubic-bezier(.16,1,.3,1)` 弹性归位——手感是"捏着一件东西"，不是"翻一页"。
4. **换图用淡入 + 缓推镜（crossfade + 1.02→1.05 缓慢 scale）**，配合指针视差（±12px 惯性跟随），静图有了呼吸感，又不会像 Ken Burns 那样喧闹。
5. **细节模式替代放大镜**：双击/按钮进入 2.2× 光标跟随平移（带 lerp 插值和边界钳制），滚轮调倍率（1.4–3.6×）——看釉面弦纹、黄铜旋钮这些"文案里吹的点"真有地方看，比 hover lens 更适合触屏。
6. **用计数器 01/06 + 一根细进度线替代三个圆点**：数字大字用衬线体并带向上滚动的小动画，进度线只作方位暗示，不占审美空间。

## 三、被舍弃 / 被吸收的东西

- 吸收自 D：缩略图导航（但从横条改成竖列拱形，与主舞台同构）。
- 吸收自 E：双击细节放大（从鼠标 hover lens 升级为可调倍率的查看模式）。
- 舍弃自动轮播：详情页自动播图非常廉价，浏览节奏交还给用户。
- 舍弃装订刻度点、 dispenser 式大箭头按钮：以缩略列 + 计数器 + 进度线替代。

## 四、实现备注

- **图片**：当前用 `picsum.photos/seed/shanmingN` 的灰度占位图（ grayscale 是刻意的编辑方向，6 张图在暖纸色底上会自动统一气质）。上线时把 `SLIDES` 里 `seed` 换成真实产品图 URL，把 `big()/small()` 改成真实地址即可，数据结构不变。
- 字体走 Google Fonts（Noto Serif SC / Noto Sans SC），断网时回落到系统宋体/黑体，版式不断。
- 全页有 SVG feTurbulence 纸张颗粒层（multiply 混合、5% 不透明度）压住"数码感"。
- 无障碍：缩略图为 button + aria-label/aria-current，文案区 aria-live，Esc 退出放大，`prefers-reduced-motion` 下动画全部关闭。
- 已知取舍：主舞台上的滚轮被劫持用于翻页/调倍率（展示区不是长页面，可接受）；移动端缩略列改为横滑，`touch-action:pan-y` 保证纵向滚页面不被吃掉。
