# broken.html 诊断与修复笔记

Fixed file: `fixed.html`（内容、文案、配色、整体风格与原版一致，仅修 CSS 结构问题）

---

## 问题 1：首屏内容被顶部导航挡住

**病因**
`nav` 是 `position: fixed; height: 64px`，脱离文档流、不占据页面空间；而 `.hero` 直接从页面顶部（y=0）开始布局。结果是 hero 图最上面 64px 被悬浮的半透明导航压在下面，视觉上像"内容钻到导航底下"。

**修复**
给 `.hero` 加 `margin-top: 64px`，为 fixed 导航预留出等高的空间。导航本身保持 fixed + 半透明毛玻璃不变，滚动时内容从其下方穿过的效果也保留。

---

## 问题 2：图片看着是"歪的、偏的"（主要是房型卡片小图）

**病因**
`.room .pic` 是固定高 220px、宽度随卡片的容器，里面的 `img` 用了 `object-fit: contain`。`contain` 的行为是**完整显示图片、按原图比例缩放到刚好塞进容器**，多余部分露出容器的灰底 `#eee`。由于这几张 Unsplash 图的长宽比和 220px 高的宽容器不一致，图片没填满、四周留灰边，且默认居中后看起来偏上/偏小，就像"歪的偏的"。

**修复**
改为 `object-fit: cover; object-position: center;`：图片按比例放大到填满容器，居中裁掉溢出部分。卡片小图由此铺满圆角区域，不再有灰边和错位感。顺手给 img 加了 `display: block`，消除 inline 图片的基线空隙隐患。

---

## 问题 3：首屏大图被拉伸变形

**病因**
`.hero img` 设置了 `width: 100%` 和固定 `height: 380px`，但未设置 `object-fit`。img 的默认 `object-fit` 是 `fill`——**不保比例、强行拉伸到目标尺寸**。原图是宽幅照片，被压扁/拉宽后人物和建筑比例失真，是"图片歪"观感的另一个来源。

**修复**
给 `.hero img` 补上 `object-fit: cover; object-position: center;`：保持图片比例，等比放大填满 1200px 宽 × 380px 高的横幅区域，居中裁切。尺寸、位置均不变，只是不再变形。

---

## 问题 4：有一块"怎么都去不掉"的间距 / 内容整体偏右

**病因**
内容被包在一个 `.old-copy` 的 div 里，该类是从旧模板复制时残留的样式：

```css
.old-copy { margin-left: 40px; margin-top: 24px; }
```

它让整个内容区右侧多出 40px 空白（相对居中的 `.content` 又向右偏移）、顶部多出 24px 空白。因为写在独立的选择器里，改 section/p 的 margin 都动不了它，所以"怎么都去不掉"。

**修复**
删除 `.old-copy` 的样式及这层无用的包裹 div，`<section>` 直接放在 `.content` 内。内容由 `.content` 自身的 `max-width: 960px; margin: 0 auto` 正确居中，多余的左偏移和顶部间距消失。

---

## 问题 5（顺带）：房型卡片在 960px 容器里轻微溢出

**病因**
`.room` 固定 `width: 300px`，三张卡 + 2 × 24px gap = 948px；而 `.content` 内容区实际宽度是 960 − 40（左右 padding）= 920px。卡片总宽超出容器 28px，flex 默认收缩会把卡片压扁，圆角和内边距看起来被挤压。

**修复**
把 `.room` 的固定宽度改为 `flex: 1; min-width: 0`，三卡在容器内等分空间（每张约 291px，与原 300px 观感几乎一致），窄屏时也会自动等分，不再溢出。
