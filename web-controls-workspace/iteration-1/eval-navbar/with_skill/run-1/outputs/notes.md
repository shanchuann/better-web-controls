# 选型说明：个人作品集导航栏 + 简单首屏

依据 `skills/web-controls/SKILL.md` 工作流：需求路由到 `references/layouts.md`（导航/首屏/布局），按钮选型参考 `references/controls.md`，"高级感"这类模糊词按 `references/rules.md` 的"设计黑话 7 词"翻译。以下按"先判断、再选型、后说理由"的顺序记录。

## 一、需求翻译："高级感"不是一句话，是七个词

用户原话"有高级感"= 十次八九次做不对的模糊需求。拆成可执行的词（来自 rules.md 设计黑话）：

| 黑话词 | 在本页的落实 |
|---|---|
| **留白 Whitespace** | 首屏只放一句主标题 + 两个按钮；区块上下留 130px |
| **栅格 Grid** | 全页统一 `min(1180px, 90%)` 内容宽度，卡片间距一致 |
| **卡片 + 微交互 Card** | 作品卡悬停上浮 6px + 边框亮起，不翻不闪 |
| **液态玻璃 Liquid Glass** | 导航浮岛用半透明磨砂 + 背景模糊 |
| **瀑布流 Masonry** | 作品区不等高卡片 |
| 内敛视觉语言 | 近黑墨色 + 米白纸感 + **唯一的强调色**香槟金；衬线大标题（Playfair Display）× 无衬线正文 |

## 二、导航栏选型：9 种里挑了哪种

候选（layouts.md"导航 9 种"）：

1. **悬浮吸顶 Floating · Sticky** ✅ 选定 —— 作品集页面短、内容少，导航本身就该是页面上唯一精致的"物件"；浮起的圆角卡离顶留白、自带阴影，高级感天然强。
2. **全屏遮罩 Full-screen Overlay** —— 作品集常见，仪式感强；但桌面端一级菜单仅 3 项，为 3 个链接盖整屏太重，降级给移动端用。
3. **侧边栏 Sidebar** —— 出局：偏后台/工具站，个人品牌页用会显得像管理系统。

选定方案的实际组装（按公式：名字 + 触发 + 收起 + 位置）：

- **悬浮吸顶 Floating · Sticky**：圆角胶囊浮岛，fixed 顶部留白 18px，初始半透明玻璃；下滚后变矮变实色 + 投影（叠加了 **滚动收缩 Shrink on Scroll**）。
- **锚点导航 Scrollspy**：滚到"作品 / 关于 / 联系"哪个区块，对应导航项金色下划线自动高亮。
- **移动端汉堡 + 全屏遮罩 Full-screen Overlay**：点三条杠打开整屏菜单，菜单项逐个上浮，Esc/✕ 关闭。
- 按钮三步公式（controls.md）：导航右侧为**线状胶囊按钮 OUTLINE PILL**"联系我"——因为全页**实心主按钮只能给一个**（首屏 CTA）。

## 三、首屏选型：先判网站类型，再决定突出什么

layouts.md"首屏设计"判断：个人作品集 = **个人品牌形象类**，首屏要回答的是"**你是谁、擅长什么**"，不是塞功能。

候选：

1. **全屏沉浸式 Full-screen** ✅ 选定（简化版）：一整屏大视觉 + 一句主标题，个人品牌站最直接。
2. **落地页布局 Landing Page**：偏产品转化节奏，作品集不需要功能介绍接龙。
3. 左右分栏编辑式：也可，但信息量小时画面比不上满屏 Banner 有分量。

落实为 skill 给出的个人品牌配方（圆形头像 + 放大代表作品 Banner）：

- 右半幅一张**放大的代表作品 Banner**，用渐变蒙版向左融进墨色，不设边框卡片；
- 大号衬线主标题"为好产品，做有分量的设计。"（讲能力，不是自我介绍）；
- **圆形头像 + 姓名与职能**一行，回答"你是谁"；
- 底部一行 meta：年份跨度 / 滚动提示 /"目前可接新项目"状态点。
- CTA 组合：**面状按钮 SOLID**"查看作品 ↓"（全页唯一实心）+ **线状按钮 OUTLINE**"与我聊聊"；文字动词开头、说结果。

## 四、其他按 skill 落实的细节

- **进场分批渐现**：`.reveal` 元素进入视口上浮显现，并尊重 `prefers-reduced-motion`——等待体验里"结构先出现"的原则，用在首屏。
- **图片加载失败兜底**：头像 `onerror` 隐藏，避免破图破坏高级感。
- 全部远程图片来自 Unsplash；字体走 Google Fonts，断网时回退系统中文字体，文件仍可直接双击打开。
- 主色只用在：导航高亮、 kicker、数字、斜体强调、实心按钮 hover——**强调色只服务一个层级**。

## 五、可直接复用的 Prompt（slot-by-slot）

> 给我的个人作品集网站做导航栏与首屏。导航用**悬浮吸顶 Floating Sticky**：离顶留白的圆角玻璃浮岛，fixed 顶部；下滚后变矮变实色加投影（Shrink on Scroll）；滚动到页面区块时对应导航项自动高亮（Scrollspy）；移动端用**汉堡菜单 + 全屏遮罩 Full-screen Overlay**，菜单项逐个浮现。右侧放线状胶囊"联系我"。
> 首屏用**全屏沉浸式**：深色墨底，右半幅放大代表作品图向左渐隐；主文字用衬线大标题写清"我是谁、擅长什么"；加圆形头像一行；底部一条 meta 信息线。放**一个实心主按钮"查看作品"+ 一个线状次按钮"与我聊聊"**。
> 风格用设计黑话：大留白、统一栅格、半透明液态玻璃、单一香槟金强调色、衬线 × 无衬线搭配，悬停只做轻微上浮。
