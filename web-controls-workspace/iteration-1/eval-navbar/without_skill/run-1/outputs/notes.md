# 说明 — 个人作品集导航栏 + 首屏

## 交付物
- `index.html`：单文件 HTML（内嵌 CSS + 少量原生 JS，无任何依赖库），双击即可在浏览器打开。
- 远程图片仅一处：首屏背景图来自 Unsplash，联网时会加载；断网时不影响布局与可用性。

## 设计思路：高级感从何而来
1. **克制的深色配色**：近黑背景 `#111112` + 暖白文字 + 单一金色点缀 `#c8a96a`。全站只有一个强调色，避免花哨。
2. **字体气质对比**：标题用衬线体（Georgia / 宋体栈）营造编辑感，正文用无衬线系统字体保证可读性，大标题配斜体强调词。
3. **大量留白 + 精确小细节**：小号大写字母配超宽字距（eyebrow、meta 信息条）、细分隔线、顶部的短横线装饰。

## 功能点
- 导航栏：
  - 首页时全透明，与首屏融为一体；滚动超过 24px 后变为深色毛玻璃（`backdrop-filter`），并显示底部分隔线。
  - 链接 hover 有从左划入的下划线动效；"开始合作"为圆角描边按钮，hover 反色填充。
  - 移动端（≤760px）自动切换为汉堡菜单，展开为下拉面板，点击链接后自动收起。
- 首屏：
  - 全屏高度， UneAnne 摄影图 + 深色渐变过滤保证文字对比度，叠加一层 SVG 噪点纹理（data URI，无额外请求）增加质感。
  - 入场动效：eyebrow → 标题 → 副文案 → 按钮依次上浮淡入（纯 CSS animation + delay）。
  - 底部信息条：版权 / 向下滚动的呼吸线条 / "Currently Available"状态。

## 可自定义的基本位置
- 品牌名：`.nav__logo` 中的 `LIN CHE`。
- 强调色：`:root` 中的 `--accent`。
- 背景图：`.hero__bg` 的 `url(...)`。
- 标题与副文案：`<h1>` 与 `<p class="rise d3">`。

## 已知取舍
- 导航下方其它版块（作品、关于等）为留白锚点，本任务只要求导航 + 首屏，未搭建后续内容。
- 噪点纹理与渐变叠在低性能设备上开销极小，未做额外降级。
