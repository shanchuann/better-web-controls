# 实现说明 — 月度经营报告页面

**产出文件**：`page.html`（单文件，无外部依赖，可直接双击打开）

## 页面结构（自上而下）
1. **报告头部** — 标题、环比 +12% 徽章、报告周期与出品方。
2. **KPI 卡片区（4 张）** — 本月营收 480 万（核心卡，深蓝渐变强调）、近 12 个月累计、整体付费转化率、渠道综合流失率，各带环比箭头（涨绿降红）。
3. **近 12 个月营收走势** — 纯 SVG 折线图：面积填充 + 数据点 + 每点数值标签 + 12 期线性趋势虚线（JS 内做最小二乘拟合），含 Y 轴网格刻度。
4. **各产品线营收占比** — SVG 环形图（stroke-dasharray 分段），中心显示总额，配图例 + 横向占比进度条双呈现。
5. **各渠道转化/流失** — CSS 漏斗条（访问→注册→试用→付费，标注各环节转化率与流失说明）+ 渠道明细表格（访客量、付费转化率、流失率、流失主环节、风险标签）。
6. **管理层要点** — 蓝底结论卡，给出目标完成率、结构变化、风险与机会点。

## 数据设定
- 倒数第二月设为 429 万，使 480 / 429 ≈ +12%，与 KPI 自洽；近 12 月累计 4,656 万。
- 产品线四条（智能硬件 182 / SaaS 130 / 企业服务 101 / 增值服务 67），合计恰为 480 万。
- 渠道四条（付费投放/自然流量/合作伙伴/私域），转化率与漏斗口径一致，并给出风险分级。

## 技术要点
- 图表全部为内嵌 SVG/CSS 手绘，JS 仅负责根据数据数组生成坐标，改数据即改图表。
- 无任何 CDN、字体、图片外链，离线可开；含 `@media print` 打印优化与窄屏（<860px）响应式降级。
- 占比条与漏斗有进场宽度动画（width transition），CSS 变量统一配色。
