# 实现说明

## 需求
订单管理页面中：① 选择订单负责人的下拉框；② 按负责人筛选订单列表。单文件 HTML，中文界面，可直接双击打开。

## 实现要点

- **自定义下拉框（Dropdown）**：未用原生 `<select>`，而是用 button + 弹层实现，支持头像、姓名、"N 单"计数、选中态（✓ 高亮）和内置搜索框（负责人较多时可快速定位）。
- **筛选逻辑**：下拉选中某负责人后，订单表格即时过滤；"全部负责人" 选项恢复全量。负责人筛选可与关键词搜索叠加（AND 关系）。
- **键盘可达性**：下拉支持 ↑/↓ 移动高亮、Enter 选中、Esc 关闭；带 `aria-haspopup` / `aria-expanded` / `role="listbox"` / `role="option"` 等无障碍属性。
- **筛选反馈**：工具栏下方有可单独删除的筛选标签（chip），支持"清空全部"和"重置筛选"；无结果时显示空状态；操作通过 toast 提示。
- **数据与视觉**：内置 12 条模拟订单 + 6 位负责人，纯前端本地渲染；仿企业后台风格（蓝主色、斑马表格、状态徽标），无任何外部依赖。
