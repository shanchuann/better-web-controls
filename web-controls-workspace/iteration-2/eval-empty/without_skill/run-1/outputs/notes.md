# 实现说明：CRM 客户列表两种空状态

产出：`page.html`（单文件，内嵌 CSS/JS，中文界面，双击即可打开，无任何外部依赖）。

## 两种空状态的区分

同一列表区域按条件互斥切换三种视图：

1. **新用户首次进入（无客户）**：插画 + 标题“还没有客户”+ 说明文案 + 双主行动（**新建第一个客户** / **批量导入客户**）+ 三步上手引导卡（新建/导入 → 分配归属人 → 记录跟进）+ 次级链接“3 分钟上手指南”。重点是降低空白感、给出下一步。
2. **搜索/筛选无结果**：插画（放大镜 + 空文档）+ 标题“没有找到匹配的客户”+ 动态回显当前搜索词与筛选条件（生成可单独移除的 chips，点 ✕ 即移除该条件）+ 主行动“清空搜索和筛选条件”+ 次行动“新建客户”+ 三条排查建议（检查拼写 / 缩短关键词 / 放宽条件）。重点是告诉用户"为什么空"和"怎么出去"。

## 页面与交互

- 完整 CRM 外壳：侧边栏、面包屑顶栏（批量导入 / 新建客户）、工具栏（关键词搜索 + 归属人 / 状态 / 标签三个筛选下拉）、数据表格。
- 内置 6 条模拟客户数据，搜索与筛选**真实生效**：有匹配则显示表格，无匹配自动进入空状态 B；首次进入态下用户开始搜索/筛选会自然切到实时模式。
- 顶部一个标注为“演示开关（实际产品中不存在）”的分段控件，可一键预览三种场景（首次进入 / 无结果 / 有数据），便于验收。
- 清空入口有两处：工具栏“清空筛选”（有条件时才出现）与空状态内的主按钮。

## 细节

- 设计 token 化（颜色 / 圆角 / 阴影），插画为内嵌 SVG，状态用彩色 pill、标签用 chip。
- 无结果空状态用 `role="status" aria-live="polite"` 播报；移除条件按钮带 aria-label；`focus-visible` 焦点样式。
- 响应式：窄屏隐藏侧边栏、收纳次要列。
- 演示按钮（新建/导入/指南）点击弹 toast，避免死链接感。
