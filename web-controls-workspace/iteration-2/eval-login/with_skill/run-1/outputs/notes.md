# 选型笔记：SaaS 产品登录页（陶橙品牌色）

## 1. 需求识别

用户原文："帮我们 SaaS 产品做个登录页，要高级一点，品牌色是陶橙色。"

- 需求类型：**页面布局与结构（登录页）**，参考 `layouts.md` 登录页一节；同时涉及表单控件（`controls.md`）与校验/反馈时机（`rules.md`）。
- 模糊点判定："高级一点"属于风格性模糊表述，仅凭它 AI 只能猜测（SKILL.md 使用注意第 1 条）。layouts.md 明确指出："帮我做个高级的登录页"这类表述会让 AI 自行猜测，应直接指明样式名称。因此**先列候选并给出判断依据，再选型实现**。
- 已知信息：产品形态为 SaaS；品牌色为陶橙（Terracotta Orange，取 #E2725B 系）；输出单文件 HTML；页面语言中文。
- 未知信息（本评测无用户可确认，按最常见场景假设并在笔记中声明）：是否多角色登录（个人/企业双端）、是否需要验证码/手机号登录、品牌侧展示什么内容。

## 2. 候选方案（来自 layouts.md 登录页 5 种，列出 3 个主要候选）

| 候选 | 名称 | 适用场景 | 与本需求的匹配 | 风险 |
|---|---|---|---|---|
| A | **居中卡片式 Centered Card** | 稳妥通用，多数工具与 SaaS 产品的常规选择 | 实现稳妥，但形态最常见，"高级一点"的诉求下容易落入千篇一律的结果 | 无差异化，难以承载品牌展示 |
| B | **Split Screen 左右分屏式** | 品牌展示与登录并存 | SaaS 登录页典型做法：左侧讲品牌（价值主张、信任元素），右侧放无卡片表单；陶橙品牌色可大面积用于品牌侧，"高级感"由排版与留白建立 | 需处理移动端折叠（参考文件已给出"移动端折叠单栏布局"的规则） |
| C | **Immersive Background 沉浸背景式** | 表单融入有色背景，排版与分隔线建立层级 | 视觉冲击强，但陶橙为高饱和暖色，全屏铺满时文字可读性依赖深色遮罩，表单可用性风险较高 | 可读性与对比度把控难度大 |

（另两种"多角色 Tab 登录""分步登录"分别针对双端身份切换与验证步骤多的场景；用户未提及多角色与多步验证，信息不足以支持，不列为候选，假设单表单登录。）

## 3. 判断依据

1. **登录页描述三要素：布局、背景、卡片**（layouts.md）——需求中三者均未说明，需由选型补齐：
   - 布局：SaaS 产品登录是"品牌信任 + 转化"的复合场景，左品牌右表单的分屏结构同时服务两个目标；
   - 背景：品牌色陶橙大面积铺在品牌侧而非整页，规避沉浸式的可读性风险；
   - 卡片：右侧采用**无卡片表单**（表单直接叠放在浅色底上，用留白与分隔线分区），避免"卡片套卡片"的臃肿感，也符合 rules.md"卡片不是默认答案"的分组判断（登录是单一填写任务，用留白分区即可）。
2. **强度匹配与时机规则**（rules.md）：
   - 校验时机：登录表单字段少且相互独立 → **失焦校验 Blur Validation**，错误提示显示在输入框下方；提交时再统一校验兜底。
   - 等待体验：点击登录后的接口等待时长不可预知 → **不确定进度 Indeterminate**，按钮内用循环同步 spinner，不编造百分比。
   - 提示等级：登录成功/失败属于轻量结果反馈 → **轻提示 Toast**，右上角出现数秒自动消失，不打断操作。
3. **按钮三步公式**（controls.md：形态、样式、文字）：
   - 主操作：**面状按钮 SOLID BUTTON + 全宽 FULL-WIDTH**，陶橙实心填充，文字"登 录"，全页仅此一个主色按钮；
   - 次操作：**文字按钮 TEXT BUTTON**"忘记密码"（无边框无底色，不与主按钮争夺注意力）；
   - 第三方登录：**线状按钮 OUTLINE BUTTON**（仅一圈描边），不与主操作争夺视觉权重。
4. **"高级感"的落地手段**（rules.md 设计术语）：留白 Whitespace + 统一栅格 + 品牌侧大字排版；陶橙仅用于品牌面与主按钮两处，避免高饱和色泛滥。

## 4. 最终选型

**Split Screen 左右分屏式登录页（6:4）**，移动端折叠为单栏（品牌侧收为一窄条头部）。

最终 Prompt 规格（按"布局类型、背景、卡片、气质"顺序组装）：

> 做一个 Split Screen 左右分屏式登录页，左 60% 右 40%，移动端折叠单栏。左侧为陶橙（#E2725B → #C2543A 渐变）品牌面板：品牌标识、大字价值主张、三条信任元素，深色暖棕文字保证对比度；右侧为暖白底无卡片表单：字段标签置于输入框上方，邮箱与密码失焦校验、错误提示显示在输入框下方，密码支持显隐切换，"忘记密码"为文字按钮，"登 录"为陶橙实心全宽面状按钮（等待时按钮内显示循环 spinner，不显示虚假百分比），第三方登录为两枚线状按钮；提交成功用右上角轻提示 Toast，数秒自动消失。整体气质：留白充分、栅格统一、暖色现代 SaaS 风。

## 5. 假设声明（因无用户确认环节）

- 假设单角色登录（不含个人/企业 Tab 切换）；若实际为双端产品，可升级为 Role-based Tabs 方案。
- 假设账号为"邮箱 + 密码"登录，另附第三方登录入口。
- 登录为演示交互：前端模拟校验与成功反馈，不对接真实接口。
