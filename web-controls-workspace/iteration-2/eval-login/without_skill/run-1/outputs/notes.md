# 实现说明：SaaS 登录页（陶橙品牌色）

**产出**：`page.html`（单文件，内嵌 CSS/JS，无外部 JS 依赖，双击即可打开；仅 Google Fonts 为可选增强，离线时自动降级到系统中文字体）

## 设计方向
- **定位**：面向 B 端 SaaS 的"高级感"登录页，采用左右分栏——左侧为品牌叙事画布，右侧为功能表单区，是成熟 SaaS（Linear、Notion 类）的经典构图。
- **品牌色**：陶橙 `#D96A33`（主）+ 深陶 `#B94F1F`（按压/强调）+ 浅陶 `#F3C9AE`（点缀），辅以暖调米纸底 `#FAF5EF` 与暖黑 `#2B211B`，整体暖陶土色系，避免蓝紫渐变的"AI 模板感"。
- **品牌区视觉**：深暖底色上用两个带不规则圆角的大尺寸径向渐变"陶土形体"做缓慢漂移动画（尊重 `prefers-reduced-motion`），配合衬线标题（Noto Serif SC）、数据指标条（3,200+ 团队 / 99.98% 可用性）与客户证言，营造质感与信任感。

## 功能与交互（纯原生 JS）
- 邮箱/密码**失焦校验 + 输入实时纠错**，成功/错误状态各有图标与文案，错误时自动聚焦首个出错字段。
- 密码**可见性切换**（带 `aria-pressed` 与图标切换）。
- 自定义复选框"记住我"、忘记密码、注册引导链接。
- 第三方登录入口：微信 / 飞书 / 企业 SSO（品牌图标 + 占位 toast 反馈）。
- 提交按钮：loading 转圈 → 模拟成功 → 底部 toast 提示，按钮有 hover 抬升与阴影层次。
- 分层入场动画（staggered rise）。

## 可访问性与细节
- 焦点环统一使用陶橙 `:focus-visible`，复选框/眼睛按钮均有键盘焦点样式。
- toast 使用 `role="status"` + `aria-live="polite"`；品牌区装饰元素 `aria-hidden`。
- ≤960px 时收起品牌区，单栏表单自适应移动端。

## 占位说明
提交为前端模拟（无后端），SSO 与链接为占位，接入真实接口时替换 `setTimeout` 逻辑即可。
