# 实现说明

## 需求
设置页面点击“保存”后给出反馈，只提示"保存成功"，且不打断用户操作。产出为单文件 HTML（双击即可打开，无任何外部依赖）。

## 方案：顶部 Toast 轻提示
采用**非模态 Toast**而非 alert/confirm/模态框，原因是模态反馈需要用户点击确认才能继续，会打断操作流；Toast 出现几秒后自动消失，用户可继续编辑表单。

## 关键实现细节
- **位置**：`position: fixed`，固定在视口顶部居中（`top: 24px`），不覆盖表单区域，不随滚动移动。
- **不拦截操作**：`pointer-events: none`，Toast 即使出现也绝不会挡住下方元素的点击。
- **入场/退场动画**：通过 `opacity + transform` 的 0.25s 过渡实现淡入下滑效果；尊重 `prefers-reduced-motion`，减弱动效偏好时关闭过渡。
- **自动消失**：2 秒后自动隐藏，无需用户手动关闭。
- **可访问性**：使用 `role="status"` + `aria-live="polite"`，屏幕阅读器可在不打断的前提下播报"保存成功"；图标加 `aria-hidden`。
- **连续保存**：每次触发前 `clearTimeout` 上一次的隐藏定时器，避免快速多次点击时 Toast 闪烁或提前消失。
- **防重复提交**：保存期间按钮置 `disabled` 并显示"保存中…"，完成后恢复并弹 Toast。
- **轻量校验**：昵称为空时同样用 Toast 提示"昵称不能为空"（复用同一提示机制，风格统一），并聚焦输入框。

## 界面
中文界面，包含昵称、邮箱、界面语言、邮件通知开关等常见设置项，视觉采用简洁的卡片式布局。
