# 选型笔记 — 电商商品图展示区（陶瓷蓝牙音箱）

交付物：`page.html`（完整单文件 HTML，中文界面，可直接双击打开）、本笔记 `notes.md`。
参考依据：`SKILL.md` 工作流 + `references/controls.md`（"轮播 7 种玩法""Tab 标签页""弹窗四要素"）+ `references/fixes.md`。

## 1. 需求转写

原文："做一个电商商品详情页的图片展示区，商品是一款陶瓷蓝牙音箱。我不要那种普通左右滑动加三个圆点的轮播，要好看一点的高级浏览方式。"

参照 `controls.md` 的提示——"说'做个轮播'通常得到左右滑动加三个圆点"——用户已经感知并排除了默认形态。模糊点是"高级一点"：按本技能"用户需求模糊时，先给出判断问题或候选方案，不直接编写代码"的要求，先做判断与候选对比（本任务是评测执行，无法反问，故将判断依据写入本笔记后落选型结论）。

## 2. 判断先于选择

- 场景：电商商品详情页图区（PDP）。用户目的不是"逛内容"，而是**为购买决策评估产品**：看清楚釉面、织物声带、接口、真实比例。
- 内容类型：硬件实体。控件手册中 360° View 一条明确标注适用"电商产品图、硬件展示"——陶瓷音箱造型整体圆润独立，正面/顶面/背面工艺有差异，存在"全角度"的价值。
- 排除项（用户明示）：走马灯 + 圆点指示器（Carousel with dots）。
- 关键判断问题（若可反问用户将确认这三条）：
  1. 浏览目的是评估细节还是氛围？→ 细节为主（购买决策）。
  2. 商品是否存在全角度观察价值？→ 存在（陶瓷音箱是独立立体实体，工艺分布在各面）。
  3. 移动端占比？→ 电商详情页移动端占比高，交互必须触屏可用（悬停类方案降权）。

## 3. 候选对比

| 候选 | 形式 | 与本场景的匹配 | 结论 |
|---|---|---|---|
| 图片预览标签 IMAGE PREVIEW TABS | 缩略图切换主图，大图与标注随选中切换 | 电商 PDP 的成熟标准（对照手册场景标注"商品展示"），信息密度友好；但形式常规，单独使用只是"没变丑"，不满足"高级"诉求 | 保留为基底 |
| 360°旋转展示 360° VIEW | 按住拖动查看全角度 | 手册原文"适合电商产品图、硬件展示"，且天然是"不左右滑、无圆点"的高级浏览形式；触屏原生可用 | **主交互** |
| 手风琴画廊 ACCORDION | 一排图只露一条边，指向哪张展开哪张 | 视觉花哨，但横向空间被缩略列吃掉，适宜摄影集/作品集；移动端悬停不存在 | 不选 |
| 翻页式 PAGE FLIP | 3D 翻面带卷边 | 画册感强，但翻页打断"快速对比各面细节"的购买决策路径 | 不选 |

## 4. 最终选型与理由

**混合画廊：360° 旋转展示 × 图片预览标签（360° TURNTABLE × IMAGE PREVIEW TABS）**

- 360° 旋转视图作为缩略图轨道上的**第一个视图**，与其余 4 个精修平面视图（正面 / 顶面特写 / 背面接口 / 场景图）并列，点缩略图切换主图。
- 指示器＝缩略图轨道本身（选中态黄铜描边环），**不是圆点、不是箭头翻页**，直接满足用户的排除性要求。
- 理由：360° 提供"上手把玩实体的高级感"，图片预览标签保证电商购物的信息效率与可预期切换路径；两者互补而不互相取代。
- 实现形态：主图区用 Canvas 程序化渲染机身（织物声带织纹、拾音孔、背面接口均以方位角参数绘出，任意角度连续转动，不是逐帧假 3D），静态视图为内嵌 SVG（离线可用、无外部请求）。

## 5. 操作规则（按 Prompt 三要素顺序整理，可直接复用为 Prompt）

"做一个 360° 旋转展示 × 图片预览标签的商品图 Gallery：5 个视图可切换；360° 视图按住主图左右拖动旋转，支持触屏与鼠标，松手后自然惯性衰减，闲置 2.5 秒恢复缓慢怠速自转，提供'回正'按钮回到正面；静态视图点缩略图即切换，大图区随选中项切换标注；键盘 ← → 切换视图；放大镜按钮打开灯箱 Modal：静态图支持滚轮缩放、拖动平移、双击复位，Esc / × / 点背景关闭，打开时锁定页面滚动并管理焦点；移动端缩略图移到主图下方横排，可点击区域不小于 44px，拖动区 touch-action 禁止误滚动页面；prefers-reduced-motion 下停用自转与惯性。"

**轮播细节三要素（手册要求）对照落实**：
- 形式：360° 旋转 + 缩略图切换主图混合式。
- 指示器：缩略图轨道（选中高亮环），非三个圆点。
- 自动播放：仅 360° 视图怠速自转（交互即停、闲置恢复）；静态视图不自动播放。

## 6. 与参考模板的一处偏离（声明）

`controls.md` 的 360° View 模板句是"松手自动回正"。本交付改为：**松手后惯性滑行自然停止，闲置 2.5 秒后缓慢自转，另设"回正"按钮**。理由（强度匹配原则）：商品查看流程需要停在侧面细节上对照价格与规格，强制回正会在用户正观察背板接口时打断目标；"回正"作为用户主动的轻量操作保留该语义。此取舍已在本笔记中留痕，便于复核。

## 8. 已知边界与后续可扩展

- 360° 为参数化程序渲染（程序化画布），与静态精修图的写实程度有差异；实际接入商拍图时，把 Canvas 视图替换为逐帧序列图（多帧 turntable，换图轨迹即可复用现有拖动/惯性逻辑）。
- 场景图为同一设计语言的插画式渲染，正式上线替换为实拍图即可，交互不变。
