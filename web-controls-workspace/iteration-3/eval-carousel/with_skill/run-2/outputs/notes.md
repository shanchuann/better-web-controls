# 选型笔记 —— 陶瓷蓝牙音箱 · 商品详情页图片展示区

需求原文："做一个电商商品详情页的图片展示区，商品是一款陶瓷蓝牙音箱。我不要那种普通左右滑动加三个圆点的轮播，要好看一点的高级浏览方式。"

## 1. 需求识别与判断

- 需求类型：**新增控件**（电商详情页的图片浏览控件）。依据工作流查阅 `references/controls.md` 的“图片预览标签”与“轮播 — 7 种玩法”两节；桌面悬停与移动端降级规则参考 `references/rules.md`（悬停交互在触屏需改为点击/滑动、多栏折叠为单栏、触控目标 ≥ 44px）。
- 内容判断：这是**研究型浏览**，不是宣传型浏览。商品详情页的看点不是第 1 张主图触达多少人，而是用户能否把 6 张图（正面 / 侧面 / 顶部 / 细节 / 配色 / 场景）逐张看清楚——确定要看哪张、随意来回切、放大看釉面。
- 明确排除项：用户点名排除"普通左右滑动 + 三个圆点"的默认轮播，即排除了仅有 Fade/Slide 动画、圆点指示器、自动播放三件套的通用 Carousel。

## 2. 候选对比（controls.md 出处标注）

| 候选 | 形式 | 优势 | 劣势（对本需求） | 出处 |
|---|---|---|---|---|
| A. 图片预览标签 IMAGE PREVIEW TABS | 缩略图列表 + 主图跟随切换，所有入口同时可见 | 目标即"逐张细看"：缩略图本身就当导航和状态指示，第 4 张细节图又一目了然——不用一个一个翻到第几页 | 形式偏常规，需要靠切换动效与放大能力做出高级感 | controls.md“Tab 标签页 — 6 种” |
| B. 360° 旋转展示 360° VIEW | 按住拖动查看全角度 | 名单里明确写着"电商产品图、硬件展示" | 需要几十帧连续角度素材，单文件 6 张图撑不起来；且只能看整体，看不清釉面斑点、旋钮齿纹等细节，与"研究材质"的目的错位 | controls.md“轮播 — 7 种玩法”第 6 条 |
| C. 3D 旋转木马 3D CAROUSEL | 中间大、两侧小、带透视 | 橱窗感、视觉冲击强 | 两侧图被透视压缩、点击目标小，不适合"逐张研究"式浏览；更适合品牌官网橱窗与作品集 | controls.md“轮播 — 7 种玩法”第 2 条 |
| D. 手风琴画廊 ACCORDION GALLERY | 一排图各露一条边，指向展开 | 形式感强 | 展开时单图比例不稳定，构图发挥空间受限；横向条形更适合摄影集 | controls.md“轮播 — 7 种玩法”第 5 条 |

## 3. 判断依据

1. 浏览意图是"看细节、来回切"：缩略图常驻可见比"一页一页点"更高效 → 候选 A 的形式天然匹配。
2. 6 张图各有叙事重心（结构 / 材质 / 配色 / 场景），比例稳定才能逐张胜任 → 排除 C、D 的形变卡位。
3. 素材现实约束：单文件、无外链，6 张静态图 → 排除 B（需连续帧序列）。
4. "高级感"不应来自动画噱头，而来自浏览能力的升级：**灯箱大图 + 悬停局部放大 + 分数式计数**。这正是 controls.md 对该控件的既定用法："每个标签用缩略图+文字标题；点击标签时，上方大图与文案随选中项一起切换"。
5. 强度匹配：看图是低风险浏览行为，不需要任何打断式交互；**不设自动播放**（用户在研究商品，自动切走会打断视线）。

## 4. 最终选型

以 **图片预览标签 IMAGE PREVIEW TABS** 为主体，叠加增强："做一个图片预览标签：缩略图列在左（6 张，悬停浮现标题，选中项整列不透明并加陶土色高亮边），上部为主图舞台；点击缩略图时主图以交叉淡入 Fade 切入；指示器为分数式计数（01 / 06）+ 缩略图高亮，不用三个圆点；不自动播放；点击主图打开全屏灯箱 Lightbox，屏幕内可 ← → 切换、Esc 关闭；桌面端悬停主图局部放大跟随鼠标，移动端缩略图改为底部横排、主图支持左右滑动切换。"

组合依据：淡入式 Fade 取自"轮播 7 种玩法"第 1 条（切换柔和，适合品牌级图），喜欢从左列排到下一张的资源？"分数式计数（01 / 06）+ 不自动播放"锁定"无圆点无轮播"的排除项；灯箱与悬停放大把"看细节"做到位——高级感来自产品级的浏览能力，而非装饰。

## 5. 验收要点

- [ ] 6 张缩略图全部可见即全部可选，选中态清晰（非圆点）
- [ ] 主图切换为交叉淡入，无跳白；每图配说明文案
- [ ] ←/→ 键切换、灯箱打开后 Esc 关闭
- [ ] 桌面悬停放大跟随光标；移动端缩略图收底部横排，滑动可切换
- [ ] 不自动播放
