# 选型笔记 —— 电商商品详情页图片展示区（陶瓷蓝牙音箱）

## 一、需求转写

原文："做一个电商商品详情页的图片展示区，商品是一款陶瓷蓝牙音箱。我不要那种普通左右滑动加三个圆点的轮播，要好看一点的高级浏览方式。"

问题类型：新增控件。查阅 `references/controls.md` 的两节：
- "轮播 — 7 种玩法"（AI 默认只会"左右滑加三个圆点"，与用户明确排除的形式一致）
- "Tab 标签页 — 图片预览标签 IMAGE PREVIEW TABS：缩略图切换主图；作品集、空间案例、**商品展示**"

## 二、候选对比（轮播 7 种中的 3 个 + 1 个辅助控件）

| 候选 | 形式 | 参考文件标注的适用场景 | 对本需求的契合度 |
|---|---|---|---|
| 360°旋转展示 360° View | 按住拖动查看全角度，松手自动回正 | **电商产品图、硬件展示** | ★★★ 蓝牙音箱是硬件单品，用户最想看的就是正面/背面/侧面细节，交互参与感强、显"高级" |
| 手风琴画廊 Accordion | 一排图只露出一条边，指向哪张展开哪张 | 摄影集、作品集 | ★★ 视觉漂亮但偏"看图集"，不适合单品多角度对比；悬停触发在移动端失效 |
| 3D旋转木马 3D Carousel | 中间大、两侧小、带透视 | 作品集橱窗 | ★★ 橱窗感好，但单品场景下两侧的"别的图"意义弱，且本质仍是左右轮播，接近用户排除的形式 |
| 卡片堆叠 Card Stack | 上面一张滑走露出下一张 | 商品推荐、内容卡片流 | ★ 偏推荐流，不是单品详情的主视角 |
| 图片预览标签 IMAGE PREVIEW TABS | 缩略图切换主图 | 商品展示 | ★★★ 作为辅助控件承载非 360 的视图（细节图、场景图、配色），与 360 主互补 |

## 三、判断依据（工作流第 2 步：判断先于选择）

按"组件描述三要素：组件名称、使用场景、操作规则"与"轮播四要点：形式、指示器、自动播放"逐项判断：

1. **内容关系**：单件硬件商品 + 若干静态细节图。硬件产品详情页的行业惯例之一就是 360° 拖转（如耳机、音箱、鞋类详情），参考文件也明确标注 360° View 适用于"电商产品图、硬件展示"——需求类型与控件标注场景直接命中。
2. **用户排除项**："左右滑动 + 三个圆点"是最普通的走马灯 Carousel；360° View 的操作是"按住拖动"，没有页与页的切换，天然不属于该形式。
3. **"高级浏览方式"的解读**：交互参与感 > 被动观看。360° 拖转让用户亲手转出背面细节，比任何自动轮播更有"高级感"与记忆点。
4. **向用户确认的关键判断项**（本次为离线执行，无法交互确认，以下作为假设执行并在页面中做成可切换，需修正时改缩略图即可）：
   - 是否有真实产品多角度摄影图 → 假设有（同机位连续帧）；Demo 用 Canvas 程序化绘制替代。
   - 是否只展示 360° → 假设是；但釉面细节、底座接口、场景图、釉色方案仍需要静态展示 → 用缩略图（图片预览标签）承载。

## 四、最终选型与理由

**主控件：360°旋转展示 360° View**；**辅助控件：图片预览标签 IMAGE PREVIEW TABS**（缩略图沿边栏排布，选中态描边高亮，主区与文案随选中项切换）。

按"细节三步"组装的完整描述（Prompt）：

> "做一个 360°旋转展示 360° View：按住音箱左右拖动查看全角度，松手后带惯性缓慢停转；闲置约 2.8 秒且鼠标不在其上时自动慢速旋转，悬停或拖动即暂停；正面为网面声学单元，背面为釉面与接口细节；用度数徽标 + 环形罗盘指示当前视角，提供'回正'按钮平滑回正。另做一排图片预览标签 IMAGE PREVIEW TABS：桌面端沿左栏、移动端沿底部横滑，每项为图标 + 名称，点击时主图与说明文案随选中项切换；360° 视图支持方向键旋转与回正，遵循 prefers-reduced-motion。"

选型理由汇总：
- 契合参考文件标注场景（电商产品图、硬件展示），且不落入用户排除的"左右滑 + 圆点"形式。
- 有明确可演示的交互规则（形式 / 拖动规则 / 指示器 / 自动播放与暂停条件），不是靠形容词撑起来的"高级"。
- 图片预览标签补足 360° 表达不了的静态信息（釉面、接口、场景、配色），是商品详情的完整闭环。
- 边界与可达性：Pointer Events 统一鼠标/触屏；键盘 ←/→ 旋转、回正按钮；prefers-reduced-motion 时停用自动旋转；触屏 touch-action: pan-y 保证纵向滚动不被劫持；单文件零依赖，可双击离线打开。

## 五、实现说明（Demo 的技术取材）

- 无真实产品摄影素材，故 360° 视图用 Canvas 按圆柱投影逐列采样一张 2048px 的 360° 展开贴图绘制（正面为覆盖约 180° 的编织网面，背面为釉面刻字与接口），叠加静态柱面明暗带；物理上柱体侧影不随旋转变化，与真实陶瓷圆筒音箱一致。
- 静态视图为内嵌 SVG 插画（釉面细理纹、底座接口、桌面场景、三款釉色），不依赖任何外部资源，无网络请求。
