# 实现说明

## 需求
电商商品详情页（陶瓷蓝牙音箱）的图片展示区，要求"高级浏览方式"，不使用"左右箭头 + 三个圆点"的普通轮播。单文件 HTML，中文界面，双击即可打开。

## 方案：3D 环绕展台（Coverflow 画廊）
- **视觉形式**：5 张"商品照片"以 3D 透视排布——主图居中，邻近图片向两侧退后、缩小、加蒙版与轻微模糊，形成有纵深感的环绕展台，替代平铺轮播。
- **图片来源**：全部为内联 SVG 手绘的"产品渲染图"（正面 / 侧颜 / 黄铜旋钮特写 / 织物音孔特写 / 生活场景），零外部资源，保证单文件可离线打开。
- **交互**：
  - 鼠标拖拽自由滑动（带速度甩动判定），滚轮、左右方向键、两侧悬停箭头均可切换；
  - 点击主图进入细节放大态，再点返回；
  - 底部胶片条（缩略导航，非圆点）显示标号与图名，带进度线；支持约 4 秒自动巡展，交互后重置计时；
  - 循环环绕：首尾无缝，用 wrap 取半圆距离避免跳变。
- **联动细节**：右侧"釉色"色板实时改变所有 SVG 中陶瓷釉面的颜色（CSS 变量注入 SVG 渐变 stop），图片展示与商品参数真正联动。
- **布局**：左展台 + 右信息栏的标准详情页结构，含价格、评分、购买按钮与三栏规格说明；响应式窄屏纵向堆叠；支持 `prefers-reduced-motion`。

## 技术要点
- 纯原生 HTML/CSS/JS，无依赖。
- 3D 变换由 CSS `calc()` 组合 `--o`（相对偏移）与 `--drag`（拖拽像素）两个变量驱动，JS 只负责更新变量，拖拽时关闭 transition 获得跟手感。
- 页面文件：`page.html`
