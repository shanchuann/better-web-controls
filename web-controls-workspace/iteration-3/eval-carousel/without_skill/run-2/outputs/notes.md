# 实现说明 —— 陶瓷蓝牙音箱 · 商品详情页图片展示区

**输出**：`page.html`（单文件，双击即可打开，无任何外部依赖 / 网络请求）

## 交互方案：为什么不是"左滑 + 圆点"轮播

放弃了自动播放、循环克隆、底部圆点这些轮播特征，改用一套**完全由用户驱动的电影胶片式浏览**：

| 交互 | 行为 |
| --- | --- |
| 直接拖拽主图 | 图像跟随手指位移（0.6 阻尼），松手超过阈值（70px）滑入上/下一张，不足则弹回原位 |
| 左右方向键 | 切换上一张 / 下一张（带方向感知的位移过渡） |
| 主图上滚轮 | 换图（带 720ms 声学阻尼）；在第一/最后一张时滚动自动"让路"给页面滚动 |
| 缩略图 | 66px 方形胶片带 + 角标编号，激活态描边 + 上浮阴影，自动 scrollIntoView |
| 点击主图 | 进入全屏大图查看器（`Enter`/双击也可） |
| 大图内 | 滚轮缩放（光标位置锚定缩放，1–4x）、放大后拖拽平移（限位推导 `50z−25`）、双击复位 2.4×、`←→` 切换、`Esc` 关闭 |
| 釉色选项 | 点击"雨过天青"釉色可直接联动主图切换到对应版次 |

## 视觉与动画细节

- 切图过渡：新层按方向从 ±4.5% 位移 + 1.02 缩放进入（`cubic-bezier(.22,.8,.24,1)`），旧层淡出并反向放大 1.035，形成"景深推移"而非生硬横滑
- 计数器 `01 / 06` 使用等宽字体（等宽数字防抖动），每次换图数字做 rise 小动画
- 左列在桌面端 `position: sticky`，右侧商品信息先看完长内容时主图始终在场
- 配色采用"纸感米白 + 陶土橙"的器物店语系，标题用宋体衬线，与陶瓷材质叙事一致

## 图片素材

6 张"商品摄影"（正面全景 / 编织线充电口 / 点阵网罩 / 顶部旋钮俯视 / 居家摆设 / 天青釉限定）全部为**内嵌 SVG 现场绘制**（渐变 + pattern 点阵 + 手雕刻字），零外部图片请求，离线打开也完整；主图与缩略图复用同一套绘制函数（gradient id 按 uid 前缀隔离，避免冲突）。

## 兼容性

- 指针事件（Pointer Events）统一鼠标 / 触控；主图 `touch-action: pan-y` 保证移动端垂直滚动不受拖拽劫持
- 缩略图条溢出横向滚动（隐藏滚动条）；≤980px 双列变单列、大图查看器边距自适应
- 可达性：`role="tablist/tab"`、`aria-label`、`:focus-visible` 描边、大图为 `role="dialog"` + 焦点管理
