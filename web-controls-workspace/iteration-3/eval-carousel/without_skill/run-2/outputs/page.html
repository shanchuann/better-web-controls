窑火与手作

每一只“山雾”都取高白泥手工拉坯成型，阴干三十天后入柴窑，经 1310℃ 还原焰烧足七十一小时。釉色在窑内的温位与火路里自然窑变，成品纹理无一重复。

声学腔体与陶瓷壳一体设计，釉面既是外观也是振声结构的阻尼层。声音如雾：低频温润不轰头，高频细腻带陶瓷特有的清透。

随附手织棉蜡编织线与同釉色陶瓷挂坠，出街上班，它更像一件案头器物。
