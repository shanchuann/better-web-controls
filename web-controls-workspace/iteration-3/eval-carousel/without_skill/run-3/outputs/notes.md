# page.html 实现说明

## 需求拆解
电商商品详情页图片展示区（陶瓷蓝牙音箱），要求高于"左右滑动 + 圆点轮播"的浏览体验，单文件 HTML、中文界面、双击可开。

## 采用的浏览方式：堆叠卡片 Deck（主交互）
- 图片以卡片层叠呈现：最前一张平铺置顶，后面几张逐张缩小、下移、降透明度，透视堆叠，直接传达"还有更多"。
- 拖拽换图：按住最前卡片左右拖拽，卡片实时跟随指针旋转；超过阈值（或快速甩动）即飞出，下一张从堆叠中弹起复位；未达阈值橡皮筋回弹。
- 多路径操控：左右箭头按钮、键盘 ← / →、底部缩略图点击直达（任意跳转，不强制顺序）。
- 状态指示：01/05 计数 + 底部 5 段进度条，同步高亮当前缩略图。

## 辅助交互
- 单击顶卡以点击处为原点放大 2.1 倍查看细节（放大态下拖拽禁用，再次点击复位），替代传统放大镜。
- 右侧信息面板釉色色块切换，通过 `--accent` CSS 变量实时改绘音箱顶部控制钮与织物底纹（CSS 绘图联动）。
- 加购 / 购买按钮 toast 反馈；sticky 信息栏。

## 图片方案
无外部资源，5 张"商品图"全部用 CSS 绘制并内嵌于卡片：正面全景（陶瓷筒身 + 织物半罩）、俯视釉面圈纹、手工肌理特写、书桌场景图、三配色并列图。离线可用，任一浏览器双击打开即渲染。

## 工程细节
- Pointer Events 实现拖拽，兼容触屏；`prefers-reduced-motion` 下关闭过渡动画。
- 换图动画期间加 `animLock` 防连点错乱；z-index / 透明度按深度统一由 `render()` 计算。
- ≤900px 降为单列布局，≤640px 缩小舞台高度。
