# 实现说明

## 文件
- `page.html`：单文件 HTML（内嵌 CSS + 原生 JS，无外部依赖），双击即可在浏览器打开。所有图表为 SVG/CSS 手绘，数据以 JS 数组维护，替换数字即可复用。
- `notes.md`：本说明。

## 页面结构（面向管理层的一句话信息流）
1. **页头**：报告标题、汇报对象、数据截止日、导出/打印按钮（print 样式已做适配）。
2. **KPI 卡片 ×4**：本月营收 480 万（环比 +12%）、环比变化、近 12 个月累计 4978 万、单月最高。卡内含与上月的对比胶囊。
3. **近 12 个月营收走势**：SVG 折线 + 渐变面积图，含 Y 轴网格、月份标签、末点数值强调（480），鼠标悬停各点有原生 title 气泡。
4. **各产品线营收占比**：SVG 环形图（stroke-dasharray 分段），中数字显示总营收；环形分段和下方图例均支持悬停查看金额（占比 × 480 万）。
5. **整体转化漏斗**：访问 → 注册/留资 → 商机 → 成交，横向条形漏斗，每级之间标注流失人数与流失率。
6. **各渠道转化与流失**：四渠道（官网直达 / 搜索引擎 / 社交媒体 / 线下渠道）表格列，含访问量、成交量、转化率（绿）、流失率（红），附简短结论注释。

## 数据说明
- 页面数据为**示例数据**，口径自洽：各渠道访问与成交之和 = 漏斗总量（128,000 / 2,140）；产品线占比合计 100%；环比 480 ÷ 428.6 ≈ +12%。正式使用前替换数组即可，不需要改渲染逻辑。
- 折线图坐标按数据范围（350–500）自适应，新增月份超过范围时需同步调整 `minV/maxV`。

## 设计取舍
- 浅灰底 + 白卡片 + 单主色（蓝），仅用红/绿表达流出/流失方向，管理层阅读时信息层级清晰。
- 所有数字用 `tabular-nums` 对齐；图表均带 `role="img"` 与 aria-label。
- 页面响应式（窄屏单列），打印时隐藏按钮、去阴影。
