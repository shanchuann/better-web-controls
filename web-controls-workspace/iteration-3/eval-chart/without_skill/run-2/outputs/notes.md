# 实现说明

## page.html
面向管理层的月度经营报告单文件页面，双击即可在浏览器打开，无外部依赖。

**结构**
- 顶部标题区：报告周期 + 状态徽章
- KPI 卡片区（4 张）：本月营收 480 万（环比 +12%，标注上月 428.6 万）、全年累计、成交订单、全渠道转化率
- 左卡：近 12 个月营收走势 —— SVG 面积折线图（由 JS 根据数据数组生成坐标点），带横向网格、纵轴刻度、每月数值标注，末月（480）重点高亮
- 右卡：各产品线营收占比 —— SVG 环形图（stroke-dasharray 按百分比分段累加绘制），中心显示总营收，右侧图例含金额与占比
- 底卡：各渠道转化流失 —— 表格内每渠道一条四段漏斗条（访问→留资→下单→成交，颜色由浅到深），标出该渠道流失率最高的环节；下方附全渠道汇总漏斗与"管理层提示"洞察块（付费广告下单→成交流失最高，给出可挽回金额估算）

**技术要点**
- 全部图表用原生 SVG + CSS 渲染，JS 仅负责按数据数组计算坐标/弧长，改数据数组即可复用
- 流失率、占比、汇总漏斗均由 JS 实时计算，避免手工算错
- 响应式：≤900px 时 KPI 变两列、双卡改单列
- 克制配色（蓝主色 + 绿涨红跌），管理层阅读友好的浅色主题

**数据均为演示数据**（营收序列、产品线占比、渠道漏斗），替换脚本顶部的 `REV / LINES / CHANNELS` 数组即可接入真实数据。
