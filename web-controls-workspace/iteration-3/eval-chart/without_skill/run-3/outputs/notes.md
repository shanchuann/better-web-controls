# 实现说明

**文件**：`page.html`（单文件，内嵌 CSS/JS，零外部依赖，双击即可打开）

## 页面结构
1. **页头**：报告标题 + 年月徽标 + 数据口径与出报日期。
2. **KPI 卡（3 张）**：本月营收 480 万（环比 +12%，附迷你趋势线）、近 12 个月累计营收 4,865 万、全渠道付费转化率 2.43%。
3. **近 12 个月营收走势**：纯 JS 生成 SVG 折线 + 面积渐变图，横轴 2025-11 至 2026-10（末月 480 万，次月 429 万，环比 +12%）。支持鼠标悬停：十字参考线、高亮点、tooltip 显示亿/万换算及各月环比。
4. **产品线营收占比**：SVG 环形图（stroke-dasharray 分段）+ 图例。智能硬件 186 / SaaS 订阅 152 / 专业服务 84 / 增值服务 58（合计 480）。悬停任一分段或图例，环形高亮、中心切换显示该产品线的占比与金额。
5. **渠道转化与流失漏斗**：五级漏斗（访问 120,000 → 注册 21,600 → 激活/试用 9,720 → 付费 4,860 → 复购/续费 2,916），每级显示占比条形、环节转化率、流失人数（红色标签），页脚汇总最大流失环节（注册，流失 60%）。条形宽度加载时动画展开。

## 设计要点
- 面向管理层的干净排版：中性灰背景、白卡片、深蓝主色（#2f54eb）+ 红绿语义色（流失/增长），衬线感数字用 DIN 风格字体栈。
- 除漏斗为 HTML/CSS 外，趋势图与环形图均为原生 SVG，无图表库。
- 响应式：<900px 自动降级为单列；含打印样式（卡片不跨页断开）。

## 数据说明
营收与环比来自需求原文；产品线构成、渠道漏斗人数为合理演示样例，替换 `page.html` 中脚本顶部 `revenue / products / funnel / months` 四个数组即可复用。
