# 选型笔记：删除项目 · 二次确认交互

## 需求原文

> 我们的后台管理里有个"删除项目"功能，删除后所有任务和文件都没了，不可恢复。帮我给删除按钮加上合适的确认交互。

参考文件：`references/rules.md`（二次确认与等待体验）、`references/controls.md`(按钮三步公式、弹窗四要素)。

## 判断依据（判断先于选择）

1. **后果是否可逆**：不可逆。"所有任务和文件都没了"且用户明确说明不可恢复。
2. **影响范围**：项目级删失，连带任务、文件与成员权限，属于"影响大的批量删除"。
3. **操作频率**：删除项目是低频操作，使用较重的确认手段不会影响日常操作效率。
4. **误触风险**：后台管理中的危险按钮存在误触和权限误用风险，需要"说明后果 + 制造确认成本"。

## 候选对比（二次确认 7 种，rules.md）

| 候选 | 英文 | 打断程度 / 确认成本 | 适用场景 | 是否适配本需求 |
|---|---|---|---|---|
| 撤销 Undo | Undo | 低，操作后给撤销入口 | 发消息、归档、可恢复删除 | ✗ 本删除不可恢复，无Undo可能 |
| 长按确认 | Hold to Confirm | 中 | 防误触、移动端危险按钮 | ✗ 桌面后台，且无法说明影响范围 |
| 左滑删除 | Swipe to Delete | 中 | Web 列表单项 | ✗ 场景是详情页按钮，非列表项 |
| 气泡确认 | Popconfirm | 中低 | 中等风险单项操作 | ✗ 无法承载"128 任务 + 342 文件"级别的后果说明，确认过轻 |
| 弹窗确认 | Modal | 高 | 删除重要文档等严重后果 | △ 可说明后果，但单次点击即可确认，仍不够"难删" |
| 输入文字确认 | Type to Confirm | 最高（可交互项内） | 删除仓库、清空数据 | ✓ 几乎是本场景的标准做法 |
| 勾选确认 / 独立确认页 | Select All to Delete | 最高 | 批量删除、最高风险 | ✗ 单项目删除，跳独立确认页过重 |

## 决策线套用（rules.md）

> 轻微事项重度确认会干扰用户，严重事项轻度确认会导致事故。
> 决策线：可逆用撤销；轻微用长按/左滑；中等用气泡；**严重后果用弹窗；不可逆且影响大用输入确认或独立确认页**。

## 最终选型：弹窗确认 Modal + 输入文字确认 Type to Confirm（组合）

两个控件组合而非二选一：

- **Modal 居中弹窗**承担"说明后果"：蒙版阻断操作，弹窗内逐条列出影响范围（任务 128 个、文件 342 个约 1.2 GB、成员权限 12 人），满足二次确认第二个价值。
- **Type to Confirm**承担"制造确认成本"：输入完整项目名称后，删除按钮才启用，满足第一、三个价值（防误触、保留反悔余量——下载/恢复窗口由系统另行保证）。
- 未选独立确认页：单个项目删除不需要整页代价；勾选确认更适合跨项目批量删除。

## 落地规格（Prompt）

> 做一个**输入文字确认 Type to Confirm**，包裹在**弹窗确认 Modal** 内（居中弹窗，红色警告图标 + 标题 + 影响范围清单 + 输入区 + 操作按钮）。
> - 触发：点击"删除项目"面状红色实心按钮（SOLID BUTTON，图标 + 文字，危红主色，仅此按钮使用红色）后弹出。
> - 操作规则（Modal 四要素：类型 / 触发 / 关闭 / 内容）：点击取消按钮、遮罩或按 Esc 关闭；只有输入完整项目名称后"永久删除"按钮才启用；输入不匹配时点击删除在输入框下方显示错误提示"输入内容不匹配"。
> - 删除执行中按钮进入 loading 态（不可重复点击）；完成后弹窗关闭，页面呈现删除后的空状态（Empty State），并用轻提示 Toast（右上角 / 顶部居中，数秒自动消失）确认"项目已永久删除"。
> - 无障碍：dialog 使用 `role="alertdialog"` + `aria-modal`，打开自动聚焦输入框，关闭后焦点回到触发按钮。
> - 移动端：弹窗操作按钮全宽、触控目标 ≥ 44px（媒体查询已处理）。

## 验收要点

1. 打开页面，点击红色"删除项目"按钮 → 弹出居中确认弹窗，遮罩阻断下方操作。
2. 不输入或输入错误内容时，"永久删除"按钮保持禁用；强制点击（如 Tab+Enter 绕过）时显示"输入内容不匹配"的错误提示在输入框下方。
3. 输入"星链运营平台"完整匹配后按钮才启用。
4. 用取消按钮、点击遮罩、按 Esc 三种方式均可关闭弹窗，且页面焦点回到删除按钮。
5. 确认删除后：按钮先进入"删除中…"的加载态（约 0.9 秒模拟请求），随后弹窗关闭、顶栏 Toast 提示"项目已永久删除"，原项目卡替换为空状态，可通过"重新载入演示"恢复初始状态。
6. 移动端（≤560px）：弹窗按钮放大至全宽，触控目标满足 44px。
