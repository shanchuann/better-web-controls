# 选型笔记：订单管理页 · 选择负责人并按负责人筛选订单

## 1. 需求识别与依据

**需求原文**："订单管理页面里要选负责人，帮我做个下拉选择负责人，顺便按负责人筛选订单。输出一个可以直接打开的完整 HTML 文件（单文件）。"

- 需求类型：**新增控件**（下拉）+ 页面为订单管理列表。
- 查阅参考文件：`references/controls.md`（下拉组件 7 种、表格 5 种、长列表加载 3 种）、`references/rules.md`（空状态 5 种、对齐 5 种、提示消息）。

**需求拆解**：一个"选择负责人"的下拉，选中后订单列表按该负责人过滤。"选负责人"与"按负责人筛选"是同一个下拉的两个用途：选人即筛选条件，不是把负责人写进订单。选项是"负责人"而非"部门"，通常为扁平的少量人员，无上下级。

## 2. 候选对比（来自 controls.md "下拉组件 7 种"）

| 候选 | 适用场景 | 本需求是否匹配 |
|---|---|---|
| Select 单选下拉 | 固定少数选项，只能选一个，如订单状态、负责人 | ✅ 负责人为固定少量人员、单选，最常见 |
| Combobox 可搜索选择框 | 选项多，边搜边选 | ⭕ 若负责人上百人（跨多团队）应升级为 Combobox；示例仅 5 人无需搜索 |
| Multi-select 多选下拉 | 多选、选中项成标签，适合数据过滤 | ⭕ 需求只说"选负责人"（单个人），未要求多维度叠加过滤 |
| Cascader 级联选择 | 选项有上下级（公司—部门—个人） | ❌ 负责人是叶子人员，未提及层级 |
| Grouped Select 分组下拉 | 选项多且按类别分组 | ⭕ 若按大区分组可加分，选项少于 10 时不必分组 |

**判断先于选择**：负责人选项（1）无上下级 → 排除 Cascader；（2）数量少（约 5 人）→ 排除 Grouped 分组与 Combobox 搜索；（3）需求为单人选择 → 排除 Multi-select。结论指向 **Select 单选下拉**。

## 3. 信息不足时确认的问题（若非单文件交付会先向用户确认）

1. 负责人数量是否超过 20~30 人？超过则选 Combobox（边搜边选）。
2. 是否需要按多个负责人或多条件（状态、时间）叠加筛选？需要则引入 Multi-select。
3. 选项是否存在"大区—人员"两级？有则用 Cascader 或 Grouped（大区作分组）。

本交付基于默认假设：**单选、无层级、少量固定选项**，按 Select 实现，并在下拉中补充"全部负责人"选项与每人订单数标注，便于用户预判筛选结果。

## 4. 最终选型（完整 Prompt 规格）

> 做一个**负责人 Select 单选下拉**，放在订单管理列表的工具栏中，选中后按该负责人筛选订单列表。
> **形式**：触发框显示当前负责人头像与姓名，未选时显示占位文字"选择负责人"；展开为面板列出全部负责人，附所属大区与课时订单数，当前选中项带对勾。
> **操作规则**：单选；打开面板点击选项即筛选并关闭；支持键盘 ⌘/Ctrl 操作——打开后 ↑↓ 高亮、Enter 选中、Esc 关闭、点击外部关闭；选中后触发框右侧出现 ✕ 清空按钮，点 ✕ 或移除筛选标签可回到"全部负责人"。
> **边界情况**：某负责人名下无订单时显示"0 条"标记；筛选无果显示空状态——当前条件保留为可移除的标签，引导"点 ✕ 移除条件或改选负责人"，并提供"查看全部订单"按钮。

## 5. 从参考文件同步引入的配套规则

| 规则 | 出处 | 本页落地 |
|---|---|---|
| 空状态·筛选无果 | rules.md 空状态 5 种 | 条件保留 + 标签可移除 + "查看全部订单"引导，不做"提示 + 大按钮" |
| 两端对齐 | rules.md 对齐 5 种 | 名称贴左、金额右对齐（等宽数字 tabular-nums） |
| 状态筛选 | rules.md 长页面定位 | 负责人即列表筛选器，选中后实时过滤并显示条数 |
| 表头筛选 | controls.md 表格 5 种 | 负责人作为列之一，筛选条件在工具栏与列内双向呼应 |
| Toast 替代 | rules.md 提示 7 级 | 筛选属轻量操作，用可见的计数/标签反馈，不打断（无弹窗） |

## 6. 取舍说明

- **不做每行改派**：需求中的"选负责人"理解为选筛选条件；若要在行内给订单改派负责人，需另加行内 Popover，另行确认。
- **不做状态、时间多条件筛选**：本需求只要求按负责人，保持一个字段一个职责。
- **数据为本地演示数据**（10 条订单、5 位负责人，其中"周涛"名下 0 条用于演示空状态），双击打开即用，无网络依赖。
