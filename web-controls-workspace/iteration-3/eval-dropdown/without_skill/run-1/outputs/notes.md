# 实现说明

单文件 HTML（内嵌 CSS/JS），双击可直接打开，无任何依赖。

## 功能

- **负责人下拉选择**：自定义下拉组件（非原生 select），支持搜索过滤、每人显示部门与订单数、选中高亮 + 勾号、头像色块首字。
- **按负责人筛选订单**：选择后表格实时过滤，顶部统计同步显示总数与当前筛选条件。
- **清除筛选**：选中负责人后出现"清除筛选"按钮，一键恢复"全部负责人"。
- **空数据提示**：筛选后无订单时显示"暂无符合条件的订单"。

## 交互细节

- 点击外部区域或按 Esc 关闭下拉；Enter 选中搜索结果的第一个匹配项。
- 按钮用 `aria-expanded` / `aria-haspopup` / `role="listbox"` 提供 ARIA 语义，支持键盘聚焦（focus-visible 样式）。
- 下拉打开/关闭有箭头旋转与淡入动效。

## 数据

内置 10 条示例订单、6 位负责人的 mock 数据，过滤逻辑在 `render()` 函数中：`orders.filter(o => !selected || o.owner === selected)`。
