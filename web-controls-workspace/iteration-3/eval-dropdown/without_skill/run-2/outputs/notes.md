# 实现说明

## page.html
单文件 HTML（内嵌 CSS/JS，无外部依赖），双击即可在浏览器打开。

### 功能
- **负责人下拉选择**：自定义下拉组件（非原生 `<select>`），带（全部负责人）选项，每个负责人有彩色圆点、头像色块与订单数量。
- **按负责人筛选订单**：选择后表格实时过滤，同时更新右上角订单总数统计；选"全部"显示所有订单。
- **空状态提示**：某负责人名下无订单时显示"该负责人名下暂无订单"。
- **交互细节**：
  - 点击下拉外部区域自动关闭，按 `Esc` 也可关闭；
  - `aria-haspopup` / `aria-expanded` 无障碍属性；
  - 悬停、选中项高亮（背景 + ✓ 标记）。

### 数据
内置 5 位负责人、10 条示例订单（订单号 / 客户 / 金额 / 负责人 / 状态 / 日期），全部为本地内存数据，可按 `ORDERS`、`OWNERS` 两个数组直接替换为真实数据源。

### 视觉
浅灰背景 + 白色卡片，People 头像首字圆形色块区分负责人，订单状态用彩色标签（待处理 / 已完成 / 已取消）区分。
