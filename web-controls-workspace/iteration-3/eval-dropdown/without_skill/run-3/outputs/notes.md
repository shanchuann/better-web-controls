# 实现说明（page.html）

单文件 HTML，无任何外部依赖，直接双击打开即可使用。

## 功能

1. **按负责人筛选订单**
   - 顶部工具栏有一个"负责人"下拉（选项：全部 / 张伟 / 李娜 / 王强 / 赵敏 / 陈静），选择后表格实时过滤，出现"重置筛选"按钮。
   - 统计栏实时显示：已筛选单数 / 总单数、当前筛选的负责人、待指派单数。

2. **选择每单负责人**
   - 表格"负责人"列为行内下拉，默认"未指派"，可直接点开更改所属人，更改后统计自动更新。
   - 负责人显示为彩色首字头像 + 姓名，颜色按姓名哈希稳定生成。

## 下拉组件（自定义，可复用）

顶部筛选与每行指派共用同一个 `Dropdown` 组件，包含：

- 点击开合；点击组件外部或按 `Escape` 关闭（全局监听）。
- 键盘操作：`↑` / `↓` 移动高亮、`Enter` 选中、`Esc` 关闭；选中项带 ✓ 与高亮。
- 面板空间不足时自动向上展开；打开时自动滚动到已选中项。
- 触发按钮带 `aria-haspopup="listbox"`、`aria-expanded`，选项带 `role="option"` / `aria-selected`，可聚焦并有 focus-visible 描边。
- 顶部筛选下拉支持"×"一键清空（回到"全部"）。

## 数据与渲染

- 10 条示例订单（订单号 / 客户 / 商品 / 金额 / 状态 / 负责人），订单状态用彩色徽章展示。
- 筛选结果为空时显示居中空状态"没有符合条件的订单"。

## 已验证

- Chrome headless 渲染无 JS 报错，10 个订单行 + 11 个下拉实例正常渲染，统计文案正确。
