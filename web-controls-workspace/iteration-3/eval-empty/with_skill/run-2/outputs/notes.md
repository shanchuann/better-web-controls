# 空状态选型笔记 — CRM 客户列表

需求原文：CRM 系统里客户列表在两种情况下会空——新用户刚注册还没有客户；搜索/筛选后没有匹配结果。

## 一、需求判断

依据 `rules.md`“空状态 — 5种：原因不同，引导不同”：空状态不应统一做成"提示 + 按钮"，先说明页面为什么为空。本需求命中其中两类，但"搜索/筛选后无结果"按原文应再拆分为两种情况，原因是用户能采取的修复动作不同：

| 页面为什么为空 | 命中类型 | 用户的修复动作 |
|---|---|---|
| 新用户刚注册，还没录入任何客户 | 首次使用 First-use | 创建第一位客户，或批量导入 |
| 搜索关键词没有匹配到任何客户 | 搜索无果 No Search Results | 更换、缩短关键词 |
| 筛选条件组合下没有匹配客户 | 筛选无果 No Filter Matches | 减少筛选条件 |

总结口诀（rules.md）：创建给入口，搜索改关键词，筛选改条件。

## 二、候选对比

| 候选 | 做法 | 适用情况 | 是否采用 |
|---|---|---|---|
| A. 统一空状态（一张图 + 一句"没有数据" + 一个大按钮） | 三种情况共用同一版式与同一个大 CTA | 只演示原型时省事；真实场景下会让搜索无果的用户被误导去"新建客户"，而不是修改搜索词 | ✗ 作为反面参照保留 |
| B. 首次使用 First-use | 中性插画 + 说明文案 + 创建/导入入口 | 新用户、无任何数据 | ✓ 用于"新用户刚注册" |
| C. 搜索无果 No Search Results | 关键词保留在搜索框，修改建议放在搜索框旁，不加大按钮 | 全量数据非空、仅关键词未命中 | ✓ 用于"搜索后无结果" |
| D. 筛选无果 No Filter Matches | 当前筛选条件保留在页面上方标签，可逐个 × 移除 | 数据存在但被条件过滤掉 | ✓ 用于"筛选后无结果"（含"关键词 + 筛选同时生效"的情况，此时条件标签包含关键词） |

## 三、判断依据

1. **先判断，再选工具**（rules.md 开篇原则）：三种"空"的成因不同，用户需要的东西不同——新用户需要"怎么开始"，搜索失败需要"换个搜法"，筛选失败需要"少一个条件"。因此不是一个组件，而是一套三个分支。
2. **搜索与筛选区分**：搜索框内关键词未变，文案与建议围绕搜索框；筛选生效时，条件必须以可移除的标签形式留在页面（"点击上方标签 ×，减少一个条件"），且提示位置指向上方标签，不在空状态里重复列一遍条件造成歧义。
3. **按钮强度匹配**（controls.md 按钮三步公式 + rules.md）：
   - 首次使用：主操作"新建客户"用面状按钮（全页唯一实心），"批量导入"为线状按钮（次操作不与主按钮争夺注意力），"查看使用引导"为文字按钮；
   - 搜索无果 / 筛选无果：**不添加大按钮**（rules.md 明确要求），只提供文字按钮级的轻量出口（"清除关键词"><"清空全部筛选"），避免引导用户走错误的修复路径。
4. **对齐方式**（rules.md 对齐 5 种）：空状态引导属于"图标、短标题和按钮居中"的典型场景，三者沿同一中轴居中；不放长文本，保持短句。
5. **状态可见性**：列表区同时保留条件标签行（chips），每枚可单独 × 移除，另有"清空"；移除即时重新渲染，符合"逐个移除，减少一个条件"的规则。

## 四、最终选型与 Prompt 规格

最终实现为**一套组件、三个分支**（单文件 HTML，内嵌 CSS/JS，中文界面）：

> 做一套客户列表空状态（Empty State，三分支版式，图标 + 短标题 + 说明居中）：
> ① 首次使用：插画 + "还没有客户" + 说明；面状按钮"新建客户"（主操作、全页唯一实心），线状按钮"批量导入"，文字按钮"查看使用引导"；不显示筛选标签行。
> ② 搜索无果：关键词保留在搜索框内；标题回显关键词；建议（更短关键词、检查错别字、改用电话/公司全称搜索）放在搜索框旁的说明区；**不放主按钮**，仅文字按钮"清除关键词，查看全部客户"。
> ③ 筛选无果：当前生效条件以可移除标签保留在页面上方，每枚标签带 ×（关键词标签提供 ×，状态/负责人标签提供 ×，另有"清空"）；标题说明"当前筛选条件下没有匹配的客户"，提示"点击上方标签 ×，减少一个条件再试试"；**不放主按钮**，仅文字按钮"清空全部筛选条件"。
> 边界情况：关键词与筛选同时生效且无匹配时，优先按筛选无果呈现，关键词并入条件标签列表；任何条件变更后即时切回对应状态。

## 五、页面附注

- 页面底部固定"预览场景"切换条（新用户首次进入 / 搜索无结果 / 筛选无结果 / 正常数据），仅用于演示三个分支，非交付功能的一部分。
- 正常数据使用 8 条模拟客户记录，可复现"搜索张伟技 → 无果""状态=已成交 + 负责人=陈晨 → 无果"两条触发路径。
