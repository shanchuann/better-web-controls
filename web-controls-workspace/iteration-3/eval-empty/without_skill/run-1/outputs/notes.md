# notes.md

## 实现说明

单文件 `page.html`（内嵌 CSS/JS，无外部依赖，双击可直接打开）。

### 两种空状态的区别

1. **新用户空状态（`#emptyNew`）**
   - 标题引导行动："还没有客户，从第一笔开始"
   - 主操作：立即新建客户 + 导入客户（Excel）
   - 附带 3 步引导卡片（新建 → 记跟进 → 看报表），帮新用户理解产品价值
   - 触发时机：系统内一个客户都没有

2. **搜索/筛选无结果（`#emptyNoResult`）**
   - 明确汇报当前条件："关键词“xx” 且 阶段“xx”没有匹配到的客户"
   - 提供两条出路：清空搜索与筛选（恢复全列表）、新建客户
   - 动态拼接条件描述，用户知道是"筛选太严"而不是"数据丢了"

### 细节
- 页面顶部提供场景切换单选（有数据 / 新用户），便于演示两种空状态；也可以通过搜索一个不存在的词触发无结果状态。
- 空状态图标用内联 SVG 插画风（文件夹、放大镜），不依赖图片资源。
- 无结果状态用 `role="status" aria-live="polite"`，筛选变化时对读屏用户可感知；表格隐藏时同步 `aria-hidden`。
- "新建客户"按钮做了模拟交互：点击后切回有数据场景并重新渲染表格。
- 无结果区的描述文字随输入/筛选实时更新（`noResultDesc`）。
