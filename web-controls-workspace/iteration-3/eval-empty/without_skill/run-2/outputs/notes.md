# 实现说明

## 页面结构
- 单文件 HTML（`page.html`），内嵌 CSS/JS，双击即可打开，无外部依赖。
- 模拟了一个 CRM 客户管理界面：左侧导航 + 顶部面包屑 + 客户列表卡片（工具栏 / 筛选标签 / 表格 / 分页）。

## 两种空状态的核心区分
状态判定逻辑在 `render()` 中（按优先级）：
1. **场景 A：新用户 · 暂无客户** —— 客户库本身为空时展示。插图 + “还没有客户，从第一批开始”+ 主操作（新建客户 / 批量导入）+ 三步引导（新建导入 → 分层管理 → 跟踪转化），目的是教育用户完成第一份数据。
2. **场景 B：搜索/筛选 · 无匹配** —— 库里有数据但当前条件过滤后为 0 条时展示。放大镜插图 + “未找到匹配的客户”+ 描述文案**动态回显当前搜索词和筛选条件**（搜索词加粗高亮）+ 建议清单（检查拼写 / 减少条件 / 换字段搜索）+ “清除全部搜索和筛选”“仅重置阶段筛选”两个动作按钮。

## 关键交互
- 搜索框实时过滤（名称/电话/负责人/行业），带清空按钮；阶段下拉筛选；“筛选”按钮统计命中条件数量徽标。
- 生效的条件会以可单独移除的标签（filter tag）形式展示在表格上方。
- 空状态 B 的文案会根据组合条件实时更新，如：没有找到包含 “xxx” 且阶段为“跟进”的客户。
- “清除全部搜索和筛选”一键恢复完整列表，配合 Toast 反馈。
- 新建客户模态框：在场景 A 点“新建客户”提交后会自动脱离空库状态，展示新数据行（ Empty → 有数据 的正向闭环演示）。

## 演示辅助
- 右上角“演示切换”下拉可快速在三种视图间切换：有数据 / 新用户空库 / 搜索无结果，方便评审两种空状态。
- 默认进入为"有数据"视图，在搜索框输入不存在的关键词（或切到"搜索无结果"）即可看到场景 B。

## 其他细节
- 用户输入（搜索词、客户名）渲染前做了 HTML 转义，防注入。
- 响应式考虑：工具栏 flex-wrap 换行，卡片内空状态居中自适应。
- 快捷键：`/` 聚焦搜索框，`Esc` 关闭模态框。
