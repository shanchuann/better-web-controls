# 实现说明

## 概述
`page.html` 是一个 CRM“客户列表”页面的单文件演示（内嵌 CSS/JS，无外部依赖，双击即可打开）。核心是实现两种明确区分的空状态，并让它们能被真实交互自然触发。

## 两种空状态

1. **新用户空状态（还没有客户）**
   - 插画 + 标题“还没有客户，从第一位开始”+ 简短价值说明。
   - 主操作“+ 添加第一位客户”（新建表单入口），次操作“导入已有客户”。
   - 额外提供三步引导卡片（录入资料 → 分配负责人 → 记录跟进），降低新用户迷茫感。
   - 触发方式：演示数据被清空时（页面加载即为本状态，或按 `Alt+1`）。

2. **搜索/筛选无结果空状态**
   - 插画（放大镜+对勾）+ 标题“没有找到匹配的客户”。
   - 动态回显触发它的筛选条件（关键字、类型、阶段），让用户明白"为什么没结果"。
   - 主操作“清除全部筛选”，次操作“+ 新建该客户”；底部提供可点击的示例关键字（搜索"公司"/"张"）降低试错成本。
   - 触发方式：在搜索框输入不匹配内容，或组合筛选条件下无命中。

## 关键实现
- `render()`（page.html 中的脚本）根据数据集与搜索/筛选结果在三个视图间切换：数据表格、`emptyNew`、`emptyFiltered`，用 `.show` class 控制显隐，并带淡入动画。
- 顶部计数文本（`#statText`）随状态同步更新（共 N 位客户 / 没有匹配的客户 / 还没有客户）。
- 空状态容器使用 `role="status" aria-live="polite"`，切换时会被读屏设备播报。
- 搜索框支持 `:not(:placeholder-shown)` 显示“✕ 清空”按钮，支持 `type="search"` 原生清空。
- 左下角演示提示条说明开关快捷键（`Alt+1` / `Alt+2`），方便评测者主动对比两种状态。
- 未使用任何外部资源或框架，纯原生 HTML/CSS/JS。

## 已知简化
- “新建客户”“导入客户”为演示 alert（新建后会恢复示例数据），用于验证空状态间流转，不代表完整业务。
