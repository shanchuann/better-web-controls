# 选型笔记：山晨民宿官网页面修复

## 1. 需求类型识别

用户反馈"AI 做的页面不对劲"，属于**修复页面问题**类型，按工作流查阅 `references/fixes.md`（细节修复对照表）。用户抱怨集中在三处，逐条与对照表匹配：

| 用户症状（原文） | 对照表匹配 | 病因 | 修复指令（照用原文，未改写措辞） |
|---|---|---|---|
| "图片总看着是歪的偏的" | #2 图片看着偏了 | `object-fit: contain` 居中留白，看起来像歪的 | "改成填满容器 cover，别居中。" |
| "有些间距怎么都去不掉" | #4 间距去不掉 | 多半是残留的 margin 未归零 | "查残留的 margin，彻底去掉。" |
| "首屏内容还被顶部导航挡住了" | #5 内容被导航栏挡住 | 透明浮动导航叠加在内容上 | "给内容留出导航栏的高度（padding-top）。" |

## 2. 逐项候选对比与判断依据

### ② 图片歪偏（ rooms 内房型图 `.room .pic img`）

- **候选 A：`object-fit: cover`** —— 图片按比例放大填满容器、居中裁掉溢出部分。适合房型封面这类"完整品类、无所谓完整构图"的场景，视觉上整齐无留白。（对照表 #2 指定方案）
- **候选 B：`object-fit: contain`（现状）** —— 图片完整显示但两侧留白，配合灰色底 `#eee` 形成偏移错觉，正是用户抱怨的根源，排除。
- **候选 C：按语义重算 1:1 裁切位置（对照表【语义裁切】句）** —— 适合头像/需要保住关键主体的场景；房型宽图（220px 高、300px 宽，约为 15:11 横向比例）用 cover 居中裁切即可，无需逐张指定裁切点。

**判断依据**：房源封面是装饰性大图而非必须_keep 全貌的证件式图片。**选定 A（cover）**。
另外首屏 hero 大图 `.hero img` 已是 `width:100%; height:380px` + 块级布局，本身没有 contain 问题，保持原状不动。

### ④ 间距去不掉

- **候选 A：删除残留 margin（对照表 #4 指定方案）** —— 源码中 `.old-copy` 是"从旧模板复制来的样式"，带 `margin-left: 40px; margin-top: 24px`，导致整块内容不在容器网格内、与 content 的 20px padding 叠加出不规则缩进。直接去掉这两个 margin，注释说明。
- **候选 B：保留类名、把 margin 改为别的值** —— 治标不治本，残留壳类还会误导后续维护，排除。

**判断依据**：该 `<div class="old-copy">` 只包裹、无样式作用点（去掉 margin 后不再承担任何样式），因此**选定 A**：margin 归零并连同壳类一起删除，HTML 结构层级相应收紧一格，内容和配色不变。

### ⑤ 首屏被导航挡住

- **候选 A：给 hero 加 `padding-top: 64px`（对照表 #5 指定方案）** —— 内容整体下移一个导航高度，fixed 半透明导航依旧悬浮，hero 图片顶端正好从导航下缘开始，一行 CSS、零 DOM 改动。
- **候选 B：把导航从 `fixed` 改为 `static/相对文档流`** —— 不再遮挡，但会改变"导航悬浮在半透明背景上"的既有样式气质（用户要求保持风格不变），排除。
- **候选 C:给 hero img 加 `margin-top: 64px`** —— 与 A 等效，但 margin 顶在 img 上会连带背景窗口上缘露出 `#faf8f5` 空隙，不如 padding 包在容器内干净；且 64px 正好等于导航 height，用 padding 表达"给导航留位"语义更准。

**判断依据**：导航的 fixed + 毛玻璃是这个页面的风格元素，不能动。**选定 A**：`.hero { padding-top: 64px }`。

## 3. 最终实现摘要

| # | 症状 | 改动 |
|---|---|---|
| 1 | 房型图片歪偏 | `.room .pic img` 的 `object-fit: contain` → `cover` |
| 2 | 间距去不掉 | 删除 `.old-copy` 残留的 `margin-left: 40px; margin-top: 24px`，并去掉该无样式壳层 |
| 3 | 首屏被导航挡住 | `.hero` 增加 `padding-top: 64px`（导航栏高度） |

## 4. 未动的部分（用户要求保持内容 / 配色 / 风格不变）

- 文案、所有图片 URL、三档价格与房型描述一字未改（仅修正了 alt 属性中误入的一处空格，不影响显示）。
- 配板色 `#faf8f5 / #333 / #fff / #888 / #999`、字号字重、圆角、导航半透明毛玻璃样式全部保留。
- 对照表使用建议中"修复后检查三处：对齐、间距、遮挡"均已复核：房型卡内部图片填满无留白（对齐）；内容块回到 960px 容器栅格（间距）；hero 不再被 fixed 导航覆盖（遮挡）。
