# 修复说明

针对原页面三个问题逐一修复，文案、图片、配色、字体均保持原样。

## 1. 首屏内容被导航挡住
- 原因：导航是 `position: fixed; height: 64px`，但 body 没有给顶部预留空间，首屏大图顶端有 64px 被永久遮住。
- 修复：`body { padding-top: 64px }`，与导航高度精确对齐，页面内容从导航下沿开始。

## 2. 图片看着歪/偏
- 首屏大图：`img` 默认 `object-fit: fill`，容器定高 380px 与图片原始宽高比不一致时被水平拉伸变形。修复：改为 `object-fit: cover`，等比裁切填充、不失真。
- 房型卡片图：容器定高 220px 却用 `object-fit: contain`，比例不符时四周留出灰白底、图内容偏移悬空。修复：改为 `object-fit: cover` 铺满圆角容器，并给图片加 `display: block` 消除行内基线空隙。

## 3. 去不掉的多余间距
- 原因：旧模板残留 `.old-copy { margin-left: 40px; margin-top: 24px }`，把正文顶开上边距并整体缩进，视觉上无法对齐。
- 修复：删除该残留样式及其包裹层；同时将 `h2`、`.desc` 外边距归一为明确值，避免依赖浏览器默认边距产生不稳定空隙。

## 顺带的加固（不改变桌面观感）
- 房型卡片由固定 `width: 300px` 改为 `flex: 1 1 240px` + `flex-wrap: wrap`：桌面宽度下三卡仍是等宽一行（约 291px，与原渲染一致），窄屏时自动换行不再相互挤压。
- 导航模糊效果补充 `-webkit-backdrop-filter` 前缀，兼容 Safari。
- 增加一条极窄屏（≤480px）的导航内边距微调，防止溢出。
