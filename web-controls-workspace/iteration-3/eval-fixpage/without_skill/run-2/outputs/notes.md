# 实现说明

针对用户反馈的三个问题逐一修复，原有的内容、配色（#faf8f5 底色、灰色系文字、白色卡片）和整体风格保持不变：

1. **首屏被导航挡住**：原页面导航是 `position: fixed` 高 64px，但 hero 从页面顶部（y=0）开始，没有为它腾出空间。修复：给 `body` 加 `padding-top: 64px`，把首屏内容推到导航下方，无需改动导航本身。
2. **图片歪/偏**：
   - hero 大图：`width: 100%` + 固定 `height: 380px` 会把图片按容器比例拉变形。修复：加 `object-fit: cover; object-position: center`，按容器裁切、不拉伸。
   - 房型卡片图：原来用 `object-fit: contain`，照片填不满 220px 容器时会留白且居中偏移，看起来"歪的偏的"。修复：改为 `object-fit: cover`，图片满铺卡片并居中裁切。
3. **怎么都去不掉的间距**：旧模板残留的 `.old-copy` 样式带 `margin-left: 40px; margin-top: 24px`，导致内容区整体偏移、顶部多出一块空隙。修复：清零该容器的外边距，间距只由 `section` 的统一 `padding: 48px 0` 控制；同时补了 `h2`/卡片描述的默认 margin 清零，避免浏览器默认间距造成的不齐。

顺带的小完善（不改变风格）：导航锚点指向对应区块实现平滑跳转定位；房型卡片加 `flex-wrap: wrap` 以便窄屏时换行不溢出；修正了第三张卡片 alt 文本的乱入英文字符。
