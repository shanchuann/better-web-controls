# 修复说明

针对三个问题的修复（内容、配色、整体风格均保持不变）：

1. **图片歪的偏的** — 房型卡片图片原先用 `object-fit: contain`，在固定高度容器里会留白并显得偏移。改为 `object-fit: cover`，按比例裁剪填满容器。首屏大图原先无 `object-fit`（默认 `fill`），会被强行拉伸变形，同样改为 `cover`。

2. **间距去不掉** — 页面主体被 `.old-copy` 包裹，该类残留了 `margin-left: 40px; margin-top: 24px`（旧模板复制来的遗留样式），导致内容整体偏移、间距异常。已将残留 margin 清零。另外给 `h2` 补了底部间距、导航最后一个链接去掉多余右外边距，保持视觉节奏统一。

3. **首屏被导航挡住** — 导航是 `position: fixed` 但页面没有为其预留空间，首屏从视口顶部开始，被 64px 高的导航遮住。给 `.hero` 加了 `padding-top: 64px`，导航下方再开始展示首屏图片。

顺带优化：`.rooms` 增加 `flex-wrap: wrap`，窄屏时卡片自动换行不溢出；修正了第三张卡片 alt 文本里的多余字符。
