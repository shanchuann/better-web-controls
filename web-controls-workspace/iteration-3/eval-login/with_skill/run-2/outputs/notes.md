# 选型笔记 — SaaS 登录页（品牌色：陶橙）

需求原文："帮我们 SaaS 产品做个登录页，要高级一点，品牌色是陶橙色。输出一个可以直接打开的完整 HTML 文件（单文件）。"

按 SKILL.md 工作流执行：识别需求类型 → 查阅 `references/layouts.md`（登录页一节）、`references/rules.md`（表单校验时机 / 提示等级 / 移动端降级 / 设计术语）、`references/controls.md`（按钮三步公式）→ 列候选对比 → 记录判断依据 → 直接实现。

## 一、需求判断

- 用户想要的：页面布局与结构 → 登录页（`layouts.md` 登录页一节，描述需包含**布局、背景、卡片**三项）。
- 模糊点："高级一点" 没有说明控件形式，AI 只能猜测。按工单流程，本应向用户确认；此处无法追问，将关键判断依据转化为**可辩护的默认假设**，写明 选型理由，由复核者验收。
- "SaaS 产品"：面向企业团队协作类产品，登录页通常承担一部分品牌传达职责（价值和背书），而不只是表单容器。

## 二、候选对比（登录页 5 种，来自 layouts.md）

| 候选 | 布局 · 背景 · 卡片 | 适用场景 | 对本需求的契合度 |
|---|---|---|---|
| A. 居中卡片式 Centered Card | 单栏留白 + 悬浮卡片 | 多数工具与 SaaS 的常规选择，稳妥通用 | 合格但常规，"高级感"空间有限，品牌色只能做点缀 |
| B. Split Screen 左右分屏式 | 左右分屏；品牌侧有色背景；右侧**无卡片表单**直接叠放 | 品牌展示与登录并存 | ✔ 品牌色可大面积铺陈，"高级感"由留白、衬线大字、克制动效支撑；SaaS 品牌页的主流高级做法 |
| C. Immersive Background 沉浸背景式 | 有色沉浸背景 + 无边框表单 | 品牌氛围优先、表单一体 | 氛围感强，但整页高饱和陶橙对可读性与冷静的证据呈现不利 |
| D. Role-based Tabs 多角色 Tab 登录 | 同一表单切换身份 | 个人/企业双端产品 | 需求未提到多身份，无判断依据，不选 |
| E. Step-by-step 分步登录式 | 分屏流程，一屏一个任务 | 验证步骤较多（OTP、二次验证等） | 登录字段 ≤ 4 个，controls.md 明确"字段在 4 个以内不要分步"，不选 |

## 三、判断依据与默认假设

1. 布局：品牌色需要被"看见"，且 SaaS 登录页需要信任背书 → 选 **B（Split Screen，左品牌右表单）**。按参考范例定为 6:4 分屏，移动端折叠为单栏（brand 侧压缩为顶部条）。
2. 卡片：右侧**不使用卡片**，表单直接叠放在暖白背景上，层级靠留白与对齐建立（rules.md"分组方式：卡片不是默认答案" + "留白 Whitespace"术语）。
3. 气质：陶橙（terracotta，主色 #C75A2E 系）是暖色、有手作感的颜色 → 视觉语言用暖白底 (#FAF7F4)、衬线大标题、克制的微交互，避免荧光渐变和玻璃拟态，保证"高级"而非"花哨"。
4. 表单字段假设：仅 邮箱 + 密码（+ 记住我 / 忘记密码），未假设短信/验证码登录。
5. 第三方登录假设：提供 企业微信 / 飞书 两个线状（OUTLINE）入口；若实际产品没有，可整块删除。

## 四、交互动效选型（来自 rules.md / controls.md）

- **主按钮**：面状实心 SOLID + 全宽 FULL-WIDTH（移动端表单场景 + 主操作唯一），文字动词开头"登 录"；全页仅此一个实心按钮，其余（忘记密码、申请试用）为文字按钮 TEXT。
- **校验时机**：邮箱与密码 **失焦校验 Blur**（短表单、字段相互独立），提交时统一复查并自动聚焦第一个错误项；**错误提示显示在输入框下方**，说明"哪里错、怎么改"。
- **表单体验检查点**：Label 在输入框上方、必填标记提前标注、Helper Text 给格式示例、Inline Validation 字段旁说明、提交后 Success Feedback。
- **等待反馈**：登录等待时长未知 → **不确定进度 Indeterminate**，按钮内用循环同步 spinner（controls.md 进度：算不出比例不编造百分比）；期间表单禁用防重复提交。
- **提示等级**：结果反馈用 **轻提示 Toast**（级别 02，右上角出现数秒自动消失，不打断操作），不用 ALERT/Modal。
- **密码可见性**：眼睛图标切换（ICON BUTTON 补充控件），Cap 不外泄。
- **移动端降级**（rules.md 7 条检查）：左右分屏折叠单栏，阅读顺序从品牌条到表单；触控目标 ≥ 44px；无 hover 依赖（悬停效果同时挂 :focus-visible / :active）。
- **高级感来源（rules.md 设计术语）**：留白 Whitespace + 栅格 Grid + 卡片微交互（仅品牌面板图标）+ 低强度动效（输入框聚焦色、按钮按压、左侧内容入场淡入），全部带 prefers-reduced-motion 降级。

## 五、最终选型

**Split Screen 左右分屏式登录页（6:4，移动端折叠单栏）**

- **布局**：左侧 60% 为陶橙沉浸品牌面板（深陶橙渐变 #7B3018 → #C75A2E → #E08A4F，叠细颗粒噪点纹理），含 logo、衬线主标题、价值句、三条背书指标、用户证言；右侧 40% 暖白底 (#FAF7F4) 无卡片表单。
- **背景**：右侧纯暖白，仅靠留白与左对齐排版建立层级；品牌橙只出现在按钮、链接、聚焦态，保持全页唯一强调色。
- **控件清单**：Logo；文字按钮"返回官网"；Label 邮箱 Text Field（失焦校验 + 错误在下方）；Label 密码 Text Field（可见性切换、最小 8 位提示、壳聚焦态）；记住我 Checkbox；忘记密码 文字按钮；全宽实心主按钮（登录中变 spinner + "正在登录…"）；分隔线"或"；企业微信/飞书 线状按钮；页脚"没有账号？申请试用"。
- **操作规则**：邮箱失焦校验格式；密码失焦校验长度；提交统一复查、聚焦首个错误；全部通过 → 按钮进入不确定进度 spinner → Toast"登录成功"。
- **可访问性**：正式 label 关联、aria-live 错误区、错误 aria-invalid / aria-describedby、对比度 ≥ 4.5:1（按钮深陶橙 #AE4A1F vs 白字 ≈ 5.5:1）、键盘焦点环完整、reduced-motion 降级。

## 六、最终 Prompt（按 SKILL.md 固定顺序：布局类型、背景、卡片、控件、交互规则）

> 做一个 Split Screen 左右分屏式登录页，桌面 6:4，移动端折叠为单栏。
> 左侧为陶橙沉浸品牌面板：深陶橙渐变背景（#7B3018 → #C75A2E → #E08A4F）加细颗粒噪点，内容左对齐，包含 logo、衬线主标题"让每个想法，稳妥落地"、一条价值句、三条背书指标（12万+ 团队 · 99.99% 可用性 · ISO 27001）和一条用户证言，入场时轻微淡入。
> 右侧不使用卡片，表单直接叠放在暖白背景 #FAF7F4 上：标题"欢迎回来"，下方标签在上输入框在下的字段——工作邮箱（必填，失焦校验邮箱格式，错误提示显示在输入框下方并说明改法）与密码（必填，≥ 8 位，带可见性切换图标）；再下方"记住我"勾选框与"忘记密码"文字按钮同一行两端对齐。
> 主操作为一个全宽、圆角、实心陶橙（#AE4A1F，hover 加深）的"登 录"按钮，全页唯一实心按钮；提交时统一校验并聚焦第一个错误项；通过后按钮禁用并显示循环 spinner"正在登录…"，等待时长不可知，不显示虚假百分比；结果用右上角轻提示 Toast 数秒自动消失。
> 主按钮下用"或"分隔并提供"企业微信 / 飞书"两个线状描边按钮；页脚提供"没有账号？申请试用"文字入口。
> 桌面 hover 效果在触屏退化为按压反馈；可点击区域 ≥ 44px；品牌橙仅用于主按钮、链接与聚焦态；支持键盘操作与 prefers-reduced-motion。
