# 登录页选型笔记

对应需求原文："帮我们 SaaS 产品做个登录页，要高级一点，品牌色是陶橙色。输出一个可以直接打开的完整 HTML 文件（单文件）。"

## 0. 需求识别

- 场景：登录页 → 查阅 `references/layouts.md`“登录页 — 5种”。登录页描述包含 **布局、背景、卡片** 三项要素。
- "高级一点" 是模糊风格表述。按 SKILL.md“使用注意”：不凭空猜测直接写码，先列候选与判断依据。
- 关联控件与规则（查阅 `references/controls.md`、`references/rules.md`）：
  - 按钮：三步公式（形态、样式、文字）；主按钮全页仅一个，其余用线状/文字样式。
  - 表单校验：失焦校验 + 提交校验组合；错误提示显示在输入框下方，说明"哪里错、怎么改"。
  - 等待体验：登录等待无法计算百分比 → 按钮内使用不确定进度的循环同步 spinner，不编造百分比。
  - 成功反馈：轻提示 Toast，右上角出现数秒自动消失。
  - 表单整体体验 7 检查点：Label、必填标记、Helper Text、即时校验、错误位置、成功反馈。
  - 移动端降级：多栏折叠单栏、触控目标 ≥ 44×44px、输入框触发对应键盘类型。

## 1. 候选对比

| 候选 | 形式 | 适用场景 | 本案评价 |
|---|---|---|---|
| A. 居中卡片式 Centered Card | 卡片悬浮居中，页面留白充足 | 多数工具与 SaaS 的常规稳妥选择 | 稳但"平"：品牌色只能出现在按钮与细节点缀，"陶橙"无法成为主视觉记忆点，难以支撑"高级+品牌"诉求 |
| B. Split Screen 左右分屏式 | 6:4 左右分屏，左侧品牌叙事，右侧无卡片表单；移动端折叠单栏 | 品牌展示与登录并存 | **品牌色可铺满半屏成为主视觉**；表单落在浅底上，可读性与专业感最好；符合 SaaS 企业用户的预期气质 |
| C. 沉浸背景式 Immersive Background | 陶橙→金渐变铺满全屏，表单无边框叠放，加深色遮罩 | 品牌官网、活动页 | 视觉激进；浅色输入框与白字压在暖橙底上，对比度与可读性都吃紧，企业 SaaS 登录场景偏冒险 |

排除项（同样来自 layouts.md 登录页 5 种）：
- Role-based Tabs 多角色 Tab 登录：本案是单一身份登录，无"个人/企业"双端身份切换需求。
- Step-by-step 分步登录式：登录只有 2 个字段。依据 `controls.md` 步骤条节——字段不超过 4 个、操作高频熟练时不分步，单页一次填完更快。

## 2. 判断依据

1. **品牌诉求强**：用户明确指定品牌色（陶橙 terracotta），说明希望品牌被"看见" → 需要能大面积承载品牌色的布局 → 指向 B。
2. **场景是企业 SaaS 登录**：高频、字段少、用户目标明确 → 表单应清爽不花哨，视觉重点放在品牌一侧 → 分屏恰好把两者隔离。
3. **"高级一点"的转写**：参考 `rules.md` 设计术语——用留白、统一栅格、克制的配色层级（品牌色只保留一个主色家族）、大字排版与微交互来实现，而不是堆装饰。
4. **信息不足项与默认假设**（实现时需占位，用户可替换）：
   - 产品名与文案未提供 → 使用虚构品牌"陶然工作台 Taowork"，全部文案可替换。
   - 未提供风格参考图 → 按 layouts.md“风格参考图”一节的要求，把色彩色值与控件规格直接写进实现规格，不依赖图。
   - 登录方式未提供 → 默认"邮箱 + 密码"，并保留第三方登录入口。单字段邮箱选择 Text Field（输入类，非固定选项选择，无需 Select/Combobox）。
   - 未要求暗色模式与移动端适配的深度 → 暗色模式不做（用户未提，避免过度设计）；移动端做基础单栏降级（layouts.md 明确要求"移动端折叠单栏布局"）。

## 3. 最终选型

**B. Split Screen 左右分屏式登录页**，按 layouts.md 原句："做 6:4 左右分屏，左边讲品牌，右边放无卡片表单；移动端折叠单栏布局。"

理由：三种候选里只有 B 同时满足"品牌色成为页面主角"与"表单保持最佳可读性"两个条件；C 的对比度风险无法在校验中稳妥通过；A 无法表达品牌。

## 4. 实现 Prompt 规格（按固定顺序组装）

**页面三要素（布局、背景、卡片）**：
- 布局：6:4 Split Screen 左右分屏登录页，左侧品牌区，右侧登录区；≤920px 折叠为单栏，品牌区收成顶部横条。
- 背景：左侧陶橙渐变（#DE6845 → #9C3D22，浅→深、文字落位在深色区保证 ≥4.5:1 对比度）+ 细颗粒噪点 + 大圆环装饰 + 玻璃质感客户证言卡；右侧暖白纸感底（#FBF8F5），充足留白。
- 卡片：右侧**不使用卡片**（无卡片表单）；品牌侧证言卡为唯一悬浮容器。

**控件清单（中文名 英文名 + 形式 + 操作规则）**：
- 文本输入框 Text Field ×2：标签在输入框上方（不依赖 placeholder），必填标"*"，密码标签旁给"至少 8 位"辅助说明；聚焦显示陶橙描边光圈。
- 图标按钮 ICON BUTTON：密码框内"显示/隐藏密码"眼睛按钮，切换 type 并同步 aria-label。
- 复选框 Checkbox："记住我"，勾选后把邮箱存入 localStorage，下次进入自动回填。
- 文字按钮 TEXT BUTTON：忘记密码（唯一线框级旁路操作，不做线状按钮争注意力）。
- 全宽 + 面状按钮 SOLID FULL-WIDTH BUTTON："登录"，陶橙实心（#BB4E2E，白字对比度 ≈5:1），hover 上浮、active 下压；全页唯一主按钮；点击后进入加载态——按钮内循环同步 spinner + "正在登录…"，不编造百分比。
- 线状按钮 OUTLINE BUTTON ×2：企业微信 / 飞书第三方登录，仅描边不与主按钮争夺权重。
- 轻提示 Toast：登录成功右上角出现、3 秒自动消失；演示环境的第三方登录用同容器 info 态提示。

**交互规则**：
- 单字段失焦即校验邮箱格式与密码长度（仅当已填或曾报错时，避免误伤刚聚焦就离开的用户）；提交时统一校验，错误定位：请输入/格式说明显示在**输入框下方**，自动聚焦第一个错误项，纠正输入即时消错。
- 成功反馈：模拟登录 1.4s → Toast "登录成功，正在进入工作台"。
- 触控目标 ≥ 44px；邮箱 input type=email 触发邮箱键盘；prefers-reduced-motion 下关闭全部动画。

## 5. 验收清单

- [x] 单文件、无外部依赖（无网络字体/CDN/图片），双击即可打开
- [x] 全页仅一个面状主按钮，层级清晰
- [x] 错误提示在输入框下方并说明"哪里错、怎么改"
- [x] 等待用不确定进度 spinner（按钮内），成功用 Toast（轻提示等级）
- [x] 正文文字与背景对比度 ≥ 4.5:1（按钮白字 #BB4E2E ≈ 5.0；品牌区小字落在深端）
- [x] 移动端折叠单栏，品牌区降级为顶部横条
