# 实现说明

## 产品设定
虚构 SaaS“澄云 · 企业协同平台”，中文界面，单文件 `page.html`，双击即可打开（无外部依赖、无网络请求、无构建步骤）。

## 布局
- 桌面端左右分栏：左侧为陶橙渐变品牌区（Logo、主标语、三项企业数据、客户证言），右侧为 520px 白色登录卡片。
- 移动端（≤960px）隐藏品牌区，表单卡片全屏。

## 品牌色
- 主色陶橙 `#D96A32`，深色 `#B84E1D` 用于渐变收尾，`#FDF6F0` 作为浅色延伸（悬停/聚焦背景），全部收敛为 CSS 变量，方便整体换肤。

## 交互
- 输入框聚焦：品牌色描边 + 4px 柔和光晕。
- 客户端校验：账号支持邮箱或 11 位手机号格式，密码至少 6 位；错误行内提示、红框标错，输入时自动清除。
- 密码可见性切换按钮；“记住我”“忘记密码”占位。
- 提交：按钮进入 loading（旋转指示器 + 禁用），1.4s 后弹出成功 toast。
- 第三方登录按钮（企业微信 / 钉钉）为占位，点击出 toast。

## 可用性与细节
- 图标全部内联 SVG，无字体/图标库请求。
- 表单语义化（label/autocomplete/aria-invalid/aria-label）。
- 按钮、输入框均有 hover / active / focus 状态与过渡动画；toast 淡入淡出。
