# 登录页实现说明

## 方案概述
单文件 HTML 登录页（无外部依赖，双击即可打开），采用经典 SaaS“左品牌 + 右表单”分栏布局。

## 设计要点
- **品牌色**：陶橙色系全套令牌（主色 `#D96C47`、深色 `#B9532F`、浅底 `#F5E0D6`、暖灰背景 `#FAF7F4`），深浅渐变营造高级感
- **左侧品牌区**：渐变背景 + 装饰圆环、品牌口号、三组数据指标（企业客户 / 可用性 / 日均处理量），强化 SaaS 可信度
- **右侧表单区**：邮箱/手机号 + 密码、记住我、忘记密码、第三方登录（微信 / 企业 SSO）、服务条款提示

## 交互实现
- **密码可见切换**：眼睛图标在显示 / 隐藏间切换（SVG 直接换 innerHTML）
- **表单校验**：邮箱 / 手机号正则 + 密码长度校验，错误时标红字段并显示行内错误文案，输入即清除
- **提交状态**：登录按钮带 loading spinner，1.2s 模拟请求后弹出 Toast 反馈
- **Toast 提示**：顶部居中滑入淡出，成功（绿点）/ 失败（红点）两种状态

## 响应式
`≤900px` 时切换为上下堆叠：品牌区压缩为横幅，表单区全宽，隐藏次要文案。
