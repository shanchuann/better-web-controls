# page.html 实现说明

## 概览
- 单文件 HTML，双击即可打开，无任何外部依赖（纯内联 CSS/JS）。
- 品牌色：陶橙 `#D96C3F`，配套一套暖色阶（clay-50 ~ clay-900）。
- 假设产品名“炽薪云 / CHIXIN CLOUD”（可自行替换）。

## 布局
- 桌面端左右分栏：左侧为深色陶橙渐变品牌区（logo、标语、客户证言、网格纹理装饰），右侧为白色登录表单区。
- ≤900px 自动纵向堆叠，品牌区精简为紧凑头部。

## 交互与细节
- 邮箱/手机号 + 密码登录，带前端校验（格式校验、内联错误提示、错误态红色边框、聚焦首错项）。
- 密码明文/密文切换（眼睛图标）。
- “记住我”自绘复选框（陶橙选中态）。
- 登录按钮：loading 动画（spinner + 文案变化）＋ 模拟 1.4s 提交后弹出成功 toast。
- 顶部 toast 通知（成功/错误两种色点）。
- 入场 fadeUp 分层动效；支持 `prefers-reduced-motion` 降级。
- 第三方登录（微信/飞书/钉钉）占位按钮，点击给出“开发中”提示。

## 可替换点
- ICP 备案号、注册/忘记密码/协议链接目前为占位（`onclick="return false"`），接入真实路由时替换即可。
- 登录为纯前端模拟，`form.submit` 事件里 setTimeout 处替换为真实接口调用。
