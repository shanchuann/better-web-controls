# 选型笔记：个人作品集导航栏 + 简单首屏

## 1. 需求识别

原文："帮我做一个个人作品集网站的导航栏，要有高级感，配一个简单的首屏。"

按 `SKILL.md` 工作流第 1 步，需求类型为**页面布局与结构**，查阅 `references/layouts.md`，涉及两节：

- **导航 — 9 种**（原文"要有高级感"过于模糊，需先给具体样式名，不能直接写代码）；
- **首屏设计 — 先判断网站类型**：作品集属于**个人品牌形象类**，用户打开后想确认"你是谁、擅长什么"，首屏应给出**定位、代表作品和风格**，而不是塞满内容。

另涉及 `references/controls.md`（按钮三步公式）与 `rules.md`（移动端降级、设计术语）。

## 2. 候选对比（导航 — 三选一）

| 候选（名称 中文 英文） | 形式 | 优势 | 代价 / 限制 |
|---|---|---|---|
| ① 悬浮吸顶 Floating · Sticky 导航 | 离顶留白的圆角玻璃卡，滚动时固定顶部，可叠加 Shrink 变矮 | 高级感最稳的表达：留白 + 玻璃材质 + 阴影；信息始终可达 | 与深色首屏搭配时需调整卡片底色 |
| ② 滚动收缩 Shrink on Scroll | 顶部透明覆盖首屏，下滚变矮转实色 | 与大图首屏融合好，电影感 | 依赖首屏必须有整幅大图/深色底；页面只有一屏时下滚态几乎不出现 |
| ③ 全屏遮罩 Full-screen Overlay 菜单 | 点击后覆盖整屏，菜单居中放大 | 作品集常见，展示性强，个性最足 | 入口收敛为一个汉堡，导航始终只能一次一屏，日常浏览效率低 |

## 3. 判断依据

1. **页面体量**：用户只要"简单的首屏"，页面约一屏深，滚动行为（候选②的收缩触发、Scrollspy 高亮）几乎没有展示机会——为不发生的行为做设计，收益为负。
2. **"高级感"的落地方式**：参考 `rules.md` 设计术语，高级感 = 留白 + 栅格 + 克制配色 + 材质（液态玻璃），对应"浮起的圆角卡"这类具体样式名，而非泛泛的"高级一点"。候选①可直接承载这套材质语言。
3. **移动端**：`rules.md` 移动端降级第 1 条——水平导航放不下时收为汉堡。作品集在移动端用**全屏遮罩**反而是体验最好的兜底（候选③的价值以移动端形式保留）。触控目标按规则 ≥ 44×44px。
4. **首屏内容**：个人品牌类 → 圆形/矩形头像 + 放大标题 + 定位一句话 + 一组代表能力数据行，主视觉不塞满（参考 layouts.md 首屏示例"圆形头像、放大代表作品 Banner"）。
5. **按钮层级**：per `controls.md`，全页仅一个面状（实心）主按钮放在首屏 CTA"查看作品"；导航右侧"预约合作"退为线状按钮，互不争夺注意力。

**信息不足项**：用户未给姓名、作品、配色偏好——采用占位文案与暖纸白 + 墨色 + 单一陶橙强调色，可直接替换。

## 4. 最终选型

**悬浮吸顶导航 Floating Sticky 导航 + 首屏 Hero（个人品牌形象类）+ 移动端全屏遮罩菜单**。

组装后的完整 Prompt 规格（按"名称、形式、操作规则"三要素）：

> 做一个悬浮吸顶导航 Floating · Sticky Navbar：顶部离顶 20px 悬浮的圆角玻璃卡（半透明磨砂 + 模糊 + 细边框 + 柔和阴影），滚动时固定吸顶，下滚后卡片微缩高度（Shrink）；
> 桌面端左侧品牌名、右侧五个文字链接 + 一个线状按钮"预约合作"；链接悬停以下划线滑入、当前页加粗高亮；
> 首屏为个人品牌形象类 Hero：眉题（领域定位）+ 放大主标题（一句定位）+ 两行自述 + 能力标签胶囊 + 一个面状主按钮"查看作品"与一个文字按钮"联系我" + 右侧头像卡片（含可接项目状态标签）+ 底部三格数据行（经验 / 项目 / 奖项）；
> 移动端（≤800px）收起链接与线状按钮，汉堡按钮（44×44px）呼出全屏遮罩菜单：深色整屏、菜单居中放大、逐项上浮入场，点击菜单项、关闭按钮或按 Esc 关闭，并锁定滚动；
> 预置栏目（作品 / 关于 / 服务 / 联系）暂无对应区块时，点击以轻提示 Toast 说明"栏目将在完整站点中提供"，不误导向死锚点；支持 prefers-reduced-motion。

## 5. 选型理由（在对比中为何是①）

- 候选①把"高级感"转译成了可执行的材质与布局参数（玻璃卡、留白、吸顶、微缩），是三者中唯一不需要额外前置条件（大图首屏、整屏菜单节奏）的选择，对"简单首屏"的匹配度最高。
- 候选②的核心价值场景在本页不存在（仅一屏，滚动行为几乎不触发）；候选③个性最强但以牺牲导航可达性为代价，适合作品多、页面深的站点——此处仅作移动端兜底形式保留。
- 差异化质感动效通过 Hero 侧实现（主标题句号用强调色、链接下划线滑入、遮罩菜单逐项上浮），避免动效过载。
