# 选型笔记：个人作品集导航栏 + 简单首屏

需求原文："帮我做一个个人作品集网站的导航栏，要有高级感，配一个简单的首屏。直接输出单文件 HTML。"

判断：需求涉及两类内容——布局与结构（导航栏、首屏），参考 `layouts.md` 的"导航 — 9种"与"首屏设计"两节；导航内含按钮，规格参考 `controls.md` 按钮三步公式。"高级感"是模糊词，不能直接写代码，需先把它转写成具体风格参数（见第 4 节）。

## 1. 导航候选对比（9 种中取 3 个候选）

| 候选 | 形式 | 适用场景 | 是否入选 |
|---|---|---|---|
| ① 悬浮吸顶 Floating · Sticky | 浮起圆角卡，离顶留白带阴影，滚动固定 | 首屏大留白的展示型页面，导航卡像"陈列在页面上"的作品之一 | ✅ 桌面端选型 |
| ② 滚动收缩 Shrink on Scroll | 顶部透明覆盖大图，下滚变矮变实色 | 依赖首屏大图；本页首屏是排版型（无高质量摄影图可依赖，单文件离线也不应外链图片），透明覆盖没有承载物 | ❌ 排除 |
| ③ 全屏遮罩 Full-screen Overlay | 点击后覆盖整屏，菜单项居中放大 | 参考文件明确标注"作品集常用"；桌面端项少（3 项 + CTA），遮罩过度，但作为移动端菜单形态最合适 | ✅ 移动端选型 |
| （排除）侧边栏 / 二级下拉 / Mega Menu | — | 侧边栏是后台工具形态；本站无多级分类，不需要下拉与多列面板 | ❌ 排除 |

操作规则补充：单页锚点跳转，叠加 **Scrollspy 锚点导航**（滚到哪个分区，对应导航项高亮），这不是独立候选而是行为增强项——单页作品集 4 个分区，滚动高亮是移动端之外最需要自动反馈的场景。

## 2. 首屏候选对比（按"首屏设计"：先判断网站类型）

判断：个人作品集属**个人品牌形象类**，用户打开首屏想确认的是"你是谁、擅长什么"，不是塞产品功能。

| 候选 | 形式 | 是否入选 |
|---|---|---|
| ① 排版型首屏：定位语句 + 圆形头像 + 一行信任数字 | 参考文件示例："加入圆形头像、放大代表作品"；全部系统字体与 CSS 渐变，不依赖图片 | ✅ 选型 |
| ② 全屏沉浸大图 Full-screen：整屏摄影图 + 一句主标题 | 高级感强，但需要真实高质量人像/作品图；占位图反而廉价 | ❌ 排除 |

## 3. 按钮选型（三步公式：形态、样式、文字）

- 主操作：**面状按钮 SOLID BUTTON**——"查看作品"（动词开头、说结果），实心墨色，胶囊圆角、hover 微浮起。全页仅此一个实心主按钮；联系区的"写一封邮件"降级为线状，避免主按钮失焦。
- 次操作：**线状胶囊按钮 OUTLINE BUTTON**——导航右侧"联系我"，仅一圈描边，不与主按钮争夺注意力。
- 轻量操作：**文字按钮 TEXT BUTTON**——"更多介绍 →"，hover 箭头位移。

## 4. "高级感"的具体化（风格参数，不依赖网络）

- 底色暖米白 `#F7F6F2`，文字墨色 `#1B1912`，克制点缀色（赭陶 `#B4552D`）只用于焦点态、高亮圆点与一处强调词。
- 字体层级：标题用衬线大字（Songti/SimSun 系统衬线，单文件可离线打开），正文用无衬线，数字说明用 Georgia 小号加宽字距。
- 质感手段：大量留白、细线分隔、圆角浮起卡、克制的阴影（无渐变横幅、无动图装饰）。

## 5. 信息不足项与处理假设（复核点）

1. 姓名与头像未知 → 使用虚构占位"林一舟"+ CSS 渐变头像，验收后替换。
2. 作品数量与分类未知 → 作品区给 3 张极简占位卡。
3. 用户只要求"导航 + 首屏"，但 Scrollspy 与锚点需要有目标分区 → 首屏之下加三个极简占位分区（作品/关于/联系）与一行页脚，使导航真实可用；验收后替换为真实内容。
4. 深浅色偏好未知 → 默认浅色暖米白。

## 6. 转写后的完整 Prompt（最终实现所依据的规格）

"做一个中文个人作品集单页，单文件 HTML。

导航：悬浮吸顶导航 Floating · Sticky——离顶部 16px 的圆角胶囊浮卡，半透明磨砂背景加柔和阴影，滚动时轻微收缩、阴影加深；左侧站名，右侧'作品、关于、联系'三个锚点链接，滚动到对应分区时该链接高亮（Scrollspy，高亮项下缘加一个小圆点）；最右一个线状胶囊按钮'联系我'。

移动端（≤860px）：导航链接收进汉堡按钮，点击后全屏遮罩菜单 Full-screen Overlay，菜单项居中、衬线大字、依次淡入上浮；点菜单项、按 Esc 或再点汉堡均关闭，打开时锁定页面滚动；汉堡图标随状态变形为关闭叉。

首屏（个人品牌形象类）：左文右图两栏。鼓励句 + 衬线大标题（'我是林一舟，把复杂业务画成一眼看得懂的设计'，强调词用赭陶色）+ 一句定位副文 + 主按钮'查看作品'（全页唯一实心）与文字按钮'更多介绍'+'8 年经验 / 20+ 团队 / 40 项作品'三个数字；右侧圆形头像（虚线圆环缓慢旋转）+ 一枚'目前开放合作'悬浮小徽章。

整体风格：暖米白底、墨色文字、赭陶点缀，衬线标题加无衬线正文，细线分隔与克制阴影；prefers-reduced-motion 时关闭动效与平滑滚动。"
