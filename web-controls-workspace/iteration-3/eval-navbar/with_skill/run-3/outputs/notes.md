# 选型笔记 — 个人作品集：导航栏 + 简单首屏

## 1. 需求转写（模糊 → 准确）

用户原文：'帮我做一个个人作品集网站的导航栏，要有高级感，配一个简单的首屏。'

这是典型的"好看导航 + 模糊风格"表述。按 SKILL.md 使用注意：不直接凭"高级感"写代码，先转写为准确描述——

| 模糊表述 | 转写后的准确描述 |
|---|---|
| "好看的导航栏" | 悬浮吸顶导航 FLOATING STICKY NAVBAR + 锚点高亮 SCROLLSPY（layouts.md 导航 9 种中的第 1、8 种） |
| "高级感" | 术语拆解（rules.md 设计术语）：留白、栅格对齐、半透明磨砂悬浮卡、衬线大标题编辑感排版、克制的单点缀色、hover 微浮起 |
| "简单的首屏" | 首屏类型判断：个人品牌形象类 → 回答"你是谁、擅长什么"：定位句 + 圆形头像 + 放大代表作品卡（layouts.md 首屏设计示例） |

## 2. 导航候选对比（layouts.md 导航 9 种中筛选）

| 候选（中文名 英文名） | 适用场景 | 结论 | 理由 |
|---|---|---|---|
| 悬浮吸顶导航 Floating · Sticky | 作品集、品牌官网；需要常驻跳转 + 悬浮质感 | ✅ 桌面端采用 | 圆角悬浮卡离顶留白 + 滚动吸顶，是"高级感"最直接的载体；滚离首屏后仍能锚点跳转 |
| 锚点高亮 Scrollspy | 长落地页、单页站 | ✅ 与上者组合 | 本页为单页锚点结构，"滚到哪高亮哪"让导航有真实反馈 |
| 全屏遮罩菜单 Full-screen Overlay | 作品集常用（layouts.md 第 7 种注明） | ✅ 移动端采用 | 大字居中菜单有舞台感；桌面端不用它——查找成本高于常驻导航 |
| 滚动收缩 Shrink on Scroll | 顶部整幅大图打底的首屏 | ⛔ 未选 | 好前提是"大图 hero"；本页面首屏为浅色排版型，透明→实色对比弱，且与悬浮卡方案功能重叠 |
| 巨型菜单 Mega Menu / 二级下拉 Dropdown | 分类复杂的电商、多产品官网 | ⛔ 未选 | 作品集顶层导航仅三项，无子内容，加面板是过度设计 |

**导航四要素（按 layouts.md 规范）**：
- 名称：悬浮吸顶导航 Floating Sticky Navbar
- 位置与形式：顶部居中悬浮，离顶 14px；圆角胶囊卡、半透明磨砂（backdrop-filter）、1px 细线描边
- 触发与状态：常驻；滚动 >10px 后底色转实、阴影加深（属悬浮吸顶的状态强化，非 Shrink 方案）；点击项平滑滚动
- 收起方式：移动端（≤820px）水平链接收进汉堡按钮，点击展开全屏遮罩菜单——大衬线字居中、逐项上浮、Esc 或选中后关闭；触控目标 ≥44px（rules.md 移动端降级）

## 3. 首屏判断（layouts.md 首屏设计）

- 类型：**个人品牌形象类** → 首屏回答"你是谁、擅长什么"，给定位、代表作品和风格，不是塞内容
- 页面布局候选：
  1. 单栏编辑排版 + 左文右图 Hero ✅ —— 与"简单首屏""高级感（编辑感衬线）"匹配
  2. 全屏沉浸式 Full-screen ⛔ —— 需整幅摄影素材，单文件离线打开不引外图
  3. 瀑布流 Masonry ⛔ —— 面向"作品多图"的整站布局，超出"简单首屏"范围
- 首屏信息顺序：身份行（圆形头像 + 姓名 + 职位）→ 衬线大标题定位句 → 一句擅长说明 → 主/次 CTA → 状态行"可接受新项目"；右侧放置放大的"代表作 Banner"卡（几何占位插画 + 标注），符合 layouts.md 个人品牌示例"加入圆形头像、放大代表作品 Banner"

## 4. 按钮与层级（controls.md 三步公式：形态、样式、文字）

- 主 CTA：面状胶囊按钮 PILL BUTTON"查看作品"——近黑 #211E19 实心、白字、hover 微浮起；**全页唯一实心主按钮**（controls.md 页面层级规则）
- 次 CTA：线状胶囊按钮 OUTLINE BUTTON"联系我"——一圈描边无底色，导航右侧与 Hero 各一处，不与主按钮争夺注意力
- 联系区：不做第二个按钮，用大字号 mailto 链接承载转化，保持"实心按钮唯一"
- 文字：动词开头、说结果——"查看作品 / 联系我"，不写"点击这里"

## 5. 页面范围决策（最小可运行）

- 用户只要"导航 + 简单首屏"；但锚点导航不能有死链，跳转项需要落点
- 最小范围：Hero + 精选作品（3 张几何占位卡）+ 联系区与页脚；**不扩展**价格表、FAQ、评价区等模块
- 作品图均为内嵌 SVG 几何线条占位，不引外部图片/字体/CDN，保证双击离线打开

## 6. 其他规则适用性判断（rules.md）

- **强度匹配**：本页无删除/支付类高风险操作，无需二次确认与弹窗——不做多余交互
- **暗色模式**：用户未要求，不做第二套界面，避免过度设计
- **移动端降级清单**：导航收汉堡 + 全屏遮罩；双栏折单栏；无 hover 依赖交互；可点击区域 ≥44px
- **无障碍**：跳转链接（skip link）、aria-expanded/aria-hidden、Esc 关闭、focus-visible 外圈、prefers-reduced-motion 关闭动效与平滑滚动
- **定位防遮挡**：目标区块 scroll-margin-top，避免被悬浮导航盖住锚点标题

## 7. 转写后的完整 Prompt（按"名称→场景/形式→操作规则"顺序组装，供复核）

> 做个人作品集网站"悬浮吸顶导航 FLOATING STICKY NAVBAR + 简单首屏"，中文，单文件 HTML：
> 导航为悬浮胶囊卡：离顶 14px、半透明磨砂、滚动后转实色加深阴影；左侧站名"林可"，中部锚点链接"作品 / 联系"，右侧线状胶囊按钮"联系我"；Scrollspy 锚点导航，滚动到对应区块时导航项高亮且下划线滑入。移动端收进汉堡按钮，点击展开全屏遮罩菜单：大衬线字居中逐项上浮，Esc、点遮罩或选中项后关闭，触控目标不小于 44px。
> 首屏为个人品牌形象类：左侧身份行（圆形头像 + 姓名 + 职位）、衬线大标题"把想法，打磨成耐看的界面。"、一句定位介绍、面状胶囊主按钮"查看作品"（全页唯一实心按钮）+ 线状按钮"联系我"、状态行"可接受新项目"；右侧放大代表作 Banner 卡（几何占位插画 + 标题标注）。
> 视觉风格：暖米白 #F7F4EE 底、近黑 #211E19 文字、赤陶 #B4502E 单点缀色；衬线标题 + 无衬线正文；栅格对齐、大量留白。
> 落点区块：精选作品 3 张几何占位卡（纯 CSS/SVG，不引外部资源）、联系区大字 mailto 链接与页脚；单页锚点平滑滚动，scroll-margin-top 防遮挡。

## 8. 验收要点

- 双击离线可打开：无外链图片/字体/JS 依赖
- 720–820px 断点：双栏折单栏、导航收进全屏遮罩菜单
- 锚点跳转后区块标题不被悬浮导航遮挡
- 全键盘可达：Tab 顺序合理、Esc 关闭菜单、焦点环可见
- 动效克制：hover 浮起/下划线滑入，reduced-motion 环境自动关闭
