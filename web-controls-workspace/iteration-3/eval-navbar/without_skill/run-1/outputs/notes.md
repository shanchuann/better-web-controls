# 实现说明

单文件 HTML（内嵌 CSS/JS），双击即可打开，无需构建或服务器。

## 设计方向
- 米白纸感底色 + 近黑主色 + 赭橙点缀色，走低调克制的"编辑感"路线。
- 标题用衬线（Noto Serif SC，离线时回退到系统宋体），正文用无衬线，形成对比。
- 大量留白、细分割线、圆角胶囊按钮，营造高级感。

## 导航栏
- 固定顶部；滚动超过 24px 后切换为半透明毛玻璃背景并显示分隔线。
- Logo 由圆形字母标 + 名字组成，悬停时微旋转变色。
- 链接悬停有从右向左收回、从左向右展开的下划线动效。
- 右侧"合作洽谈"胶囊 CTA，悬停反色。
- 移动端折叠为汉堡菜单（带 aria-expanded 无障碍属性）。
- 滚动时按当前所在分区自动高亮对应导航项（Intersection 思路的 scrollY 计算）。

## 首屏
- 小字眉标 → 大号衬线标题（关键词带赭橙高亮底纹）→ 简介介 → 双 CTA → 数据条（经验年限/项目数/合作品牌）。
- 背景有两个大半径柔光晕（径向渐变），无图片依赖。
- 底部有向下滚动的提示线动画。
- 入场动画用 CSS keyframes 依次延迟浮现；遵循 prefers-reduced-motion 时全部关闭。

## 兼容性
- 纯 HTML + CSS + 原生 JS，无外部依赖（仅 Google Fonts 可选加载，有系统字体回退）。
- 响应式断点 820px，适配移动端。
