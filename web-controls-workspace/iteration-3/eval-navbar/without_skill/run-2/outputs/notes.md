# 实现说明

## 结构
- 单文件 HTML，全部 CSS/JS 内嵌，无外部依赖，双击即可打开。
- 固定顶部导航栏 + 全屏首屏（hero）的最小组合，中文界面。

## 导航栏
- `position: fixed` + `backdrop-filter: blur` 毛玻璃效果，滚动超过 24px 后 JS 加 `.scrolled` 类，显示底部分隔线并加深底色。
- 左侧圆形"白"字 logo 标记 + 姓名中英文组合；中部四个锚点链接，hover/激活时金色下划线从左向右展开（scaleX + transform-origin 切换）。
- 右侧描边胶囊形"与我合作"CTA 按钮；≤820px 时切换为汉堡按钮，展开为下拉面板（带透明度/位移过渡）。

## 首屏
- 深色底（#0c0c0e）+ 米金色强调色（#c8b48a），右上方径向渐变光晕营造氛围。
- 宋体系大标题 + em 强调色，宋黑混排制造对比；左侧金色短横线的问候语引导视线。
- 两个 CTA：实心金色胶囊主按钮（hover 上浮 + 阴影 + 箭头位移）与安静的文字链接。
- 底部固定一行：带循环"滴水"动画的滚动提示条 + 所在地信息。
- 入场用 `.reveal` 交错延迟（0.15s 步进）的 translateY 上浮动画。

## 其他
- 使用 CSS 变量统一色彩、导航高度、字体栈；`clamp()` 做流式字号。
