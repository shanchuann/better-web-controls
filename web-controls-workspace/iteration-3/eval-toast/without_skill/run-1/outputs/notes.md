# 实现说明

需求：设置页面点“保存”后有反馈，保存成功即可，不打断用户操作。

## 方案：非阻塞 Toast 提示

选择右上角滑入式的 Toast 通知（而非 alert/confirm/模态框），原因：

- **不打断操作**：`position: fixed` 悬浮于页面之上，不抢占焦点、不锁滚动，用户可继续编辑或点击其他内容。
- **自动消失**：2.5 秒后淡出并移除 DOM，无需用户手动关闭，配合 `aria-live="polite"` 让读屏软件也能温和播报。
- **明确成功语义**：深色底 + 绿色对勾图标 + “设置已保存”文案，一眼可辨。

## 实现细节

- 保存按钮在请求期间显示“保存中…”并禁用，防止重复提交（模拟 600ms 请求）。
- Toast 通过两个 `requestAnimationFrame` 触发 CSS 过渡，实现右侧滑入动画；容器 `pointer-events: none`，只有 toast 本身可交互，避免遮挡页面。
- 支持多条 toast 叠加（依次纵向排列），不会互相覆盖。
- 单文件，无外部依赖，双击即可打开。
