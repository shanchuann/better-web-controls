# 实现说明

## 需求
设置页面点击“保存”后给出反馈，只需告知保存成功，且不能打断用户操作。

## 方案：Toast 轻提示（非阻塞）
- **形式**：点击保存 → 顶部居中弹出“设置已保存”toast（成功图标 + 文案），约 2.5 秒后自动淡出消失。
- **不打断操作的关键点**：
  - toast 容器 `position: fixed`，脱离文档流，不引起页面布局抖动；
  - 容器设置 `pointer-events: none`，toast 显示期间用户仍可正常点击/输入页面任何元素；
  - 不使用 `alert()`、不弹模态框、不抢焦点、不需要任何用户确认操作即可自动消失；
  - 模拟 500ms 保存请求期间按钮短暂置为“保存中…”防重复提交，完成后立即恢复。
- **可访问性**：toast 容器带 `aria-live="polite"`，元素带 `role="status"`，屏幕阅读器也能收到反馈。
- **动画**：双 `requestAnimationFrame` 保证过渡生效，淡入淡出各 250ms。

## 附加细节
- 用户修改任何设置项时，底部操作栏左侧出现“有未保存的更改”提示，保存成功后自动隐藏。
- 界面为中文的简洁设置页（基本信息 + 通知与外观），单文件、无外部依赖，双击即可打开。
