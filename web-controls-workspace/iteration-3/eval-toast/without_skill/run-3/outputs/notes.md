# 实现说明

## 需求
设置页点“保存”后给出"保存成功"反馈，且不打断用户操作。

## 方案：Toast 轻提示
- **位置**：固定在页面顶部居中，不遮挡表单主体，不夺走焦点。
- **不打断操作**：不使用 alert/confirm 等模态弹窗；toast 自动消失（3 秒），用户可继续编辑；也支持连续点击保存、重复触发（每次重置动画与计时）。
- **动效**：淡入 + 轻微下移进入，透明度淡出；底部有进度条呼吸动画提示剩余时长。
- **可及性**：`role="status"` + `aria-live="polite"`，屏幕阅读器会在不中断的前提下播报"保存成功"。

## 其他实现细节
- 保存按钮点击后短暂显示"保存中…"并禁用 500ms，模拟异步请求，避免重复提交。
- 界面为中文设置页样例（个人信息 + 通知偏好开关），纯单文件，无外部依赖，双击即可打开。
